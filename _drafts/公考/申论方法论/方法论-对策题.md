# 对策题 · 方法论

> 类型：**方法论**（对策题专用；分析题见 [[方法论-综合分析]]）
> 通用阅读与找点见 [[归纳概括]]；各卷差异与赋分见 [[京考国考广东省考特色]]。
>
> **出题标志**：材料给问题，题干让你提对策。25 分 ≈ 5 个要点，每点约 5 分。

## 一、国考 vs 京考

| | 国考 | 京考 |
|---|---|---|
| 写不写问题 | **写**（题干要“梳理问题＋提建议”，问题本身占分） | **不写**，纯浪费格子 |
| 主体 | 问题本身已含政府、企业、群众，直接反推 | 常是一个主体（如企业）暴露一堆问题，须写政府监管＋企业整改＋群众监督 |
| 格式 | 问题段＋对策段 | 宏观对策＋意义；再列 2–3 条具体做法 |
| 赋分 | 20 分＝问题 10＋对策 10；每条 4 分＝2＋2 | 25 分＝5 点 × 5 分 |
| 字数 | 400 字，问题与对策**各半**，每组约 70 字 | 400 字全给对策 |
| 身份 | 常给身份（「政府工作人员」等），语言要合身份 | 同 |

### 1.1 三条硬规矩

1. **配对写**：问题与对策一一对应，不「先列一堆问题、再列一堆对策」。评卷按组给分，配对才看得见对应关系。
2. **主体＋动作**：谁来做、做什么、怎么做。缺主体＝泛泛而谈。
3. **不越权**：不写「出台法律」「修订条例」（除非身份给到），不写与材料无关的万能对策；具体边界见「九、身份边界」。

## 二、三种反推

1. **直接引用**：材料已给现成做法，直接用（京考少见）
2. **原因反推**：材料讲了“为什么”，反着写（普通话差因常年上网课 → 减少网课、增加线下课）
3. **问题反推**（最常用）：材料只说“不好”，写“怎么变好”（普通话差 → 专项培训＋定期测评＋结对帮练）

**取用顺序：直接 → 原因 → 问题**（顺序不能颠倒）

| 顺序 | 路径 | 什么时候用 | 特点 |
|---|---|---|---|
| ① | 直接引用 | 材料里专家、领导、文件已经说“要……”“应当……” | 最准最省力，采分点可直接对上 |
| ② | 原因反推 | 材料给了“为什么”，现成对策又不够 | 治本，深度高，但易跑偏 |
| ③ | 问题反推 | 前两条都空，只剩负面现象 | 最稳，但容易浮在表面 |

- 先捡材料里的，再往因果上游找，最后才从问题平推
- 三条都写同一件事时，按 ①②③ 取一条即可，别把“治标＋治本”拆成两条凑数
- 国考问题段要写、京考不写，见「一、国考 vs 京考」；写不写与反推顺序无关，是格式问题

**京考要点格式**：`序号 宏观对策（干什么）＋意义（解决什么）。具体做法 1；2；3。`

- 前半句定方向、一句话说完；后半 2–3 个做法自拟，须有主体、有动作、有对象
- “高度重视、加大力度”＝没有采分点

## 三、解题步骤

1. **找点**：对策 7 词——问题、原因、经验、教训、优势、需求＋直接对策
2. **合并**：按问题或举措维度归并，定下大致点数
3. **分格**：按点数估字数、估分值（见「七、字数规范与分格」），数点不均分
4. **匹配**：材料现成对策优先占格，缺口自行补齐
5. **调序**：定要点顺序（大逻辑）＋逐句打磨（小逻辑）

**七词扫描表**（读材料时逐类过一遍，防漏点）

| 词 | 材料里长什么样 | 怎么变成对策 |
|---|---|---|
| 问题 | 负面表述：找不到停车点、锁不上车 | 正着说反：增划泊位、校准定位 |
| 原因 | 因果句：因为规划没纳入、因为没考核 | 打因：纳入道路空间规划、纳入考核 |
| 经验 | 别处做法：某市用信用惩戒见效 | 借鉴推广：推行信用惩戒 |
| 教训 | 失败案例：一刀切禁停引发反弹 | 反向写：避免一刀切、设过渡期 |
| 优势 | 已有基础：已建成市级监管平台 | 借力：依托平台数据测算需求 |
| 需求 | 群众诉求：希望误停能有提醒 | 回应：优化还车提醒 |
| 直接对策 | 已成形的“要……”“应当……” | 直接采纳，只改表述 |

> 前 6 个是线索，必须转译才能用；第 7 个是成品，直接用。
> 实操：第一遍通读抓主线，第二遍按 7 类逐项扫，扫不到的就是真没有。

## 四、问题段怎么写：问题／原因／危害三分

**一句话判据**

- **问题**＝哪里不好：缺什么、差在哪、做不到什么
- **原因**＝为什么不好：句子必须靠“因为、由于、根源在于”才说得通
- **危害**＝会怎样：句子必须靠“导致、造成、使得、影响”才说得通

| 题干问法 | 要不要写原因／危害 |
|---|---|
| 概括／梳理……**问题** | **不写**，只写现状缺口 |
| 分析……问题产生的**原因** | 必须有原因（这是原因题） |
| **问题及原因**／问题＋建议 | 分段写：问题段仍只写问题，原因单独成段 |
| 谈谈……的**危害／影响** | 危害就是采分点 |
| 综合分析（词句理解） | 原因、危害都可能是得分层 |

**问题题里为什么要删**：①格子被挤占——10 分 5 条，一条只装得下一个点，写原因就挤掉真问题；②与对策重复——写了“因为缺机制”，对策又写“建机制”，两边都拿不满；③判分对不上号——老师按“现象清单”核对，带“因为／导致”的句子容易整条不给分。

**删不如改：把原因、危害转写成问题句**

| 原句 | 判词 | 改成 |
|---|---|---|
| 人工智能产业起步晚、时间不长 | 原因／历史背景 | 缺乏顶尖人才，硕博士培养占比低 |
| 数据跨系统流通不畅，造成大量数据孤岛 | 危害 | 数据跨部门流通不畅，存在数据孤岛、重复开发 |
| 研发周期长、投入大，公司难以承受 | 危害 | 研发资金匮乏、企业抗风险能力弱 |
| 失败风险对个人难以承受 | “这是正常的” | 不写；要写就并入“缺激励与容错” |

**两条例外**

1. 材料只给原因／危害，没有直白的问题句 → 必须“反译”成现状：“导致数据孤岛”写成“存在数据孤岛”。
2. 问题占 15 分以上且要点明显少于条数 → 可用“存在 X，影响 Y”补齐，但仍以 X 作主语。

**落笔检查**：扫一遍问题段，删掉所有“由于、因为、导致、造成、使得”起头的句子；每条只留名词化短板（缺人才、缺资金、标准缺失、机制不健全、监管不到位）。

## 五、对策思路库（十三诀：宣 制 督 保 规 聚 数 试 联 长 改 励 防）

- **宣｜思想观念** — 线下宣讲会、培训班、标语文化墙；线上公众号、短视频、村村通｜内容扣材料问题｜目的：提认识、转观念、造氛围
- **制｜制度机制** — 缺→建章立制；粗→细化规定、量化标准；软→加大违法成本、强化刚性约束
- **督｜执行监督** — 专班＋责任到人｜定期督导、通报约谈｜纳入绩效、奖优罚劣｜明察暗访、专项整治、媒体曝光、群众举报｜源头设门槛—中期强巡查—后期提成本
- **保｜资源保障** — **人**：引（破壁垒、补短板、优惠政策）育（培训、给平台）用（人岗匹配、容错纠错）留（保障服务、情感留人）；**财**：自己筹资／社会招商、慈善／政府专项资金、以奖代补、低息贷款、购买服务；**物**：盘活闲置、修复维护、采购升级；**技**：引成熟技术、请专家、搞培训
- **规｜市场行业** — 准入：提门槛、资质审核、备案；过程：明码标价、合同示范、行业公约、信用红黑名单；退出：约谈整改、停业整顿、联合惩戒（政府定规则、企业担主责、行业自律）
- **聚｜群众参与** — 问需：调研、听证、民意征集、热线与数据研判；参与：志愿者、监督员、举报奖励、议事会；反馈：接诉即办、限时办结、办结回访、结果公开
- **数｜技术赋能** — 平台：一网通办、一网统管、数据共享；手段：智能监测、视频巡查、算法预警、电子溯源；兜底：数据安全、保留线下窗口、适老化改造
- **试｜改革新事** — 小范围试点、跟踪评估、容错纠错；总结成标准、复制推广；动态评估、可退出
- **联｜协同联动** — 纵向市—区—街道—社区四级联动、压实属地；横向联席会、信息共享、联合执法；政府主导＋企业主责＋社会协同＋公众参与
- **长｜长效机制** — 纳入日常、责任清单、制度化；第三方评估、满意度、动态调整；回头看、防反弹、通报曝光
- **改｜政府自我改革** — 审批做减法：优化涉农/涉企行政审批、实行在线审批、免填报减材料、办事流程再造；服务做加法：“政策找人”而非“人找政策”、一人一档一企一档、在线导办、引导式办事指南、一网通办、一窗受理
- **励｜激励与容错** — 正向：财政补贴、以奖代补、集中采购降成本、积分兑换、评优评先、投放配额与考核挂钩；容错：首违不罚、首次误停容错告知、申诉免罚通道、设置整改过渡期
- **防｜风险与应急** — 事前：编制专项预案（不照抄上级）、开展风险普查、划定风险点位；事中：监测预警、应急演练（按主题/季节、增设亲子项目）、物资储备与统一调派、责任到人；事后：复盘评估、异地搬迁、打破“受灾—重建—再受灾”循环

### 5.2 京考高频两招：摸排与议事

**摸排调研五步**（老旧小区改造、基层治理必用）

1. 登记造册：逐户登记意愿，一户一档
2. 分类归因：把不同意／不配合的原因全部注明，分“实际问题”与“担心顾虑”两类
3. 分流反馈：实际问题反馈建设施工方，顾虑问题由干部反复沟通
4. 现场核验：实地看点位、量尺寸、定方案
5. 台账销号：建问题清单，办结一条销一条

**议事协商四问**（居民议事厅、恳谈会、听证会通用）

| 问 | 落笔要素 |
|---|---|
| 谁来议 | 社区党组织牵头＋居民代表＋利益相关方＋专业方（设计、施工、律师） |
| 议什么 | 只议具体方案（改不改、怎么改、钱谁出），不空议大原则 |
| 怎么议 | 议事厅、恳谈会、楼门会、线上投票；提前发方案、现场摆选项 |
| 议完怎么办 | 结果在社区公示栏与业主群公开，形成纪要，明确责任人和时限 |

### 5.3 使用纪律（万能≠裸写）

**公式**：万能骨架 ＋ 材料里的对象 ＋ 材料里的具体手段

| | 写法 | 结果 |
|---|---|---|
| ❌ | 加强宣传引导，提高群众参与意识 | 换到任何题都成立＝针对性为零 |
| ⚠️ | 加强宣传引导，提高居民参与应急演练的积极性 | 有对象，仍缺手段 |
| ✅ | 针对居民参与意愿低，按主题周、季节设置不同类型演练，增设亲子项目并与第三方合作设置奖项 | 骨架＋对象＋手段齐全 |

**落笔两问**

1. 这句话挪到另一道题还成立吗？成立＝没挂载，重写。
2. 句子里有没有材料里的专有名词？没有＝在背模板。

**倒着用**：先抓问题 → 再从十三诀挑 2 个字 → 最后挂上材料的对象与手段。反过来“先想背过哪些万能对策再往题上套”，就是模板痕迹的来源。

### 5.4 「调研」类万能对策：从空话写成得分句

**裸写（不得分）**：积极广泛开展调研，全方位收集问题。

三个硬伤：没有对象（调研谁）、没有手段（怎么调研）、没有产出（调研完得到什么）。「积极」「广泛」「全方位」都是形容词，删掉后句子不剩信息。

**升级三层，缺一层就是半成品**

| 层 | 要补什么 | 示例 |
|---|---|---|
| 对象 | 调研谁 | 沿街商户、老旧小区住户、返乡青年、参保企业 |
| 手段 | 怎么收集 | 逐户走访、分层座谈、实地踏勘、线上问卷、12345 数据研判 |
| 产出 | 结果怎么用 | 形成问题清单／需求台账／风险点位图，作为方案依据 |

**三个可挂载模板（按题干场景三选一）**

- **摸底型**（先摸清底数再定措施）：由街道牵头，对沿街商户逐户走访并实地踏勘，建立问题、需求、资源三张清单，作为制定整治方案的依据。
- **决策型**（涉及多方利益）：围绕改造方案，组织居民代表、经营户、管线单位分层座谈，同步开展线上问卷，意见分类归并后公示，未采纳的逐条说明理由。
- **数据型**（有平台、有热线）：调取 12345 热线、网格上报与平台投诉数据，按月分析高频问题与集中点位，形成整治清单并明确责任单位与时限。

**红线**

材料已经把问题列清楚时，不要再写「开展调研」——问题已知还去调研，属于答非所问；此时直接针对该问题给措施。调研只在材料只给现象、没给成因或底数时使用。

**与 5.2 的关系**：京考「摸排调研五步」是这套写法在基层治理题里的固定展开（登记造册—分类归因—分流反馈—现场核验—台账销号），可直接套。

## 六、材料表述 → 对策 速查

| 材料里出现 | 首选定对策 |
|---|---|
| 不了解、不重视、不愿改 | 宣传教育（宣讲、培训、新媒体、典型示范） |
| 没规定、规定粗、规定软 | 建章立制 / 细化标准 / 加大违法成本 |
| 落实不到位、走过场 | 专班＋督导＋考核问责 |
| 缺人 / 缺钱 | 引育用留 / 财政专项、以奖代补、金融支持 |
| 缺设施 / 缺技术 | 盘活存量、升级改造 / 引技术、请专家、建平台 |
| 乱、无序、恶性竞争 | 准入＋过程＋退出全链条监管 |
| 群众不知道、无处反映 | 畅通渠道＋接诉即办＋结果公开 |
| 部门推诿、各管一段 | 联席会议＋责任清单＋联合执法 |
| 只治标、易反弹 | 长效机制＋评估＋回头看 |
| 新事物、没经验 | 试点先行＋总结推广＋容错纠错 |
| 标准不统一、标识混乱、群众分不清 | 统一标准与标识＋公示可查＋地图同步 |
| 存量被占用、资源闲置浪费 | 清退占位＋专属化改造＋纳管考核 |
| 成本高、企业不愿投入 | 集中采购＋补贴奖励＋引入第三方 |
| 数据不共享、系统不兼容 | 开放数据接口＋平台对接＋多源校验 |
| 群众办事跑多次、材料多 | 免填报减材料＋在线导办＋一窗受理 |
| 有预案但照抄上级、临事等指示 | 分级预案＋演练＋一线授权＋责任到人 |

## 七、字数规范与分格

**三条红线**

- **不超**：写上限的 92%–97% 最稳（400 → 370–385，300 → 280–290）；超 5% 起扣，超 10% 直接丢表达分
- **不少**：低于上限 80%（400 字＜320、300 字＜240）判为内容不全＝自曝要点没找全
- **不脏**：错字划一道即可，禁止成团涂改；不写“以上”“完毕”“谢谢”占格

**一格一字**：标点占一格、序号占格、段首空两格。写完数行——`行数 × 每行格数 ≈ 字数`，比逐字数快。

**各题型配比**

| 题型 | 字数 | 结构 |
|---|---|---|
| 概括（京考首题） | 300 | 总括句 40–50 ＋ 4–5 条 × 50–60 |
| 词句理解 | 250 | 释义 40 ＋ 分析 2–3 层 ＋ 结论 30 |
| 对策 | 400 | 小标题 10–14 ＋ 正文 50–60 |
| 国考问题＋对策 | 400 | 问题 150 ＋ 对策 250，各 4–5 条 |
| 公文（政务信息等） | 300–500 | 标题＋称谓＋正文＋落款，格式占格要先算 |
| 作文 | 1000–1200 | 5–6 段，标题≤20 字 |

**字数 ↔ 点数换算**：1 个采分点 ≈ 15–20 字，故 250 字≈12–15 点、300 字≈15–18 点、400 字≈20–24 点。**字数不够＝点数不够**。

**时间配比**：按 10 字/分钟（含思考）估——300 字≈30 分钟、400 字≈40 分钟；作文 40 分必须留 55–60 分钟。

**分格四步**

- `正文格 = 总字数 − 引导开销`（序号＋小标题每条 10–14 字＋过渡句，约占 10%–15%；400 字题约 50–60 字）
- `条数 ≈ 采分点总数 ÷ 3.5`（每条 3–4 点最稳，过多写不实、过少易漏点）
- `每条格数 = 正文格 ÷ 条数`，按该条点数多寡 ±10 字浮动
- `验算`：每点 15–20 字；<12 字＝条数偏多，>25 字＝太啰嗦

> 400 字示例：正文 322 格 ÷ 5 条 ≈ 64 格，减标题 12 字 ≈ 52 格正文，装 4–5 个词组正合适。
>
> 口诀：先数点、再定条；一条一动作，一点一词组。

## 八、动词与句式

**动词（力度递增）**：引导·推动·督促·要求 → 完善·健全·细化·规范·畅通 → 压实·统筹·盘活·纳入·挂钩·考核 → 整治·查处·约谈·惩戒

- **主体＋方式＋目的**：`由市X部门牵头，联合Y，通过Z（数据/平台/专项行动），实现W`
- **缺什么补什么**：`针对……，建立/完善……，明确……，并纳入……`
- **闭环**：`事前（标准/准入）—事中（巡查/监测）—事后（考核/惩戒/回访）`

## 九、身份边界（防越权）

| 领域 | 可写 | 不写 |
|---|---|---|
| 立法 | 完善配套细则、地方标准、推动修订 | 出台法律、修订条例、改上位法 |
| 财政 | 申请专项、争取补贴、购买服务 | 指定拨款数额、自编预算 |
| 处罚 | 依法查处、提高违法成本、纳入信用 | 自定罚款额、吊销执照 |
| 机构 | 成立专班、明确牵头、建联席机制 | 新设机构、增加编制 |

> 写“怎么干”，不写“改法律”。

## 十、绝对化表述（扣分高频）

**判定两问**：这个承诺能 100% 做到吗？有没有例外（特殊情况、过渡期、困难群体）？只要有一问答"不能"，就是绝对化——本质是**承诺了做不到的事**。

| 不写 | 改成 |
|---|---|
| 杜绝违停、彻底根治、完全禁止 | 减少违停、有效缓解、规范停放秩序 |
| 所有、全部、一律 | 分类施策、原则上、结合实际 |
| 必须、唯一、务必 | 应当、宜、可探索 |
| 零容忍、一票否决 | 依法从严、发现即查、常态化整治 |
| 全面推行、普遍开展 | 试点先行、逐步推广 |
| 一次解决、从根本上解决 | 建立长效机制、持续发力 |

**减绝对不减力度**：`杜绝` → `依法从严查处＋常态化整治`，语气弱了、可行性涨了，阅卷按可行性给分。

**例外**：材料原文的政策表述（"零容忍""一票否决""不留死角"）可以保留，但要写成"坚持××态度""落实××要求"，不要自己升级成"实现零违法"。

## 十一、真题招式库（可直接抄）

**制｜制度规则**

- 编制五年立法规划、专项规划纲要，力争于法有据
- 建立最低保有量制度、目录清单、备案管理
- 明确配置、摆放、更换、消毒标准，让企业有据可依
- 划定并报备服务区，边界向社会公示、入库可查
- 建立常态化机制＋定期召开研讨会＋动态调整政策方向

**改｜政府自我改革**

- 优化涉农（涉企）行政审批服务事项，实行在线审批
- 免填报、减材料，“在线导办”＋“引导式办事指南”
- 建立“一人一档、一企一档”，政策直达，从“人找政策”变为“政策找人”

**督｜监督执法**

- 加大抽检力度、开展专项整治、严格合规准入
- 明察暗访、群众监督员、举报奖励、媒体曝光
- 纳入日常巡查考核、通报约谈、限期整改

**保｜资源保障**

- 菜田补贴、以奖代补、集中采购降成本、引入第三方公益投资
- 盘活闲置房屋与闲置车棚，挖潜边角地、桥下空间
- 免费提供码头接船、攻略向导等一条龙服务；预约上门

**数｜技术赋能**

- 用热力、客流数据测算需求，动态调整供给
- 多源定位交叉校验，向平台开放矢量数据
- 综合风险监测预警信息化、养老信息综合平台

**聚｜群众参与**

- 居民议事厅协商便民改造，方案及时公示
- 逐户登记摸排，把不同意的原因分类处置
- 线上问卷＋电话专线＋上门走访，形成闭环反馈
- 积分兑换、评优评先激励参与

**联｜协同联动**

- 属地街道牵头，联合城管、企业开展专项整治
- 把物业纳入应急资源调配体系，统一调派、责任到人
- 与平台签订战略合作协议，数据及时修正更新

**长｜长效机制**

- 定期评估调整、第三方评估、树立榜样社区
- 服务标准＋培训制度，防止后期服务跟不上
- 回头看、防反弹

## 十二、处置型对策：流程六步与主体搭配

**流程六步**（老旧小区、占道经营、噪音扰民等场景类题目直接套）

> **摸排**（登记意愿、分类原因）→ **沟通**（入户告知、说明影响）→ **协商**（议事厅、结果公示）→ **保障**（培训、资金、物资）→ **反馈**（问卷、专线、回访）→ **评估**（考核、动态调整）

**主体—动作表**（这张写“能写什么”，与「九、身份边界」互补）

| 主体 | 只能写这些动作 |
|---|---|
| 市政府／部门 | 编制规划、制定标准、优化审批、搭建平台、财政补贴、考核问责 |
| 街道办事处 | 摸排登记、组织协商、联合整治、日常巡查、指导培训 |
| 企业 | 报备、公示、配置设施、限时响应、主动提醒 |
| 社会组织／第三方 | 承接服务、评估、培训、公益投资 |
| 群众／志愿者 | 监督、举报、议事、志愿服务 |

**两条纪律**：问题几条就配几条对策、编号对齐；宁可把一条写具体，也不要为凑条数写空话。

## 十三、高频失分与自检（练习卷复盘）

| 病 | 判据 | 改法 |
|---|---|---|
| **序号不对应** | 问题 4 条、对策 7 条，各写各的 | 问题先编号，对策逐条挂编号；对不上＝可以不算分 |
| **问题混入原因、危害** | "起步晚""导致数据孤岛"写进问题段 | 题干只问问题时不写（见「四、问题段怎么写」）；问"原因"或"问题及原因"则分段写 |
| **不按分值分格** | 出现 1 分、1.5 分的碎对策 | 先算分值：问题 10 分／对策 20 分 → 对策 4—5 条，每条 3—4 个词组 |
| **材料对策没用足** | 自己编，材料里现成的丢了 | 现成对策先占格，反推只补缺口 |
| **越权／不可行** | "设保护月限制海外作品""指定拨款数额" | 落笔问两句：政府做得到吗？开了口子收得回吗？ |
| **格局窄** | 只会"建园＋招商""宣传传统文化" | 沿产业链铺：创作—生产—市场—评价；或上游—中游—下游 |

**障碍分三类，解法不同**（卡点先定性，再开方）

| 卡点 | 材料话术 | 解法 |
|---|---|---|
| **不愿**（意愿） | 不想共享、怕泄密、不愿改 | **刚柔并济**：合同／责任书定底线＋好处激励（订单、补贴、评优） |
| **不能**（能力资源） | 不会、缺人、缺钱、缺技术 | 投入＋培训＋引才＋技术平台，"缺什么补什么" |
| **不许**（制度） | 没规定、规定粗、规定软 | 建章立制、细化标准、加大违法成本 |

> 一句：**先分"不愿／不能／不许"，再决定是给好处、给资源、还是给规矩。**

## 十四、背诵清单

1. **十三诀**：宣 制 督 保 规 聚 数 试 联 长 改 励 防（可挂载短语与真题锚点见「5.1」）
2. **七词找点**：问题、原因、经验、教训、优势、需求＋直接对策（扫描表见「三」）
3. **三反推**：直接 → 原因 → 问题（取用顺序见「二」；国考写问题，京考不写）
4. **京考格式**：宏观对策＋意义 → 具体做法 1、2、3
5. **字数红线**：写上限的 92%–97%（400 写 370–385），低于 80% 即失分；1 点≈15–20 字
6. **分格四步**：算正文 → 定条数 → 分格 → 验算
7. **流程六步**：摸排 → 沟通 → 协商 → 保障 → 反馈 → 评估
8. **每条四有**：主体＋动词＋对象＋目的
9. **四不写**：不越权、不空喊、不复述材料、不说绝对话
10. **两硬规矩**：题干只问问题就只写现象（要原因则分段）；问题与对策序号一一对应
11. **障碍三分**：不愿（激励＋约束）、不能（资源＋能力）、不许（建章立制）
