# 公文题｜题源待考｜岩崖镇短评 · 分析

> 题目与材料：[[公文题-题源待考-岩崖镇短评-题目与材料]]　｜　方法论：[[方法论-公文题]]

## 一、三条硬要求（短评专属）

1. **每段首句是一个完整观点**，不是叙述句。
2. 这些观点要**共同支撑首段总观点**。
3. 语言要有评论味，不能写成报道复述。

## 二、课堂答案原文（`公考/素材/国考冲刺.docx` 公文题节末，逐字）

```
暗夜星空下的别样繁华

为寻求转型发展，尝试和努力发现岩崖镇的暗夜星空，为国际光学天文研究的重要基地。而来的观星旅游项目落地，也照亮了岩崖镇的转型发展之路，暗夜星空下生长出别样繁华。

多措并举保护暗夜星空，保障本镇经济发展与重大科研活动平衡。出台光学天文观测环境保护条例，进行严格划分；全域纳入保护区，规范观测基地核心区规划项目的审批、报备流程，严把项目准入关口；产业布局就要与天文观测需求相适应；组织当地商户召开座谈会并对违规者进行严肃处理；准入与预约制度，预警系统可动态调整游客数量。
```

答案止于此：**标题＋总观点段＋分观点一（保护）**，合计约 240 字，离 450 字上限还差一半。老师现场只写了「守得住」这一半，「把看星星做成产业」那一半未落笔——这才是这题真正没拷全的地方，不是整理时漏抄。

两处可直接借鉴的写法：

- 总观点用**因果链**串起来：转型寻求 → 发现暗夜星空 → 成为国际光学天文研究基地 → 观星旅游落地 → 照亮转型之路，最后收在标题「别样繁华」上；
- 分观点一的**首句是判断句**（「多措并举保护暗夜星空，保障本镇经济发展与重大科研活动平衡」），后面七个分句全是材料里的具体动作，观点与事实一分为二。

## 三、结构（450 字，按老师两段补出后两段）

```
标题：暗夜星空下的别样繁华
第一段（总观点，约 70 字）｜老师原文，见上
  因果链：寻求转型 → 暗夜星空 → 天文研究基地 → 观星旅游 → 转型之路。
第二段（分观点一 · 保护，约 170 字）｜老师原文，见上
  判断句：多措并举保护暗夜星空，保障经济与科研平衡。
  支撑：条例＋严格划分＋全域保护区＋审批报备＋项目准入＋商户座谈＋预约预警。
第三段（分观点二 · 开发，约 150 字）｜老师未写，按材料 ⑦⑧ 补
  判断句：不断开拓关联项目，才能把「看星星」做成产业。
  支撑：星轨民宿集群、无土栽培、星光合作社、观星旅游。
第四段（收束，约 50 字）｜老师未写
  转型的钥匙，往往就藏在被忽视的禀赋里。
```

> 第一段不必另起炉灶。原整理版写的「不是再造一个旧产业，而是找到别人没有的东西」是一句概括，老师原话更朴素——直接用材料里的事实链铺开，反而扣题更紧。

## 四、为什么这样分段

- 材料的做法正好两块：**保护**（守得住）＋**开发**（用得好）。两条各成一段，正好对应短评的两个分观点。
- 首段总观点要「有判断」：不是「岩崖镇转型成功」，而是「把劣势资源重新识别为优势资源」——这才叫评论。

## 五、易错

1. 段落首句写成「岩崖镇出台了条例……」——叙述句，观点丢了。
2. 通篇复述材料做法，没有一句自己的判断。
3. 忘了标题（题干已给，必须原样写）。
4. 写成推介稿（「欢迎大家来岩崖镇观星」），偏离评论立场。
5. 只写「保护」一半就收笔——老师现场犯的就是这个，240 字交了 450 字的卷。
