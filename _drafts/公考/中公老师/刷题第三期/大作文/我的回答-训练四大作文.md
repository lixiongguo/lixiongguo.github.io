# 科技创新"照亮"强国之路

党的十八大以来，以习近平同志为核心的党中央把创新作为引领发展的第一动力。科技引领着新兴产业发展，也助推了传统产业的升级，为我国的高质量发展提供了强劲的动能。但科技竞争就像短道速滑，我们在加速，人家也在加速，最后要看谁速度更快、谁的速度更能持续。为了能在科技创新的比赛中取得领先，我们需要建设重大科技创新平台，需要不断提升人才的数量和质量，需要完善的科技创新体制机制。

重大科技创新平台是科技创新可靠的支撑。重大科技创新平台集聚高端创新资源，是解决经济社会发展和国家安全的重大科技问题的物质技术基础。它们承担国家重点研发计划项目，支持顶尖科学家进行科技攻关，突破前沿基础科学问题，在重点领域实现自主可控。紫金山实验室参与主办的全球 6G 技术大会吸引了国内外国内外顶尖专家学者。为全球科技合作与协同创新"架桥铺路"，使我国能在移动通信技术领域延续 5G 领跑的优势。所以加快建设重大科技创新平台对于提高科技创新整体效能至关重要。

人才资源是科技创新最急需的资源。科技创新的竞争说到底就是人才的竞争，人才关乎到未来的发展。只有拥有足够质量和数量的人才资源才能使得国家高新技术企业和科技型中小企业如雨后春笋般涌现，发明专利的快速增长进而实现科技产业的突破，使我们在科技竞争中保持速度。Y 市经开区坚持人才引领不动摇 是 Y 市经济发展主阵地，科技创新的主战场，其，把人才和创新工作始终摆在重要议事日程常抓不懈。在新的发展阶段上只有人才才能有新的突破。经开区能有这样的成就已成为正是因为真心实意的"引才"，才让经开区在 Y 市率先实现产业高质量发展。
 
科技创新的发展不仅需要“硬件”也需要“软件”。“软件”包括体制机制与文化，党的二十大报告中提到"完善科技创新体制机制"。体制机制是科技创新的根本保障，只有完善的体制机制才能使科技创新的效率得到提升，才能使科技创新的成果得到转化。科技文化为科技创新厚植发展的沃土，通过科技文化的建设使科技创新的氛围更加浓厚。 C市通过在轨道交通站点开展公益宣传活动，讲述 C 市创新故事，弘扬科学家精神，传承科技创新的气质与精神，让科技创新在全社会蔚然成风。通过和谐的“软硬件”协同发力，共同促进科技创新的蓬勃发展。

"必须坚持科技是第一生产力，人才是第一资源，创新是第一动力"党的二十大报告中关于科技创新的表述引发了强烈的共鸣。通过不断地在科学投入，人才，体制机制与文化上下功夫,我国已在多个领域取得重大成果，进入了创新型国家行列。科技创新为我国经济实力实现历史性跃升、多项经济指标稳居世界前列提供了重要支撑，科技创新必将"照亮"强国之路。
