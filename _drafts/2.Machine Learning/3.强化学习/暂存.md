Input : 初始化策略Pi(s)
Output : 最优策略
Repeat(多轮迭代)
	策略Pi(s)从状态S0开始生成一个回合的轨迹episode=[(s0,a0,r0),(s1,a1,r1)....(st,at,rt)]
	初始化回报G=0
	for (s,a,r) in reverse(episode):
		G = r + \gamma * G 
		Q(s,a) = Q(s) + \alpha*(G - Q(s,a))
	策略提升Pi(s) = Onehot(index == argmaxQ(s,a))
