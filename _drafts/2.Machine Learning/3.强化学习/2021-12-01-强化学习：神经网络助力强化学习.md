#### 神经网络助力的强化学习

强化学习本身是一个很早就有的技术,但是之所以近年来能有如此巨大的影响主要是因为与深度神经网络的紧密结合,利用人工神经网络对于非线性函数的强大的拟合能力，极大地拓宽了强化学习的使用范围。

考虑下面的**倒立摆**问题(Cartpole)，场景模拟了一个小车和一根竖直的杆子，小车可以在水平轨道上左右移动，目标是通过控制小车的移动来保持杆子的竖直

![图片2](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/%E5%9B%BE%E7%89%872.gif)

首先对问题进行MDP建模

- **状态空间**：状态是一个包含4个连续值的向量，包括：
  - 小车位置（Cart Position）：范围为 [-4.8, 4.8]
  - 小车速度（Cart Velocity）：范围为 [-Inf, Inf]
  - 杆子角度（Pole Angle）：范围为 [-24°, 24°]
  - 杆子角速度（Pole Angular Velocity）：范围为 [-Inf, Inf]
- **动作空间**：动作是离散的，只有两个选项：
  - 0：向左移动小车
  - 1：向右移动小车
- **奖励机制**：每保持杆子竖直一帧，奖励值为1

**DQN(Deep Q-learning Network)算法**

在人工神经网络的数学理论中，**通用近似定理**（或称**万能近似定理**）指出人工神经网络近似任意函数的能力[1]。附录A是”倒立摆“问题的动力学方程,学习的过程实际上就是用神经网络(**Q网络**)来对这个动力学方程进行拟合,这个过程用数学表示如下

$Q^a_\theta(s) \to \hat Q(s,a),其中\theta是可学习的网络参数,\hat Q(s,a)是真值,a \in \{ 0,1\}$，那么就可以构建如下神经网络

![image-20250228194900867](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250228194900867.png)

```python
#代码片段3 简单Q网络(配图中展示的是4个隐藏层的网络,实际上针对倒立摆问题只要1个隐藏层就够了)
class Qnet(torch.nn.Module):
    ''' 只有一层隐藏层的Q网络 '''
    def __init__(self, state_dim, hidden_dim, action_dim):
        super(Qnet, self).__init__()
        self.fc1 = torch.nn.Linear(state_dim, hidden_dim)
        self.fc2 = torch.nn.Linear(hidden_dim, action_dim)

    def forward(self, x):
        x = F.relu(self.fc1(x))  # 隐藏层使用ReLU激活函数
        return self.fc2(x)
```

可以用Q-Learning算出来的Q值$r_{t+1}+\gamma max_aQ_\theta^a(s_{t+1})$作为真值$\hat Q(s_t,a_t)$,另外由于是连续型向量损失函数可以设为MSE均方误差

即 $Loss = (Q^a _\theta(s_t) - (r + \gamma max_aQ_\theta^a(s_{t+1}))^2$ ,这样理论上就将Q-Learning拓展到了连续空间。

```python
#代码片段4 通过梯度反向传播更新网络参数
q_values = self.q_net(states).gather(1, actions)  # Q值
max_next_q_values = self.target_q_net(next_states).max(1)[0].view(-1, 1)# 下个状态的最大Q值
q_targets = rewards + self.gamma * max_next_q_values * (1 - dones)  # TD误差目标
dqn_loss = torch.mean(F.mse_loss(q_values, q_targets))  # 均方误差损失函数
optimizer.zero_grad()  # PyTorch中默认梯度会累积,这里需要显式将梯度置为0
dqn_loss.backward()  # 反向传播更新参数
optimizer.step()
```

不过上面的思路原理上是很简单,但是工程实现上并没有那么理想,如果直接单纯地进行监督学习训练，神经网络训练是无法收敛的。

第一个问题是因为监督学习要求的训练数据满足独立同分布($i.i.d$)条件，而智能体采样的数据是有时间上的顺序关系，如果按着自然的顺利丢给网络进行训练的话，会造成网络的训练极其不稳定。

第二个问题是因为原来真值是由Q网络产生的$\hat Q(s,a)=r + \gamma max_aQ_\theta^a(s_{t+1})$,这样随着训练的进行，真值本身也在发生变化(注意到如果是表格的话就没有这个问题了),训练对象在动训练目标也同步在动，这样会使得训练的优化轨迹非常的不稳定(可见下图解释)。

DeepMind的工程师们使用了两个关键的工程技巧来解决这两个问题:回放缓存与目标网络。

第一个技巧是**回放缓存(replay buffer)**。主要是先将智能体获得的经验$(S_t,A_t,R_{t+1})$存入回放缓存中，然后从该缓存中均匀采样小批量样本用于Q函数更新。这样一方面使得数据满足独立同分布，另外一方面同一个样本$(S_t,A_t,R_{t+1})$可以复用提高了样本效率(sample efficiency,这是强化学习中一个永恒的主题)

```python
#代码片段5 回放缓存
while not done:
    action = agent.take_action(state)
    next_state, reward, done, truncated, info = env.step(action)
    #将经验保存到回放缓存中
    replay_buffer.add(state, action, reward, next_state, done)
    state = next_state
    episode_return += reward
    # 当回放缓存中数据的数量超过一定值后,才进行Q网络训练
    if replay_buffer.size() > minimal_size:
        b_s, b_a, b_r, b_ns, b_d = replay_buffer.sample(batch_size)
        transition_dict = {'states': b_s,'actions': b_a,'next_states': b_ns,'rewards': b_r,'dones': b_d}
        agent.update(transition_dict)
```

第二个技巧是**目标网络(target network)**。主要是独立一个与主网络$Q^a_\theta(s)$不一样的目标Q网络$Q^a_\mu(s)$来生成真值即令$\hat Q(s,a)=r + \gamma max_aQ_\mu^a(s_{t+1})$，这样误差就变成了 $Loss = (Q^a _\theta(s) - (r + \gamma max_aQ_\mu^a(s_{t+1}))^2$。目标网络每几步后与主Q网络进行同步。目标网络通过使用旧参数生成真值，使真值不受最新参数的影响，从而大大减少发散和震荡的情况。

```python
#代码片段6 目标网络更新(前面一段是代码片段4梯度反向传播)
def update(self, transition_dict):
    states = torch.tensor(transition_dict['states'],dtype=torch.float).to(self.device)
    actions = torch.tensor(transition_dict['actions']).view(-1, 1).to(self.device)
    rewards = torch.tensor(transition_dict['rewards'], dtype=torch.float).view(-1, 1).to(self.device)
    next_states = torch.tensor(transition_dict['next_states'],dtype=torch.float).to(self.device)
    dones = torch.tensor(transition_dict['dones'],dtype=torch.float).view(-1, 1).to(self.device)

    q_values = self.q_net(states).gather(1, actions)  # Q值
    max_next_q_values = self.target_q_net(next_states).max(1)[0].view(-1, 1)# 下个状态的最大Q值
    q_targets = rewards + self.gamma * max_next_q_values * (1 - dones)  # TD误差目标
    dqn_loss = torch.mean(F.mse_loss(q_values, q_targets))  # 均方误差损失函数
    self.optimizer.zero_grad()  # PyTorch中默认梯度会累积,这里需要显式将梯度置为0
    dqn_loss.backward()  # 反向传播更新参数
    self.optimizer.step()
	# 多步后再更新目标网络
    if self.count % self.target_update == 0:
        self.target_q_net.load_state_dict(self.q_net.state_dict())  
    self.count += 1
```

可以通过猫追老鼠的例子来直观地理解这个过程。猫是Q主网络，老鼠是Q目标网络。如果两者用同一个网络，就导致网络更新后猫和老鼠都在动，就会产生非常奇怪的优化轨迹。所以固定Q目标网络，让老鼠动得不那么频繁，可能让它每5步动一次，猫则是每一步都在动。如果老鼠每5次动一步，猫就有足够的时间来接近老鼠，它们之间的距离会随着优化过程越来越小，最后它们的轨迹就会收敛

#### AI时代的强化学习

上面无论是”迷宫“问题还是”倒立摆“问题都是人们将问题关键状态特征总结好了的。相当于是我们对原始的图像等数据进行了”精加工“，但是现实世界的很多问题是很难进行这种”精加工“的，对于有些问题我们是没有办法总结出几个关键特征的。所以需要智能体自己从原始数据中提取特征智然后再根据这些特征做决策(强化学习)。

比如下面这样的Atari视频游戏,需要智能体自己通过输入原始图像数据来学习

![image-20250305201842196](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250305201842196.png)

一般通过卷积神经网络(CNN)来对图像数据进行特征提取

```python
#代码片段6 带卷积层的Q网络(对于Atari游戏等简单低分辨率图像，仅在代码片段3中简单Q网络前加上几层卷积层即可)
class ConvolutionalQnet(torch.nn.Module):
    ''' 加入卷积层的Q网络 '''
    def __init__(self, action_dim, in_channels=4):
        super(ConvolutionalQnet, self).__init__()
        self.conv1 = torch.nn.Conv2d(in_channels, 32, kernel_size=8, stride=4)
        self.conv2 = torch.nn.Conv2d(32, 64, kernel_size=4, stride=2)
        self.conv3 = torch.nn.Conv2d(64, 64, kernel_size=3, stride=1)
        self.fc4 = torch.nn.Linear(7 * 7 * 64, 512)
        self.head = torch.nn.Linear(512, action_dim)

    def forward(self, x):
        x = x / 255
        x = F.relu(self.conv1(x))
        x = F.relu(self.conv2(x))
        x = F.relu(self.conv3(x))
        x = F.relu(self.fc4(x))
        return self.head(x)
```

对于一些比较复杂的游戏来说，只有一帧图像的信息是不足以支撑决策的,同时时序信息也很关键，这就需要用到循环神经网络(RNN)来提取时序信息的特征。

不完整信息的挑战。对于一些复杂的问题，智能体它所观测到的数据是无论是用CNN提取视觉特征还是用RNN提取时序特征，总很难确保学到的观测状态$o_t$能描述真实的环境状态$s_t$，所以并不是说用了神经网络和强化学习就一劳永逸地解决了所有问题，对于具体的现实工程问题还是需要工程师们抽象出问题具体的特征,尽可能捕获环境的状态规避掉难以处理的环境噪声确保环境的马尔可夫性。

下图是DeepMind于2015年发表在《Nature》上发表的介绍DQN那篇文章[1]的配图

![image-20250305141113541](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250305141113541.png)

图中点的颜色代表的是策略的状态价值函数$V_\pi(s)$，其值意义是”游戏结束的时候预期获得多大的奖励“。如下图中间这个游戏画面$V_\pi(s)$也许会很大，因为这时还有很多的怪兽可以击杀，所以我们会得到很高的分数。下图右边这个画面的情况我们得到的 $V_\pi(s)$可能就很小，因为剩下的怪兽也不多，并且红色的防护罩已经消失了，所以我们可能很快就会“死 掉”。因此接下来得到预期的奖励，就不会太大。

![image-20250305175820904](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250305175820904.png)

上图中展示的Landscape可以认为是一个图像数据生成的高维度的Q-table,Q网络前面架上卷积层可以将图像等高维数据映射到低维空间中。通过将这些低维空间状态可视化,我们可以直观地看到对于强化学习来说视频游戏的控制问题也就等价于高维数据空间中的”走迷宫“问题,所以近些年兴起AI技术即深度学习方法实际上就是高等数学理论中对高维空间数据的处理方法的应用。
