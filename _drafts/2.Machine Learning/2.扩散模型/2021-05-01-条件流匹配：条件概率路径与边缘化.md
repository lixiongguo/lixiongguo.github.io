> 本文是 Flow Matching 系列的第三篇，深入讨论 Flow Matching 的核心理论创新——条件概率路径与边缘化。建议先阅读第二篇：Flow Matching 训练方法。

## 1. 条件概率路径与边缘化

### 1.1 问题：直接训练的不可行性

直接进行训练的问题：

![image-20250709202537312](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709202537312.png)

> Flow Matching 目标本身很简洁，但朴素地使用时是不可行的——因为我们不知道合适的 $p_t$ 和 $u_t$ 是什么。虽然有很多概率路径可以满足 $p_1(x) \sim q(x)$，但更重要的是，我们通常无法获得一个闭式解 $u_t$ 来生成期望的 $p_t$。接下来我们展示如何通过**仅按样本定义**的概率路径和向量场，再通过适当的聚合方法来构造所需的 $p_t$ 和 $u_t$，从而得到一个更可行的训练目标。

### 1.2 构造条件概率路径

我们通过对所有的点进行建模**条件概率路径**（基于指定点的高斯分布）并进行混合，从而建模复杂的概率路径：

![image-20250709202710341](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709202710341.png)

> 一种构造目标概率路径的简单方法：对给定的特定数据样本 $x_1$，定义条件概率路径 $p_t(x|x_1)$，满足 $p_0(x|x_1) = p_0(x)$，且 $p_1(x|x_1)$ 为集中在 $x_1$ 附近的分布（如 $\mathcal{N}(x|x_1, \sigma^2 I)$，以 $x_1$ 为均值、具有充分小标准差 $\sigma > 0$ 的正态分布）。

$$p_t(x|x_1),\quad p_0(x|x_1) = p_0(x),\quad p_1(x|x_1) = \mathcal{N}(x|x_1, \sigma^2 I)$$

### 1.3 边缘化

然后通过对条件路径进行边缘化就能得到目标概率路径 $p_t(x)$：

![image-20250709203550588](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709203550588.png)

> 将条件概率路径沿 $q(x_1)$ 边缘化，即得到边缘概率路径：

$$p_t(x) = \int p_t(x|x_1) \, q(x_1) \, dx_1$$

由于混合高斯的特性：

![image-20250709203625191](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709203625191.png)

我们对向量场进行边缘化：

![image-20250709203747251](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709203747251.png)

> 条件向量场（生成条件概率路径的 VF）与边缘向量场（生成边缘概率路径的 VF）之间存在重要联系，这一联系使我们可以将未知且不可解的边缘 VF 分解为更简单的条件 VF。

$$u_t(x) = \int u_t(x|x_1) \frac{p_t(x|x_1) q(x_1)}{p_t(x)} \, dx_1$$

![image-20250709203813451](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709203813451.png)

### 1.4 中心定理

**中心定理**：经过边缘化的向量场 $u_t$ 可以边缘化 $p_t$：

![image-20250709203849550](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709203849550.png)

> 边缘向量场 $u_t$（由条件 VF 按上式聚合）生成边缘概率路径 $p_t$，即 $u_t$ 和 $p_t$ 满足连续性方程。

通过将边缘概率分解为一系列条件概率从而求解：

![image-20250709210033692](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709210033692.png)

> **定理 1**：给定生成条件概率路径 $p_t(x|x_1)$ 的条件向量场 $u_t(x|x_1)$，对任意分布 $q(x_1)$，按上式聚合得到的边缘向量场 $u_t$ 生成边缘概率路径 $p_t$。即 $u_t$ 和 $p_t$ 满足连续性方程。

## 2. 条件流匹配（CFM）

### 2.1 CFM 目标

$u_t$ 还是不可求解的，所以如果作为目标的话还是没办法进行训练，所以我们只匹配条件 $u_t$，并且可以证明的是这两者是等价的。

![image-20250709210142893](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709210142893.png)

![image-20250709204023733](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709204023733.png)

> 考虑条件流匹配（CFM）目标，其中 $t \sim \mathcal{U}[0, 1]$，$x_1 \sim q(x_1)$，$x \sim p_t(\cdot|x_1)$。与 FM 目标不同，CFM 目标允许我们轻松采样无偏估计——只需能从条件路径 $p_t(\cdot|x_1)$ 中采样并计算 $u_t(\cdot|x_1)$ 即可，因为它们都是按样本定义的。**核心观察**：FM 和 CFM 目标关于 $\theta$ 的梯度相同。

$$\mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t, q(x_1), p_t(x|x_1)} \| v_t(x; \theta) - u_t(x|x_1) \|^2$$

其中 $t \sim \mathcal{U}[0, 1]$，$x_1 \sim q(x_1)$，$x \sim p_t(\cdot|x_1)$。

### 2.2 梯度等价性（定理 2）

两个损失的梯度是一致的：

![image-20250709204540895](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709204540895.png)

> **定理 2**：假设对所有 $x \in \mathbb{R}^d$ 和 $t \in [0, 1]$ 有 $p_t(x) > 0$，则 $\mathcal{L}_{\text{FM}}$ 与 $\mathcal{L}_{\text{CFM}}$ 相差一个与 $\theta$ 无关的常数。因此 $\nabla_\theta \mathcal{L}_{\text{FM}}(\theta) = \nabla_\theta \mathcal{L}_{\text{CFM}}(\theta)$。

$$\nabla_\theta \mathcal{L}_{\text{FM}}(\theta) = \nabla_\theta \mathcal{L}_{\text{CFM}}(\theta)$$

### 2.3 高斯条件概率路径

用高斯条件概率路径来表征基础的条件概率：

![image-20250709204311551](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709204311551.png)

> CFM 目标适用于任意条件概率路径和条件向量场。此处讨论高斯形式 $p_t(x|x_1) = \mathcal{N}(x|\mu_t(x_1), \sigma_t(x_1)^2 I)$ 的构造。

$$p_t(x|x_1) = \mathcal{N}(x \,|\, \mu_t(x_1), \sigma_t(x_1)^2 I)$$

并进一步有：

![image-20250709210405474](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709210405474.png)

> 通过仿射变换 $\psi_t(x) = \sigma_t(x_1)x + \mu_t(x_1)$ 将标准高斯映射到均值为 $\mu_t$、方差为 $\sigma_t^2$ 的高斯。利用重参数化技巧代入 CFM 损失。

$$\psi_t(x) = \sigma_t(x_1) x + \mu_t(x_1)$$

### 2.4 条件向量场（定理 3）

从而对于简单的高斯概率路径能证明：

![image-20250709204342873](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250709204342873.png)

> **定理 3**：设 $p_t(x|x_1)$ 为高斯条件概率路径，$\psi_t$ 为其流映射。则唯一确定该流的向量场为 $u_t(x|x_1) = \frac{\sigma_t'(x_1)}{\sigma_t(x_1)}(x - \mu_t(x_1)) + \mu_t'(x_1)$。

$$u_t(x|x_1) = \frac{\sigma_t'(x_1)}{\sigma_t(x_1)}(x - \mu_t(x_1)) + \mu_t'(x_1)$$
