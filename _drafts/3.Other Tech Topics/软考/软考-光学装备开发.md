# 论光学测量装备配套软件的架构设计与关键技术——以干涉测量与超快脉冲诊断为例

## 摘要

光学测量装备的价值不仅取决于光路与硬件，更取决于配套分析软件能否把原始干涉图、光谱图稳定地变成可复用的工程指标。我所在单位在超快激光与精密光学相关课题中，陆续开发了迈克尔逊干涉仪面型分析软件、二维光谱剪切干涉仪（2DSI）软硬件一体化系统，以及光谱分析类工具。我在项目中担任系统架构师与核心开发，负责总体软件架构、算法流水线设计和跨平台交付。针对干涉条纹相位不连续、超短脉冲相位难以直接读取、以及科研现场跨操作系统部署等难点，我们采用"采集驱动—预处理—核心反演—结果可视化与导出"分层架构：迈克尔逊侧完成 ROI 滤波、相位解包裹与 Zernike 拟合；2DSI 侧完成光谱剪切干涉数据重建与脉宽诊断，并与 SPIDER 等商用手段交叉验证。系统交付后，凸面镜片面型与 PV 值可在软件内闭环监测，2DSI 在多种光源上与 SPIDER 结果基本一致，设备占地约 A4 大小，刷新率可达 0.1–5Hz。本文结合上述项目，论述光学装备工具软件的设计方法。

## 正文

### 一、项目背景

超快激光与精密光学加工场景中，日常最依赖三类测量能力：光谱形态分析、干涉面型检测，以及飞秒量级脉冲的时域诊断。传统做法往往是一台商用仪器配一套封闭软件：数据格式不开放、算法不可定制、Windows 与 Linux 现场混用时部署困难，课题之间也难以复用同一套处理流水线。

单位相关课题因此提出自研光学装备工具的需求，目标不是简单画曲线，而是把测量链路软件化、模块化，形成可对接硬件的分析平台。我负责的工作主要包括三项：一是迈克尔逊干涉仪分析软件，根据干涉条纹图像计算凸面镜片的 Zernike 拟合系数，监测面型与 PV 值；二是一体化二维光谱剪切干涉仪（2DSI）的配套软件与模块化硬件协同；三是光谱分析相关工具，为激光器调试与脉冲诊断提供统一的光谱观测与特征提取能力。项目来源包括课题类任务，迈克尔逊软件对接同事为潘江帆等人。界面与跨平台需求明确采用 Qt，以同时支持 Windows 与 Linux。

### 二、总体架构设计

三类工具业务不同，但软件结构可以统一。我把系统划分为四层。

设备与数据接入层负责相机、光谱仪、采集卡或仪器 SDK 的封装，对上只暴露统一的帧/光谱流与参数配置接口，屏蔽厂商差异。预处理层负责 ROI 裁剪、去噪、FFT 滤波、暗场与归一化等与物理量无关的图像/信号整理。核心反演层是业务差异最大的部分：迈克尔逊走相位解包裹与 Zernike 拟合，2DSI 走二维光谱剪切干涉重建与脉宽估计，光谱分析走峰值、带宽、边带等特征计算。应用与交互层用 Qt 提供实时预览、参数调节、结果曲线、报告导出和跨平台安装包。

这样分层之后，算法同学可以独立替换解包裹或拟合模块，硬件变更只影响接入层，界面也不必随算法频繁改动，满足科研软件"实验迭代快、交付要稳"的要求。

### 三、迈克尔逊干涉仪分析软件

该软件的目标明确：从干涉条纹图像得到面型信息，再输出 Zernike 系数与 PV 等工程指标，用于凸面镜片面型监测。处理流程固定为三步：预处理、相位解包裹、计算 Zernike 系数。

预处理阶段，操作人员在界面框选 ROI，对区域做 FFT，选取其中高频分量滤波，再经逆 FFT 得到相位图。这样可以把载波干涉信息从背景中分离出来，得到后续计算所需的包裹相位。

相位解包裹是核心难点。实测相位超过 2π 后会被折叠回 (−π, π)，形成截断与跳变。一维情况下，最直接的做法是沿扫描方向检测相邻点的相位差，一旦出现接近 ±2π 的跃变就进行补偿，把折叠相位恢复成连续相位。二维干涉图则在此基础上沿行、列或质量引导路径扩展，避免噪声引起的残差点把误差传播到整个面。解包裹质量直接决定面型是否可信，因此软件在界面上保留中间相位图，方便人工核对。

得到连续相位后，进行 Zernike 多项式拟合。Zernike 多项式是光学中常用的正交基底，其系数可解释为离焦、像散、彗差等波前像差成分，也便于与加工、装调环节沟通。拟合结果同时给出面型重建与 PV 值，形成从条纹图像到可量化指标的闭环。软件基于 Qt 开发，可在 Windows 与 Linux 上部署，满足课题组不同实验平台的使用习惯。

### 四、二维光谱剪切干涉仪（2DSI）工具

飞秒、少周期脉冲的完整表征需要光谱相位，不能只看强度自相关。2DSI（Two-Dimensional Spectral Shearing Interferometer，二维光谱剪切干涉仪）用光谱剪切干涉的方式获取相位信息，再重建脉冲时域形态。我们做的是模块化硬件与配套软件一体化方案，软硬件专利当时处于撰写阶段，目标是做出体积小、可现场使用的诊断装备，而不是只能放在光学平台上的实验原型。

性能指标方面，系统面向傅里叶极限脉宽约 5–30fs、脉冲能量约 2–10μJ、水平偏振输入的光源；光谱测量带宽约 600–1050nm；脉宽测量刷新率约 0.1–5Hz；供电为 AC 100–240V，外形约 W210×L297×H207mm，占地接近 A4，便于搬移与集成。

软件侧同样遵循"采集—预处理—反演—显示"流水线：实时读取干涉光谱数据，完成剪切量相关标定与相位重建，输出光谱相位、重建脉冲波形与脉宽等结果，并支持与历史测量对比。为验证准确性，我们在多种光源上与 SPIDER 结果对照，例如 OPCPA 样本上 SPIDER 与 2DSI 分别约为 9.2fs/10.5fs、11.1fs/11.0fs；Coherent Astrella 上约为 61.2fs/63.3fs；气芯光纤与 Venteon CEP5 等光源上也给出了可比对的测量结果。整体表明，在目标参数范围内，自研 2DSI 可以达到接近商用诊断手段的可用性，同时具备更紧凑的形态与可定制的软件接口。

### 五、光谱分析工具与系统协同

光谱分析仪相关工具承担两类角色。一是作为独立观测软件，完成光谱采集、平滑、峰值/带宽提取、数据存档；二是作为上游公共能力，为 2DSI、锁模调试等系统提供统一光谱数据格式与预处理组件。把光谱工具抽成公共模块后，迈克尔逊与 2DSI 不必各自重复实现相机/光谱仪驱动和基础绘图控件，降低了维护成本。

在架构上，三类工具共享接入层与 Qt 界面框架，差异集中在核心反演插件。后续若增加新的干涉或脉冲诊断算法，只需按同一接口注册新模块，不必重做整套软件。

### 六、实施效果与不足

迈克尔逊分析软件交付后，课题方可在实验现场直接完成条纹采集、解包裹、Zernike 拟合与 PV 监测，减少了导出到第三方脚本反复处理的环节。2DSI 一体化系统在多种超快光源上完成了与 SPIDER 的对比验证，体积与刷新率满足桌面化使用需求，形成了可演示、可交付的软硬件样机。光谱工具则成为后续激光相关项目可复用的基础组件。

不足主要有两点。一是相位解包裹在条纹对比度低、噪声大的区域仍可能出现残差传播，后续可引入质量图引导或深度学习辅助解包裹。二是 2DSI 与 SPIDER 在个别光源上仍有偏差，需要继续完善剪切量标定、色散补偿与软件自动判读，减少对人工经验的依赖。

通过这些光学装备工具的开发，我体会到：光学测量软件的关键往往不在界面，而在于把物理测量流程沉淀为稳定、可验证、可跨平台交付的算法流水线，并用分层架构把硬件差异与核心反演隔离开，才能在科研迭代中持续演进。
