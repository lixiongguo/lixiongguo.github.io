## 《沟通的方法》（脱不花）笔记

来源：脱不花《沟通的方法》。作者是得到 App 联合创始人与 CEO，本书是得到「职场四大名著」的第一本（后续为写作、表达、执行）。华为 iLearning 上的沟通课大量取材于这类内容，可对照看。

### 主旨：沟通是一场「无限游戏」

借自詹姆斯·卡斯《有限与无限的游戏》：有限游戏有边界、分胜负；无限游戏无边界、不封顶、不对立，以**可持续**为目的。沟通属于后者——目的不是赢下这一局、把话说完，而是把更多**建设性关系**连进自己的生命之网，让这张网持续生长，最终完成**自我塑造**。

三条落点：

- 沟通的起点是**倾听**（不是能说会道）；
- 沟通的终点是**行动**（不能导向行动的话等于没说）；
- 中间是**关系**（一次次把关系账户存进去）。

### 骨架：6 部分 24 讲

| 部分 | 主题 | 各讲 |
|---|---|---|
| 一 | 从倾听开始，全力以赴地沟通 | 先听再说（结构化倾听）、听话听音（四种沟通风格）、积极回应 |
| 二 | 掌握三大原则，不犯低级错误 | 开放性、目标感、建设性 |
| 三 | 让人「如沐春风」 | 破冰、赞美、激励、说服、辅导、安慰 |
| 四 | 让人按你的期待去做 | 批评、提意见、绩效面谈、主持会议 |
| 五 | 变被动为主动 | 道歉、调解、求助、拒绝 |
| 六 | 让自己发光 | 即兴发言、闲谈、汇报（提案）、竞聘 |

### 公式速查表

书的骨架基本就是这张表，遇到具体场景直接查对应行。

| 场景 | 公式 |
|---|---|
| 开放性 | 扩大共识 + 消除盲区 |
| 目标感 | 方案力（"我们有个目标要达成，对此我有一个方案"） |
| 建设性 | 可执行的最小化行动 + 可持续的行动阶梯 + 每个节点的即时反馈 |
| 破冰 | 双线卡位 + 展现关切 + 营造掌控 |
| 赞美 | 打追光 + 轻轻地 + 深深地 + 常常地 |
| 激励 | 及时赞美 + 行为建模 + 反馈闭环 |
| 说服 | 说话有分量 + 凿穿心理防线（"成功的说服是不说服"） |
| 辅导 | 植入目标 + 发现盲区 + 实战演习 |
| 安慰 | 轻度介入 + 提供支持 |
| 批评 | 控制环境 + 定义问题 + 刷新动作 + 设定反馈点 + 完成重启 |
| 提意见 | 事前征求同意 + 定义双方关系 + 提供具体建议 |
| 绩效面谈 | 营造正式感 + 换框架 |
| 主持会议 | 行为设计 + 全程控场（做"牧羊人"，不做主持人） |
| 道歉 | 关闭过去 + 承诺未来 |
| 调解矛盾 | 处理情绪 + 重建目标 + 最小改善 |
| 求助 | 别人帮得了 + 自己值得帮 |
| 拒绝 | 开门见山 + 移花接木（技巧：Yes, if） |
| 即兴发言 | 万能开头 + 谈感受 / 谈行动 |
| 闲谈 | 传递尊重 + 传递价值 |
| 提案（汇报） | 融目标 + 抢进度 + 提诉求 |
| 竞聘 | 肯定现有战场 + 我的独特打法 + 我的充分准备 |

### 三个贯穿全书的基本功

**1. 结构化倾听：三个框 + 反向叙述**

听到的每段话都拆成三个框：

- **情绪**：对方在什么情绪里（先接住，再讲事）；
- **事实**：不带评价的客观信息（谁、何时、做了什么）；
- **期待**：对方真正想要什么，常常没说出口。

回应按三步走：**响应情绪 → 确认事实 → 明确行动**。这也是"领导问你忙不忙"这类试探性问句的标准解法。

**2. 读懂沟通风格：老虎 / 孔雀 / 猫头鹰 / 考拉**

| 类型 | 特征 | 沟通要点 |
|---|---|---|
| 老虎 | 强势、掌控欲强、目标导向 | 不做铺垫、直切主题；定期给进度，别让他觉得是黑箱；他假客气时追问真实意图 |
| 孔雀 | 表现型、自来熟、对感受敏感 | 给舞台、多赞美；不聊任务聊感受，"人人都需要被看见" |
| 猫头鹰 | 谨慎、要证据、爱提负面反馈 | 主动提供事实与方案；他挑刺往往是在收集决策依据，不是针对人 |
| 考拉 | 温和、被动、"都行" | 给缓冲时间、别施压；适合做助手类角色，决策场景要主动替他推进 |

识别风格不是为了贴标签，而是为了**调整自己的节奏**——同一句话对不同风格的人效果完全不同。

**3. 接住不友好的沟通：四换**

- **换口径**：把对方的攻击性话题置换掉（"我就佩服您这种业务大拿"）；最见效，但最容易被看成抖机灵，**慎用**；
- **换时间**：不当场应答，把被动变主动（"这么重要的事让我想想，下周一我来汇报"），极端情况可用"一分钟暂停法"；
- **换场合**：一对一的冲突不搬到会上，公开的表扬不缩到私下；
- **换角色**：自己不适合当这个角色时，把角色转移出去（"这事有比我更懂行的同事"）。

### 几个值得单独记的点

- **目标感 = 方案力**：目标感强不是把"我要"挂在嘴边，而是能拿出让对方"无法拒绝的方案"。找不到目标时，问自己"这次沟通完了，我要对方做什么"。
- **建设性从小处起**：没有决策权也能有建设性——"来，你们说，我在白板上记录"就是当下可执行的最小化行动。
- **赞美照亮行为，不照亮禀赋**：夸"你这次的方案思路很清晰"比夸"你真聪明"有效，因为前者可复制、可努力。
- **道歉不是解释**：关闭过去（认错、不辩解）+ 承诺未来（给出具体的改法），解释越多越像推责任。
- **拒绝要整块地拒绝**：开门见山表明立场、给一个真理由、再给替代方案（Yes, if）——最伤人的是拖延和含糊。
- **闲谈不是闲扯**：目的是传递尊重（上个请教）与传递价值（多给一点），有四招：上个请教、多给一点、深度破冰、管理人设。

### 定位与局限

- 优点：**场景索引式**工具书，拿来即用；道歉、拒绝、批评这类"难开口"场景写得最扎实；每讲结构固定（问题清单 → 案例 → 公式 → 动作要领 → 划重点）。
- 局限：偏职场与个体人际操作层面，几乎不涉及跨文化沟通、群体沟通与结构性冲突；方法多，需要挑 2–3 个反复练，否则只是"知道"。

### 练习清单（自用）

- [ ] 每次开会前写一句"这次我要对方做什么"（目标感）
- [ ] 每周挑一次对话，练习"情绪 → 事实 → 期待"的拆解
- [ ] 挑一个最怕的场景（拒绝 / 提意见 / 绩效面谈），把公式抄在便签上，用满三次再回来改
