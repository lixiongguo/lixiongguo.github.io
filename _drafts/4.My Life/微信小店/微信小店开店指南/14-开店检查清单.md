# 第 14 章　开店检查清单

> 可直接打印或复制到备忘录，按阶段逐项打勾。全部打勾再往下走。

---

## 阶段一：开店前

- [ ] 确定主体类型（企业／个体户）
- [ ] 营业执照状态正常、经营范围覆盖商品
- [ ] 备齐法人证件、管理员实名微信、结算账户
- [ ] 证件照为清晰彩色原件或扫描件（非截图、非翻拍）
- [ ] 查清商品类目与所需资质
- [ ] 确认类目是否支持零保证金
- [ ] 确认类目是否支持个体户（部分定向类目不支持）
- [ ] 想清楚谁发货（自囤／代发／混合）
- [ ] 想清楚第一条流量渠道

---

## 阶段二：入驻中

- [ ] 微信搜索「微信小店开店」进入入驻页
- [ ] 选择正确的店铺类型（选错不可改）
- [ ] 填写资料并上传清晰证件
- [ ] 结算账户开户名与执照主体名称一字不差
- [ ] 超管本人完成人脸识别
- [ ] 填写店铺名称（无极限词）、上传头像、写简介
- [ ] 提交审核并跟踪进度
- [ ] 审核通过后完成账户验证与签约

**等待期间并行完成：**

- [ ] 拍好商品主图与详情图
- [ ] 写好商品标题与详情文案
- [ ] 联系快递、确定运费方案

---

## 阶段三：开卖前

- [ ] 申请商品类目并通过审核
- [ ] 申请新商权益（零保证金 / 1% 费率 / 成长卡 / 运费险券）
- [ ] 绑定视频号／公众号／企业微信
- [ ] 完成店铺装修（海报、简介）
- [ ] 设置客服自动回复（发货时效、退换货、尺码咨询）
- [ ] 配置运费模板（含偏远地区策略）
- [ ] 填写退货地址与联系人
- [ ] 上架商品（主图、详情、规格、库存）
- [ ] 检查标题无极限词、类目无错放
- [ ] 1 分钱测试支付与订单状态流转
- [ ] 测试一次退款流程
- [ ] 正式开卖

---

## 阶段四：日常运营

**每天**

- [ ] 处理待发货订单
- [ ] 处理售后退款
- [ ] 检查库存、补货或下架缺货商品
- [ ] 查看昨日销售数据
- [ ] 回复顾客咨询
- [ ] 发布 1 条内容

**每周**

- [ ] 复盘热销／滞销款
- [ ] 优化主图与标题
- [ ] 补充内容素材
- [ ] 核对库存周转

**每月**

- [ ] 对账（结算基数、费率、实际到账）
- [ ] 算真实毛利
- [ ] 清理长期滞销品
- [ ] 检查证件有效期
- [ ] 查看平台公告与规则更新

---

## 红线复核（每次上新前过一遍）

- [ ] 经营范围覆盖
- [ ] 特殊类目资质有效
- [ ] 无极限词／虚假宣传
- [ ] 无医疗功效表述
- [ ] 价格表述有真实依据
- [ ] 品牌授权链完整
- [ ] 非禁售／限售商品
- [ ] 图片无盗图、无水印
