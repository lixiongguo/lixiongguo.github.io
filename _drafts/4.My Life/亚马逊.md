# 亚马逊

## 海外仓

海外仓是卖家在目标销售国（或邻近国家）预先租用或自建的仓库。货物先批量运到当地入库，买家下单后再从当地发货，而不是每单都从中国直发。

在亚马逊跨境卖货里，它和 FBA（亚马逊运营中心）是两条不同的路：

| | 海外仓（第三方或自建） | FBA |
|---|---|---|
| 仓库归属 | 卖家自己租仓，或交给海外仓服务商 | 亚马逊的运营中心 |
| 谁发货 | 卖家或仓服务商 | 亚马逊 |
| 常见用途 | 多平台同时卖、大件、退货处理、备货灵活 | 主要服务亚马逊订单，可带 Prime 标识 |

典型流程：国内备货 → 海运或空运到海外仓 → 上架入库 → 订单下来后当地打包发出。买家收到货的时间和本地购物接近，物流成本也通常低于单件国际小包。

卖家用海外仓，主要是为了缩短配送时间、降低单件运费、方便处理退货，以及在亚马逊之外的独立站、eBay、沃尔玛等渠道共用同一批库存。代价是要提前压库存、付仓储费，还要自己管补货和滞销。

## ROI

ROI（Return on Investment，投资回报率）衡量的是：投入一笔成本，最终赚回多少。亚马逊选品和算账时，它和毛利率不是同一个数。

- **毛利率** = 利润 / 销售额。看售价里有多少是赚的。
- **ROI** = 利润 / 投入成本。看压出去的钱翻了多少。

利润要先扣完再算，常见扣项：采购、头程、关税、平台佣金、FBA 配送费或海外仓操作费、仓储、广告、退货损耗、促销和优惠券。欧洲站还要单独算 VAT。

业内有两种分母，算之前先说清用哪一种：

| | 分母用采购成本 | 分母用全部投入 |
|---|---|---|
| 公式 | 利润 / 采购成本 | 利润 /（采购 + 头程 + 平台费 + 广告等） |
| 看到的数 | 偏高，方便选品时横向比货 | 更接近这笔钱的真实回报 |
| 适合 | 同一条头程、同一站点下比较产品 | 决定要不要压这一批库存 |

举例：售价 30 美元。采购 6、头程 2、佣金 4.5、FBA 5、广告摊到每单 3、退货损耗 0.5。成本合计 21，利润 9。

- 按采购成本：ROI = 9 / 6 = 150%
- 按全部投入：ROI = 9 / 21 ≈ 43%

两个数都对，口径不同，不能拿去和别人的数直接比。

广告指标只覆盖广告这一段，不能代替 ROI：

| 指标 | 公式 | 看什么 |
|---|---|---|
| ACOS | 广告花费 / 广告销售额 | 广告花得赚不赚 |
| ROAS | 广告销售额 / 广告花费 | ACOS 的倒数 |
| TACOS | 广告花费 / 总销售额 | 广告在整店销售里占多重 |
| ROI | 利润 / 投入成本 | 这单生意整体赚没赚 |

同样的 ROI，库存转得越快，同一笔钱一年能做的轮次越多。看一款产品值不值得做，要把单次 ROI 和周转一起看，不要只盯一个百分比。新品期广告会把 ROI 打低，试销阶段和稳定出单阶段要分开记。

## Listing（商品详情页）

Listing 就是亚马逊上的商品详情页——买家搜索后点进来看到的那个页面。每上架一个商品，亚马逊就为它生成一条独立的销售页面，这条页面就叫一个 listing，通常对应一个 ASIN（父子变体共用同一个 listing 页面，买家在页面内切换变体）。

一个 listing 从上到下的组成部分：

| 部分 | 作用 | 要点 |
|---|---|---|
| 标题（Title） | 权重最高的关键词位 | 品牌 + 核心词 + 卖点 + 规格，200 字符内 |
| 主图 | 点击率的第一决定因素 | 白底、纯商品，1000px 以上可放大 |
| 副图 | 场景图、功能图、尺寸图，代替销售员说话 | 通常 6–9 张 |
| 价格 | 转化率的敏感变量，影响购物车归属 | 可设优惠价、优惠券 |
| 五点描述（Bullet Points） | 逐条讲卖点、规格、售后 | 5 条，每条一个卖点 |
| A+ 页面 | 图文长描述，提升转化 5–10% | 需品牌备案 |
| 评论与星级 | 信任背书，转化率的最大变量之一 | 不可操控，只能合规获取（Vine 等） |
| 问答（Q&A） | 补充详情页没讲到的疑虑 | — |
| 后台搜索词 | 买家看不到，给搜索算法看的关键词 | 250 字节左右 |

广告前先优化 listing。广告链条是：出价 → 点击 → 详情页 → 转化 → 订单，listing 决定中间的转化率这一环。转化率从 10% 提到 20%，等于所有关键词的 CPC 打五折——这就是「listing 决定 ACOS 下限」的意思。广告只是把人带到门口，留不留得住是 listing 的事；转化率差的页面灌广告流量，等于花钱交学费。

类比：把亚马逊想成巨型商场。广告（SP/SB）是商场电梯口的海报位，负责把人带到店门口；listing 是店面本身——门头（标题+主图）、橱窗（副图）、导购话术（五点描述）、装修（A+）、口碑（评论）；ASIN 是门牌号。海报打得再凶，店面破烂，客人进门就走，海报费全是白花。站外的内容是视频，站内的内容就是 listing。
