### 总结

| 特性             | 欧氏空间           | 双曲空间                 |
| :--------------- | :----------------- | :----------------------- |
| **曲率**         | $K = 0$            | $K = -1$（常负）         |
| **体积增长**     | 多项式（$O(r^n)$） | 指数（$O(e^{(n-1)r})$）  |
| **适合数据**     | 相对均匀分布的数据 | 层次化/树形结构数据      |
| **平行线**       | 过一点只有一条     | 过一点有无穷多条         |
| **三角形内角和** | $= 180°$           | $< 180°$                 |
| **异常检测优势** | 特征变形大         | 层次结构保持好           |
| **可视化**       | 直观               | 需要模型（如庞加莱圆盘） |
