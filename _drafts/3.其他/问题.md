### 问题一：CETM 的能量泛函与 Circle Patterns 的能量泛函形式相似但又有差异，这些奇怪的表达式是如何推导出来的？它们与双曲几何有何联系？

#### CETM 能量泛函的推导

CETM 的本质起点是**共形等价的度量缩放**：

$$
\tilde{l}_{ij} = l_{ij} \cdot e^{(u_i + u_j)/2}
$$

取对数边长 $\tilde{\lambda}_{ij} = 2\log \tilde{l}_{ij}$，有 $\tilde{\lambda}_{ij} = \lambda_{ij} + u_i + u_j$。然后这个"新三角形"的三边 $\{\tilde{\lambda}_{ij}\}$ 通过余弦定理确定三个对角 $\{\tilde{\alpha}^i_{jk}\}$。CETM 将 Yamabe 方程 $\Delta u = -K$ 转化为**对偶形式**：令能量梯度等于 $(\widehat{\Theta}_i - \sum \tilde{\alpha}^i_{jk})/2$ 为零。这里能量的"原函数"必须包含 Lobachevsky 函数 $\Pi(\alpha)$，因为 $\Pi'(\theta) = -\log(2\sin\theta)$ 恰好出现在对数边长的梯度链中。

推导的关键链接是 **Milnor 定理**：$\sum_i \Pi(\alpha_i) = \text{Vol}(四面体)$（即一个双曲四面体的体积等于其六个二面角对应的 Lobachevsky 函数值之和）。

#### Circle Patterns 能量的推导

Circle Patterns 能量也可以从同样的"体积原理"推导，但几何单元不同：CETM 是三角形 → 双曲四面体（顶点 + 无穷远点），Circle Patterns 是 Kite 四边形 → 双曲四面体。两者的能量都是"所有双曲四面体体积之和"，区别在于组合拓扑的分割方式。

#### 代码实现对照

在代码 `CirclePatternsWasm.cpp` 中，`ImLi2SumWasm` 函数正是 Lobachevsky 函数的积分版本：

```cpp
double ImLi2SumWasm(double dp, double theta) {
    double tStar = M_PI - theta;
    double x = 2.0 * atan(tanh(0.5 * dp) * tan(0.5 * tStar));
    return x * dp + Cl2(x + tStar) + Cl2(-x + tStar) - Cl2(2.0 * tStar);
}
```

这是 **Bobenko-Springborn 变分原理**的数值实现——通过 Clausen 积分 $Cl_2$ 的 Chebyshev 级数展开来计算 Lobachevsky 函数积分。而 CETM 代码中 Lobachevsky 函数的恒等式为：

```cpp
double lobachevsky(double a) {
    return Cl2(2*a)/2;
}
```

即 $\Pi(\theta) = Cl_2(2\theta)/2$。

#### 深层联系：统一的离散共形变分原理

CETM、Ricci 流和 Circle Patterns 三者都可以归入**"离散共形变分原理"（Discrete Conformal Variational Principle）**，形式为：

$$
E(\text{metric}) = \text{Volume}(\text{双曲多面体}) + \text{线性项}
$$

其中线性项来自曲率目标约束（通过 Lagrange 乘子法引入）。具体而言：
- CETM 的度量变量是**边长度量**的共形缩放（$u_i$ 是顶点上的标量）
- Ricci 流的度量变量是**圆填充度量**的半径（$r_i$ 是顶点上的标量）
- Circle Patterns 的度量变量是**面半径的圆填充度量**（$r_f$ 是面上的标量）

三者的优化 landscape 都"继承"了双曲几何中理想多面体体积的凸性——这是 Rivin 定理和 Bobenko-Springborn 变分原理的核心贡献。

## 具有洞见的新问题与解答

### 新问题 1：为什么 CETM 的 Hessian 恰好是 cot-Laplacian？这说明了 CETM 与调和映射之间的什么深层联系？

**解答**：CETM 能量关于 $u$ 的二阶导数计算中得到：

$$
\frac{\partial^2 E}{\partial u_i \partial u_j} \propto \cot\tilde{\alpha}_{ij}^k + \cot\tilde{\alpha}_{ij}^l
$$

这正是 **cot-Laplacian** 的权重。这意味着 CETM 的牛顿方向等价于在当前度量下求解 Laplace 方程——**CETM 本质上是将非线性 Yamabe 问题"线性化"为一系列调和映射迭代**。几何上，这说明 CETM 的每一步都在"用当前度量定义的调和函数来逼近共形映射"。这个洞察可以统一理解 CETM、Ricci 流（其 Hessian 同样是 cot-Laplacian）和 LSCM（其法方程等价于解 Laplace 方程）——它们共享同一个数值骨架。

### 新问题 2：Circle Patterns 的 WASM 实现使用了 `computeAnglesDirect()` 替代了 Mosek QP 求解。这种简化的理论代价是什么？什么情况下会失效？

**解答**：`computeAnglesDirect()` 直接将原始角度 clamp 为正数并做 Delaunay 钳制。理论上的代价是：

1. **失去了最优性**：Mosek QP 求解的是在 Coherent Angle System 约束下**最小化与原始角度的二范数距离**，而直接 clamp 只是在每个边局部处理，不保证全局最优
2. **不满足 vertex sum 约束**：直接 clamp 不能保证每个内部顶点的周围角度和为 $2\pi$。代码中通过变分能量的 saddle point 条件 $\nabla E_i = 0$（即 $K_i = 0$）来纠正这一点
3. **失效场景**：当原始网格严重偏离 Delaunay 条件（大量 $\alpha_{ij}^k + \alpha_{ij}^l > \pi$），直接 clamp 会大幅修改角度，导致原始几何信息丢失严重

**补救建议**：在 WASM 版本中增加一个"原始角度的 coherence 度量"，当 coherence 低于阈值时提示用户结果可能不可靠。

### 新问题 3：CETM、Ricci 流和 Circle Patterns 三者使用不同的"度量参数化变量"（共形因子 $u_i$、圆半径对数 $\log r_i$、面半径对数 $\log r_f$），这些变量选择是否影响优化 landscape 的凸性？有没有统一的框架？

**解答**：这个问题触及了离散共形几何的一个深刻事实。

三者都被证明是**凸优化问题**（在各自的变量空间下）：
- **CETM**：$E(u)$ 关于 $u$ 是凸的（因为 $\Pi(\alpha)$ 的凹性 + 线性项的凸性）
- **Ricci 流**：$E(u)$ 关于 $u = \log r$ 是严格凸的（Chow-Luo 定理保证的 Hessian 正定性）
- **Circle Patterns**：Bobenko-Springborn 能量关于 $\rho = \log r$ 是凸的

**统一框架**：三者都可以归入 **"离散共形变分原理"**，形式为：

$$
E(\text{metric}) = \text{Volume}(\text{双曲多面体}) + \text{线性项}
$$

其中线性项来自曲率目标约束（通过 Lagrange 乘子法引入）。三者的优化 landscape 都"继承"了双曲几何中理想多面体体积的凸性。

### 新问题 4：QuadCover 中 Weingarten 映射计算主曲率方向的理论依据是什么？离散化中如何保证精度？在脐点区域会有什么问题？

**解答**：Weingarten 映射（形状算子）$W = I^{-1} II$ 是微分几何中计算主曲率的标准工具。其理论依据：

- 曲面上一点沿方向 $\mathbf{d}$ 的法曲率由 $\kappa_n(\mathbf{d}) = II(\mathbf{d},\mathbf{d}) / I(\mathbf{d},\mathbf{d})$ 给出
- 主曲率方向 $\mathbf{d}_1, \mathbf{d}_2$ 满足 $W\mathbf{d}_i = \kappa_i \mathbf{d}_i$，即 $W$ 的特征向量
- $W$ 是切空间上的自伴算子，保证特征值（主曲率 $\kappa_1, \kappa_2$）为实数且特征向量正交

**离散化中的精度要点**：

1. **顶点法向的质量至关重要**：对面法向做面积加权平均获得顶点法向，比直接用面法向更能捕捉真实曲率。如果顶点法向噪声大，$II$ 的计算将严重失真
2. **$W$ 的对称化**：离散 $W = I^{-1} II$ 在数值上不一定严格对称，需取其对称部分 $(W + W^T)/2$ 再进行特征分解，以保证实特征值和正交特征向量
3. **切平面坐标系的选取**：应在每个面上独立建立局部切坐标系，用面法向和 Gram-Schmidt 正交化即可

**在脐点区域（$\kappa_1 \approx \kappa_2$）的问题**：

- Weingarten 映射 $W$ 退化为单位阵的常数倍（$W \approx \kappa I$），任意方向都是特征方向——主方向失去数学定义
- 离散数值计算中，极小的数值扰动（如顶点法向的离散误差）可能导致特征向量剧烈跳动
- **应对策略**：检测 $\|\kappa_1 - \kappa_2\| < \varepsilon$ 的脐点面，对这些面的方向场做 Laplacian 平滑，或用户交互修正

### 新问题 5：最优传输的 Semi-Discrete 解法中，Mérigot 方法（牛顿法求解 Laguerre 图权重的凸能量）与顾老师方法（Alexandrov 定理 + 凸优化）在理论上的关系是什么？它们是否等效？

**解答**：这是一个经常被忽视的深层联系。

- **顾老师方法**基于**Alexandrov 定理**：给定凸多面体的面法向量和面积，则其形状唯一确定。将最优传输映射等价于寻找一个凸多面体（其面法向量由目标点位置确定，面面积由目标测度确定），这归结为**支撑函数**的凸优化问题
- **Mérigot 方法**基于**Laguerre 图**：当传输代价为二次时，最优传输映射对应一个 Laguerre 图（以权重 $\psi_i$ 为图参数）。Mérigot 证明了 $G(\psi) = \int \psi^c d\mu + \sum \psi_i \nu_i$ 是 $\psi$ 的凸函数，可以用牛顿法求解

两者的**等价性**在于：
- Laguerre 图的权重 $\psi_i$ 恰好是 Alexandrov 多面体的面支撑函数在离散点上的取值
- Mérigot 能量的梯度 $\nabla_i G(\psi) = \nu_i - \mu(\text{cell}_i)$ 和顾老师能量的梯度都是"目标面积 − 当前面积"
- 两者的 Hessian 都是基于 cell 邻居结构的稀疏矩阵

本质上是**同一个凸优化问题在两种对偶坐标系中的表达**。

## 代码与文章一致性问题

1. **Circle Patterns 能量**：文章中记为 $E(\rho) = \sum_t (\mathcal{L}(\alpha_{ij}^k) + \cdots) - \sum_e \theta_e \cdot \log r$，但代码中的实现是 **Bobenko-Springborn 变分能量**（`ImLi2SumWasm`），两者来自不同公式体系。建议在文章中注明"此处展示的是 Bobenko-Springborn 变分能量，而非原始的 Lobachevsky 能量"。

2. **CETM 代码中 `lobachevsky()` 函数**：将 $\Pi(\theta) = Cl_2(2\theta)/2$ 做了正确实现，但文章中没有说明这一恒等式。建议补充。

3. **MIQ 代码**使用了交替优化（固定 p 解 θ，固定 θ round p），但文章中没有提及**收敛性**的讨论。建议补充 5-8 轮迭代收敛的经验数据。
