## BCNet

> Jiang et al., *BCNet: Learning Body and Cloth Shape from A Single Image*, ECCV 2020.

### 想法

**单张 RGB**（不必多视分割管线）同时估身体与服装。服装不绑死在 SMPL 顶点子集上：

- 每类衣有**独立 mesh + PCA 尺寸空间**（T-pose 下低维 \(\alpha\)）；  
- 与 SMPL **共享姿态 \(\theta\)**，但用网络预测服装自己的**蒙皮权重** \(W_g\)；  
- 再加位移 \(D\) 刻画穿着形变。

这样拓扑可比「SMPL 裁一块当衣服」更自由，对裙等宽松品类更友好。

### 和 MGN / Octopus 对比

| | Octopus | MGN | BCNet |
| :--- | :--- | :--- | :--- |
| 输入 | 单目 1–8 帧分割 | 多视分割+关节 | **单张 RGB** |
| 衣物表示 | SMPL 上位移 | 分层衣模板+位移 | 独立衣模板+学蒙皮 |
| 换装 | 弱（粘连） | 强 | 强（品类内） |
| 宽松衣 | 一般 | 中等 | 相对更好 |

## Cloth3D（GCVAE：用图卷积生成衣物 mesh）

> Bertiche, Madadi, Escalera, *CLOTH3D: Clothed 3D Humans*, ECCV 2020. arXiv:1912.02792
> 本地 PDF：`Cloth3D Clothed 3D Humans.pdf`
>
> ![image-20261120093030484](../../../imgs/image-20261120093030484.png)

### 定位：先解决"没有数据"，再给一个生成基线

这篇论文其实有**两个贡献**，容易被混为一谈：

1. **CLOTH3D 数据集**：第一个大规模**合成**着装人体序列数据集（7000+ 段 × 300 帧 @30fps ≈ **210 万**样本），带分层 mesh、真实布料动力学、面料标注；
2. **GCVAE**：基于**图卷积**的条件 VAE，学习衣物隐空间，用于**生成**衣物 mesh。

> ⚠️ 注意：GCVAE **不是**"从单张图重建衣服"。它的输入是身体形状 β、姿态 θ、松紧 γ 和一个 128 维隐码，属于**条件生成**而非感知重建。这一点和 BCNet 的定位完全不同。

### 数据怎么造出来（值得记的工程细节）

| 环节 | 做法 |
|---|---|
| 人体来源 | CMU MoCap（约 2600 段、23 类动作、100+ 人）→ SMPL；形状 β 在 [−3, 3] 均匀采样 |
| 版型 | 4 个设计师模板：t-shirt / top / trousers / skirt，可拼接成 jumpsuit / dress |
| 变宽 | 袖子/裤腿/裙摆按 \(W(x)=\alpha_1 x+\alpha_2\max(0,x-x_{off})+W_0\) 变宽 |
| 裁切 | 沿臂、腿、躯干裁，改变长度与拓扑（同是上衣能裁出 T 恤/衬衫/Polo） |
| 改尺寸 | SMPL 形状位移经最近邻迁移到衣物 + **迭代 Laplacian 平滑**去噪 |
| 松紧 | 在 β 前两维上加偏移 \(\gamma\in\mathbb{R}^2\)，采样 [−1.5, 0.5]（偏向宽松） |
| 仿真 | Blender 布料（mass-spring，420–600 步/秒）；面料 cotton / leather / silk / denim |
| 自穿透 | 三类处理：可解（用身体部件分割线性分开，留 4 mm）→ 无解（剔除或换瘦模型）→ 特例（去掉小臂） |

**按序列划分** 80/20，保证测试集的服装、体型、姿态都不在训练集出现过。

### 表示：衣物 = SMPL 上的偏移 + 掩码

- 先对每段序列在 rest pose 做**非刚性 ICP** 配准衣物到身体；
- 网格**细分**到 **N = 14475** 顶点（去掉头/手/脚，维度减半）；
- 衣物编码为 **偏移量**（body → cloth），再用网络预测的**掩码**把身体顶点剔掉；
- 好处：拓扑统一、维度固定，可以直接套用 SMPL 的图结构。

**裙/连衣裙的拓扑改造**（这篇比较巧的一手）：SMPL 两腿是分开的，裙子却是筒状。做法是删掉每条腿内侧一列面、再把两腿连起来，并对内侧顶点做迭代 Laplacian 平滑；图卷积在该类衣物上使用**改后的 Laplacian 矩阵**，保证邻域聚合正确。

### 网络：两个 GCN-VAE，把"版型"和"褶皱"拆开

| 模块 | 条件变量 | 学到的隐码 |
|---|---|---|
| **SVAE**（静态） | β（11 维，含性别）、γ（2 维松紧） | \(z_s\in\mathbb{R}^{128}\) **版型码** |
| **DVAE**（动态） | β、γ、θ（\(f\times72\)）、\(z_s\) | \(z_d\in\mathbb{R}^{128}\) **褶皱码** |

**设计动机**：衣物的"款式/尺码"是静态属性，"褶皱"是动力学属性，混在一个隐空间里会互相干扰。拆成两级后，可以固定 \(z_s\) 换 \(z_d\) 来改褶皱、或固定 \(z_d\) 换 \(z_s\) 来换款式。

条件变量先过一个小 **AutoEncoder**（记作 Γ），取其中间层特征 `cvar_z` 送进主 VAE；同时**从编码器第一个 FC 层回归 cvar**，用来强化隐空间解耦（消融显示这一步主要改善 KL，对表面误差影响不大）。

### 图卷积的三个工程细节

1. **池化层级**：用网格简化建 6 级金字塔

$$14475\to3618\to904\to226\to56\to21$$

2. **按身体部件限制合并**：把身体分成 **21 个部件**，禁止跨部件收缩边——否则感受野会跨越身体部位，池化失去物理意义。最后一级恰好"每个部件一个节点"。
3. **Unpooling**：把特征直接复制回上一级的所有对应顶点；全网络带 skip connection，DVAE 的特征通道数是 SVAE 的 2 倍。

> 这三条是"把 GNN 用在高分辨率人体网格上"的通用经验，可直接迁移到其他人体相关任务。

### 损失

$$\mathcal{L}=\mathcal{L}_g+\mathcal{L}_{cvar}+\lambda_{KL}D_{KL}\bigl(q(z|X,cvar)\,\|\,p(z|cvar)\bigr)$$

$$\mathcal{L}_g=\mathcal{L}_o+\lambda_n\mathcal{L}_n+\lambda_m\mathcal{L}_m+\lambda_c\mathcal{L}_c$$

| 项 | 内容 | 备注 |
|---|---|---|
| \(\mathcal{L}_o\) | 偏移的 L1 | 主重建项 |
| \(\mathcal{L}_n\) | **法线** L1 | 比 Laplacian 平滑更好：**保留高频褶皱**，Laplacian 会把细节抹平 |
| \(\mathcal{L}_m\) | 掩码 L1 | 无掩码时表面误差从 14.3 升到 92.7 mm |
| \(\mathcal{L}_c\) | **碰撞惩罚** \(\max(0,-o\cdot V_N)\) | 用身体法线 \(V_N\) 罚"偏移穿进身体" |

### 结果（静态测试集）

| 配置 | 表面误差 (mm) | 法线误差 (rad) | 掩码 IoU |
|---|---|---|---|
| 完整模型 | **14.3** | **1.04** | 0.9518 |
| 去掉法线损失 | 22.8 | 1.07 | 0.9472 |
| 去掉掩码预测 | **92.7** | 1.19 | — |
| 去掉碰撞损失 | 14.7 | 1.02 | 0.9522 |
| 默认池化 | 14.9 | 1.03 | 0.9390 |

**分品类**：裤子表面误差最低（10.9 mm），裙子最高（21.4 mm，因为顶点离身体远）；但裙子的法线误差最低（0.79 rad，几何最简单），上衣最高（几何复杂）。

**动态**：用 4 帧比用 1 帧好（平均 29.0 → 26.1 mm），说明时序上下文确有助于褶皱预测。

### 和 BCNet / MGN 的关系

| | BCNet | Cloth3D / GCVAE |
|---|---|---|
| 任务 | **从单张图重建** | **条件生成**（给定 β/θ/γ + 隐码） |
| 是否需要图像 | 是 | **否** |
| 衣物拓扑 | 每品类独立 mesh + PCA 尺寸空间 | SMPL 加密网格（裙类改拓扑） |
| 输出 | 顶点 + 蒙皮权重 | 偏移 + 掩码 |
| 姿态处理 | 共享 θ + 学蒙皮 | 偏移定义在身体上，随身体自然变形 |
| 主要价值 | 感知方法 | **数据 + 生成模型** |

一句话对比：**BCNet 解决"看到图怎么穿"，Cloth3D 解决"没有数据怎么造，以及怎么按参数生成"**。二者可以互补——用 Cloth3D 造训练数据，用 BCNet 类方法做推理。

### 笔记

- 用**偏移 + 掩码**而不是"独立模板"，本质是拿拓扑统一换表达能力：好处是能直接吃 SMPL 的图结构、能共享统计；代价是裙/连衣裙这类拓扑差异大的品类必须**手改拓扑**。
- **法线损失优于 Laplacian 平滑**这条经验，凡是"要从网格回归细节几何"的任务都适用。
- 评估指标里**法线误差**和**掩码 IoU** 缺一不可：表面误差会掩盖"整体偏外/偏内"的系统性偏差。
