## 0. 全书的一条主线

概率编程要解决的问题可以拆成四个递进的论断：

1. 决策需要概率推理——不确定性下的判断 = **知识 + 逻辑**；
2. 概率推理系统受限于它的**表示语言**（能表达哪一类模型）；
3. 贝叶斯网络这类语言的表达能力约等于"布尔电路的概率版"，撑不起真实问题；
4. 把表示语言换成**通用编程语言**（变量、丰富类型、控制流、函数），表达能力跃升，同时仍能配上可计算的推理算法。

一句话定位：**BN/MN ≈ 汇编或电路，概率编程 ≈ 高级语言，推理算法 ≈ 编译器/运行时优化。**

由此得到全书最有用的工程观：

> **模型设计与算法选择是同一件事的两面。** 模型写得越贴合算法（小最大团、少环、证据不罕见），推理越快。

第 1 章还用一个"同一简单系统分别用 Java 与 Figaro 实现"的对照说明另一层差别：结论不是"Figaro 语法短"，而是**通用语言能把"模型结构"本身当作数据来操作**——这是 BN 那套固定结构做不到的。

# 第一部分 基本概念

## 1. 概率推理的五个要素

| 要素 | 含义 | 为什么重要 |
|---|---|---|
| 一般知识 | 领域层面的概括性规律 | 模型只该装这个 |
| **概率模型** | 用概率定量编码的一般知识 | 可复用、可换证据 |
| **证据** | 关于当前具体情况的已知信息 | **不属于模型** |
| **查询** | 想知道的未知量 | 决定推理目标 |
| **推理** | 模型 + 证据 → 答案 | 数学由概率法则保证 |

再加第六个：

| **学习** | 从经验产生**新模型** | 与推理的产物不同 |

> 区分推理与学习的最简标准：**推理算法回答查询，学习算法产出模型。**

### 1.1 可能世界、分布、先验、后验

- **可能世界**：看到任何证据之前认为可能的一种完整状态（= 所有变量各取一个值）。
- **概率分布**：给每个可能世界指定概率，总和为 1。
- **概率模型**：分布的**表现形式**，不是分布本身。
- **先验分布**：见证据之前。
- **调节 (conditioning)**：把证据作用到分布上——把不兼容的可能世界概率置 0，再重新归一化。
- **后验分布**：调节之后。

由定义立刻得到：**某事实的概率 = 与该事实一致的所有可能世界的概率之和。**

也立刻得到一个反直觉的推论：**模型里必然存在与证据冲突的可能世界**（因为模型不含证据）。推理阶段才把它们淘汰。

### 1.2 三类推理 + 一类学习

| 类型 | 方向 | 例子 |
|---|---|---|
| 预测未来 | 前向 | 根据阵容与天气预判比赛结果 |
| 推断根源 | **后向** | 丢球了，反推门将水平 |
| 从过去学习以改善预测 | 跨时间 | 把上一场的结论并入本场证据 |
| 学习模型本身 | — | 用大量案例重估参数 |

关键结论（全书反复重申）：

> **模型按生成（因果）顺序搭建，推理方向可以任意。**

### 1.3 数据量与先验的此消彼长

预测质量 = f（模型接近现实的程度，数据量）。

- 数据少 → **先验主导**，先验质量决定成败；
- 数据多 → **数据主导**，模型会逐渐"忘掉"先验。

这不是比喻，第 5 节的 MAP/MLE 对比会给出精确算式。

### 1.4 为什么"表达能力"是核心问题

- **表示语言**规定了"能表达哪一类模型"，其边界叫**表达能力**；
- BN、HMM 等都是表示语言，表达能力有限；
- 作者用了一个很硬的类比：BN 相当于"逻辑门电路"，能实现任何功能，但没人会用它写工资单系统；
- 概率程序则是"带随机元素的普通程序"，程序的意义定义为**每条执行路径的概率**。

这条思路的出处是 1997 年 Pfeffer、Koller、McAllester 的开创性论文（Stuart Russell 在序言里专门讲了这段历史）。

## 2. 概率模型的数学结构

### 2.1 四个成分（建模检查表）

| 成分 | 含义 | 常见错误 |
|---|---|---|
| **变量** | 不确定量，有类型与值域 | 塞入不相关的量，模型臃肿 |
| **依赖性** | 谁影响谁（有向/无向） | 按推理方向而非生成方向连边 |
| **函数形式** | 给定父变量时的分布族 | 只图方便，不顾物理意义 |
| **数值参数** | 分布的具体数字 | 参数太"自信"，压死数据 |

模型不对时，逐项排查这四条即可。

变量类型可以很丰富：布尔、枚举、实数、整数、列表、结构化类型。**"类型丰富"是概率编程相对 BN 的第一项红利**（BN 的变量基本只有离散取值）。

**模型的图表示**：节点 = 元素（包括没被赋给 Scala 变量的中间元素），有向边 = "后者的定义中引用了前者"。只有复合元素能成为边的终点。这张图就是后续推理算法的操作对象。

### 2.2 生成过程

模型 = 一个**生成过程**：想象按顺序给每个变量抽值，父先于子。四种典型的不对称关系：

1. 参数 → 使用参数的实例（硬币偏差 → 每次抛掷）
2. 原因 → 结果
3. 真值 → 计量值（真实电量 → 传感器读数）
4. 先发生 → 后发生

**额外的可靠性约束**：

> 生成过程必须**以概率 1 终止**。若程序有正概率进入无限递归，它就无法在可能世界上定义有效分布。

这是概率编程相对普通程序多出来的一条硬约束，值得单独记住。

### 2.3 独立性与条件独立性

**独立**：知道 A 不带来关于 B 的任何信息

$$P(B=b \mid A=a) = P(B=b)\quad\text{（对所有取值成立）}$$

且独立性是对称的。

**条件独立**：在某些信息已知后才独立

$$P(B \mid A, C) = P(B \mid C)$$

**实用的判别法**：用"分两步调节"来验算。先按 C 调节得到新分布，再按 A 调节；若结果不变，则 A 在 C 下与 B 条件独立。

书中的比率判据更直观：若在 C 的每个取值下，B 的两个取值的概率比都固定，则 B 与 A 在 C 下条件独立。

**这个"分步调节"直觉，正是第 6 章链式法则分解和第 3 章 d-分离的共同基础。**

### 2.4 连续变量与概率密度

为什么必须用密度：若每个点都有正概率，区间内有无穷多点 → 总概率无穷大，矛盾。所以：

- **单点概率 = 0**
- 只有**区间**有正概率
- **PDF** 描述"每点的密度"，区间概率 = 密度在该区间的**积分**（= 曲线下面积）

例：高度在 [113.2, 113.3] 的概率是 1/1000，[113.29, 113.30] 是 1/10000。

### 2.5 Beta-Binomial：全书的核心工作例子

任务：不均匀硬币，观察 100 次，预测第 101 次。

变量与依赖：

- `Bias`：连续，Beta 分布（**参数本身是随机变量**的入口）
- `NumberOfHeads`：`Binomial(100, Bias)`
- `Toss101`：`Flip(Bias)`

**注意没有 `NumberOfHeads → Toss101` 的边**：前 100 次的信息全部经 `Bias` 中介；`Bias` 已知时二者条件独立。这是"按生成过程连边"的典型示范。

**Beta 参数的自然解读**：

> **α = 想象中已观察到的成功次数 + 1，β = 想象中已观察到的失败次数 + 1。**

| 先验 | 含义 |
|---|---|
| `Beta(1,1)` | 一无所知（均匀） |
| `Beta(2,5)` | 相当于先看过 1 正 4 反，偏向反面 |
| `Beta(11,11)` | 弱信息但"有 10 次正、10 次反的经验"，能有效抑制过拟合 |

α、β 的量级越大，先验越硬。

**共轭性**：

$$\text{Beta}(\alpha,\beta)\ \xrightarrow{\ \text{观察 } N_S,N_F\ }\ \text{Beta}(\alpha+N_S,\ \beta+N_F)$$

后验与先验同族，贝叶斯法则里的积分退化为加法。书里强调：概率编程**不依赖**共轭（近似算法能算难积分），但能用就该用。

## 3. 两类图模型

### 3.1 有向 vs 无向

| | 有向 | 无向 |
|---|---|---|
| 语义 | 不对称关系（多为因果/生成） | 对称影响，无显著方向 |
| 框架 | 贝叶斯网络 (BN) | 马尔科夫网络 (MN) |

**依赖方向判据**（作者称掌握前四类即可定对 95%）：

1. 先发生 → 后发生
2. 同刻状态的因果（断电 → 停机）
3. 真值 → 计量值
4. 参数 → 使用参数的变量

含糊情形（需经验法则）：部分 ↔ 整体、特殊 ↔ 一般、具体 ↔ 抽象。

**诊断模型的经典错误**：看到"打印机不工作"想问原因，于是画 `症状 → 病因`。错了——箭头必须按生成过程画；诊断只是**推理反向**，模型本身不动。

### 3.2 BN 的定义与语义

**三要素**：带定义域的变量集 + 有向**无环**图（允许无向环）+ 每个变量在父变量下的 CPD。

**可能世界的概率** = 各 CPD 对应条目连乘：

$$P(x_1,\dots,x_n)=\prod_i P\bigl(x_i\mid \mathrm{pa}(x_i)\bigr)$$

所有可能世界之和恒为 1（可自行验算）。

**BN 的一个便利性质**：任何单个可能世界的概率都能**局部**算出，不需要知道全局归一化常数。

**设计一个诊断型 BN 的三步法**（书中的打印机范例）：

1. **选变量及定义域**——由粗到细：先做"打印结果摘要"，再展开"页数/速度/质量"，最后到底层"打印机状态/墨粉/进纸/网络/软件/用户"；
2. **定结构**——按生成顺序连边；
3. **写 CPD**。

实践要点：**不要一次性做完三步**，而是逐步细化；每加一块就立刻跑一次推理，看结果是否符合直觉。这种"增量验证"比事后调试省事得多。

### 3.3 d-分离的直觉版

推理沿**路径**传播，路径可能被阻塞。三种模式：

| 模式 | 未观测中间节点 | 观测中间节点 |
|---|---|---|
| 链 / 中介（A → C → B） | 通 | **阻塞** |
| 分叉（A ← C → B） | 通 | **阻塞** |
| **会聚**（A → C ← B） | **阻塞** | **通** |

第三行最反直觉，叫**诱导依赖 / explaining away**：

> 未观测"画是否鲜艳"时，"主题"与"材料"独立；一旦知道"很鲜艳"，再得知"是油画"，则"是风景画"的信念下降——两种解释在**竞争同一个证据**。

实用价值：这正是"诊断"之所以有效的数学原因，也是"多加一个证据反而降低某假设概率"的解释。

### 3.4 MN 的定义与语义

**三要素**：带定义域的变量集 + **无向**图（允许环）+ 一组**势 (potential)**。

**势**：从变量取值组合到**非负实数**的函数。

**解读原则：其他条件都相同 (ceteris paribus)**。

> 势值高 ≠ 该状态概率高。势只表达"在其他因素不变时，这个组合比其他组合更可能"。最终概率还要被别的势抵消。

势的比值有直接含义：同色势 0.9、异色势 0.1 → 其他条件相同时，同色的相对可能性是异色的 **9 倍**。

**结构规则两条**：

- 势只能提及图中**相连**的变量；
- 图中相连的两个变量**必须**被某个势一起提及。

**分布的计算**：

$$P(x)=\frac{1}{Z}\prod_c \psi_c(x_c),\qquad Z=\sum_x\prod_c\psi_c(x_c)$$

即：势乘积 → 未规格化概率 → 求和得 Z → 除以 Z。

### 3.5 BN 与 MN 的三点本质差异

| | BN | MN |
|---|---|---|
| 单世界概率 | 可直接局部算出 | **必须知道 Z**，要枚举全部世界 |
| 参数可解释性 | CPD 语义直接 | 势只是相对权重 |
| 推理规则 | 有 d-分离、有诱导依赖 | 更简单：路径不被观测阻塞即可传播 |
| 因果/时间方向 | 有 | 无 |

第 2 点解释了"为什么很多人觉得 MN 难调参数"——这是结构性的，不是理解问题。

### 3.6 图像恢复：MN 的标准范例

- 每像素一个布尔变量
- 一元势：亮 0.4 / 暗 0.6
- 二元势（相邻）：同色 0.9 / 异色 0.1

这个模型在书里被反复用作推理与 MPE 的试验台，因为它的结构是标准网格，能清楚暴露算法行为。

**实测补充（[code/](code/README.md)）**：`0.9/0.1` 与 `0.4/0.6` 不在同一尺度上。
一条异色边的代价 `log 9 = 2.197`，单像素证据只有 `log(0.8/0.2) = 1.386`，所以
**照字面数值求 MPE 会得到全暗图**——平滑把证据压死了（§2.1 "参数太自信"）。
给二元势加指数 `beta ≈ 0.4` 后去噪才生效，且此时 MPE 与"逐像素边缘阈值"解相差
8 个像素、后验高 5.0，正是 §8.2 那条论断的可算实例。

## 4. 表达力的三次扩展

这一节讲"概率编程比 BN 多出来的能力"，并**直接指出它对算法的影响**。

### 4.1 未知数量：开放宇宙

- BN 的变量集固定；一旦对象个数随机，BN 就表达不了；
- 概率编程中"数组长度本身是元素"就自然表达；
- **开放宇宙 (open universe)**：对象数量未知甚至无限；
- **Process**：无限随机过程（如时空随机场），按需取值。

**对算法的影响（关键）**：变量个数不确定 ⇒ 无法枚举 ⇒ **因子分解算法基本失效**，只能走抽样。这是"表达能力换算法自由度"的典型权衡。

### 4.2 面向对象建模：关系与类型不确定性

在"值不确定"之外再加两种：

1. **关系不确定性**：谁与谁有联系本身是随机的（"这两人是否朋友"）；
2. **类型不确定性**：对象属于哪个类不确定（这台设备是激光还是喷墨）。

**对算法的影响**：对象的**内部细节被封装**后，VE 可以把内部元素就地消去，只在接口上留小因子。

> **接口越小 → 最大团越小 → 推理越快。** 这是"好的 OO 设计"与"好的推理性能"同源的唯一原因，非常值得记住。

### 4.3 动态系统

**状态变量**：随时间变化且相互依赖的变量。三类任务对应静态情形的三种（预测未来、推断过去、随时监控）。

**马尔科夫链**：单一状态变量 + 一阶依赖。

**马尔科夫假设**：任一时刻状态，在前一时刻状态给定的条件下，独立于更早的所有状态。

建模三要素：

1. **状态取值集合**（要克制：迁移表大小是 |S|²）
2. 初始值或初始分布
3. 迁移模型 \(P(S_t\mid S_{t-1})\)，通常各时刻共享

**HMM** 两个假设：

1. 隐含状态构成马尔科夫链；
2. 观测只依赖**当时**的隐状态（给定隐状态时，观测独立于所有更早的隐状态与观测）。

**DBN**：把 BN 沿时间展开，每时刻可有多个状态变量与多个观测。

**概率编程的超越**：**结构可随时间变化**——每时刻的网络拓扑本身不同（对象数量、关系变化）。这类模型没有"固定图"可展开，BN/DBN 框架无法表达。

**对算法的影响**：结构可变 + 无限时间 ⇒ 必须用**过滤/滚动**方式（第 9 节），不能整段展开。

# 第二部分 推理

## 5. 概率推理三原则

### 5.1 链式法则

一般形式（无条件独立假设）：

$$P(X_1,\dots,X_n)=\prod_{i=1}^{n}P\bigl(X_i\mid X_1,\dots,X_{i-1}\bigr)$$

BN 中利用条件独立简化（依赖被父变量截断）：

$$P(X_1,\dots,X_n)=\prod_{i=1}^{n}P\bigl(X_i\mid \mathrm{Pa}(X_i)\bigr)$$

**易错点**：严格链式法则要求第 3 个变量对**前两个**取条件；只用第一个是错的。BN 里能简化，是因为父变量已经截断了依赖。

**作用**：把小 CPD 表乘成完整联合分布。

### 5.2 全概率公式

$$P(Q)=\sum_{h}P(Q,h)$$

连续情形换积分。**作用**：把无关变量"消掉"，得到边缘分布。

### 5.3 贝叶斯法则

$$P(H\mid E)=\frac{P(E\mid H)P(H)}{P(E)}$$

工程写法（避开难算的 P(E)）：

$$\boxed{P(H\mid E)\ \propto\ P(H)\cdot P(E\mid H)}$$

即 **后验 ∝ 先验 × 似然**。

多变量一般形式：

$$P(\mathbf{X}\mid\mathbf{Y},\mathbf{Z})\ \propto\ P(\mathbf{X}\mid\mathbf{Z})\,P(\mathbf{Y}\mid\mathbf{X},\mathbf{Z})$$

**X** = 原因，**Y** = 结果，**Z** = 背景条件。这个精炼式是记忆贝叶斯法则的最佳形式。

### 5.4 三者分工

```
CPD 集合 ──链式法则（乘）──▶ 联合分布
                                │
                    全概率公式（加）│
                                ▼
                            边缘分布
                                ▲
                    贝叶斯法则（翻）│
                                │
                            结果 → 原因
```

**链式往上搭，全概率往下摊，贝叶斯横着翻。**

### 5.5 硬币案例：三种预测路线的精确对比

设定：先验 `Beta(2,5)`，观察 100 次得 63 正 37 反 → 后验 `Beta(65,42)`。

| 方法 | 取什么 | 公式 | 结果 |
|---|---|---|---|
| **MAP** | 后验的**众数** | (α−1)/(α+β−2) = 64/105 | **0.6095** |
| **MLE** | 只最大化似然（≡ `Beta(1,1)` 先验） | 63/100 | **0.63** |
| **全贝叶斯** | 用整个后验求期望 | α/(α+β) = 65/107 | **0.6075** |

差异来源清楚：MLE 完全信数据，先验把结果往 0.5 拉回一点。

### 5.6 三种方法的取舍

**MLE**

- 优点：计算高效（不做积分）、无需指定先验
- 缺点：**过拟合**。10 次抛掷 7 次正面就断定偏差 0.7 是草率的

**MAP**

- 精确的抑制过拟合例子：`Beta(11,11)` 先验 + 10 次里 7 正 3 反 → 后验 `Beta(18,14)`
  - MAP ≈ 17/30 = **0.567**
  - 全贝叶斯 = 18/32 = **0.5625**
  - 对比 MLE 的 0.7：先验把估计拉回了 0.56 附近
- 缺点：先验难指定

**全贝叶斯**

- 优点：用整个分布；**多峰分布时 MAP 会停在某个峰而忽略其他峰**
- 缺点：需要积分，计算最贵

> 这也是概率编程系统默认倾向全贝叶斯（用近似算法处理积分）的原因。

## 6. 因子分解推理

### 6.1 因子

**因子** = 从"一组变量的取值组合"到**实数**的函数。

- **行数** = 各变量取值个数之积
- CPD 是因子，但因子更一般：
  - 值不必在 [0,1]（MN 的势可以 >1）
  - 值不一定是概率
  - 算法运行中会产生不对应任何 CPD 的中间因子

**因子分解的意义**（类比整数分解）：15 = 3×5，小数相乘比大数容易；联合分布也是——"小因子之积"远优于"整张联合表"，因为后者随变量数**指数增长**。

### 6.2 乘积之和表达式

无证据：

$$P(Q)=\sum_{h}\prod_i f_i(Q,h)$$

有证据：引入**证据因子**（符合的置 1、不符的置 0），再归一化：

$$P(J\mid B=\text{Bright})\ \propto\ \sum_Z P(J)P(B\mid J)P(Z\mid J)E_B(B)$$

工程技巧：证据因子可直接与对应 CPD 因子**合并**（删掉不符合的行），省一次乘法。

注意：这里算出的是**未规格化**答案，最后必须归一化（例如 16:14 → 0.533/0.467）。

### 6.3 VE 的图形视角（理解复杂度）

1. 初始图 = **端正图 (moral graph)**：同一子变量的多个父变量"联姻"连边（因为它们在同一个 CPD 因子里）；
2. 每消去一个变量，把它所有邻居**两两连边**；
3. 最终得到**诱导图**；
4. 结论：

$$\text{VE 复杂度}\ \propto\ \exp\bigl(\text{诱导图最大团顶点数}\bigr)$$

理由：出现在同一因子里的变量必然构成团；因子行数是各变量取值数之积。

**消元顺序的决定性作用**：同一网络，一种顺序最大团 = 3，另一种 = 4，代价差一个数量级。

**三角化定理**：

- 初始图**是**三角化图 ⟺ 存在**不新增任何边**的消元顺序
- 初始图**不是**三角化图 ⟹ 任何顺序都至少要新增一条边
- 推论：**树/无环网络总有最优顺序**（从两端往中间消）

**找好顺序**：本身是组合难题（代价与最优最大团成指数关系），实践中用启发式——**每次选"消去时新增边最少"的节点**。Figaro 的变体还额外考虑变量取值个数。

### 6.4 VE 的代数视角

```
for each non-query variable Z (按选定顺序):
    F = {所有提及 Z 的因子}
    g = 把 F 全部相乘
    h = 对 Z 求和（消除 Z）→ 新因子
    用 h 替换 F
最后把所有剩余因子相乘 → 查询结果（未规格化）
```

这就是"乘 → 求和 → 生成新因子"的循环。因为是纯代数变换，VE 是**精确**的。

### 6.5 VE 为什么对 HMM 线性

HMM 展开后：

- 每个节点的父节点 ≤ 1 → 端正图**不需要联姻加边**
- 图是**无环**的 → 存在不加边顺序
- 所有连接都是两两相连 → 最大团顶点数恒为 **2**

因此 **VE 代价随序列长度线性增长**。语音识别能用 VE 就是靠这个结构。

**普适结论：模型规模不是关键，结构才是。** VE 适用于任何"最大团小"的模型，哪怕变量上万。

### 6.6 让 VE 跑得动的四个原则

| 原则 | 做法 | 收益 |
|---|---|---|
| **结构设计** | 让端正图接近树/三角化 | 最大团小 |
| **函数分解** | 把 n 参数复合函数拆成多个 2 参数 | 因子行数从指数降到线性 |
| **封装** | 对象只暴露小接口；链内部元素不外泄 | 内部变量就地消去 |
| **简化网络** | 删边/删点，牺牲精度换可算 | 立刻可用 |

函数分解的数量级示例（4 个二项分布相加，每个 11 种取值）：

- 直接 4 参数：11⁴ = **14641** 行
- 拆成 3 个两两加法：121 + 121 + 441 = **683** 行
- 约 **21 倍**差距

### 6.7 置信传播 (BP)

在因子图/网络上传播"消息"，用局部消息之积近似边缘分布。

| 情形 | 性质 |
|---|---|
| 图是**树** | **精确**（等价 VE） |
| 图有**环** | **Loopy BP**：近似、快、**不保证收敛** |

- 优点：单次迭代便宜，能处理 VE 撑不住的规模
- 代价：无正确性保证；需调迭代次数；环多时振荡
- 设计目标相应变为：**减少长环、控制环数**

#### 6.7.1 原始论文精读：Pearl (1982)

> Judea Pearl, *Reverend Bayes on Inference Engines: A Distributed Hierarchical Approach*, AAAI-82, pp. 133–136.
> UCLA Cognitive Systems Laboratory, Technical Report R-30. 本地 PDF 见同目录。

**时代背景**。1982 年 AI 界的主流做法是"为了处理不确定性，必须牺牲一点概率论"——MYCIN 的确定性因子、Prospector 的主观贝叶斯、各种启发式证据合成规则，都是 ad-hoc 的。作者开篇就点破这是一种 **myth**，并主张：先问清楚"传统概率论究竟要求我们做哪些计算"，再判断这些计算是否真的与现代需求（局部、异步、分布）不相容。

**论文要解决的三件事**：

1. 如何在**层级组织**的推理结构里，把新证据/新信念的影响**异步传播**开；
2. 异步传播会引发**不稳定**——若"更强的假设"抬高"支撑证据"的信念，"证据"又反过来抬高"假设"，两者互相通信就可能陷入无限更新循环。要给出**保证单趟完成**的参数与规则；
3. 证明**多值变量**（一个变量有 n 个互斥状态）也能做规范贝叶斯推理，驳斥"条件独立与互斥穷尽不可兼得"的批评。

#### 6.7.2 问题设定

- 推理网是有向无环**树**：每条边 \(A\to B\) 表示一族规则"若 \(A\) 则 \(B\)"；
- 不确定性由**条件概率矩阵** \(M(B\mid A)\) 量化，元素 \(M(B\mid A)_{ij}=P(B_j\mid A_i)\)；
- 方向含义：\(A\) 是假设集合，\(B\) 是其"指示/表现"（manifestation），称 \(B\) 是 \(A\) 的**儿子**；
- 每个节点只允许**一个多假设父亲**（这是后面能单趟收敛的结构前提）；
- 叶节点是可观测变量。

#### 6.7.3 唯一的假设：局部通信

全文只有一条结构性假设：

$$P\bigl(B_j\mid A_i,\,D^{u}(B)\bigr)=P\bigl(B_j\mid A_i\bigr)\tag{1}$$

其中 \(D^u(B)\) 是"B 以上网络"的全部数据。含义：

> **B 与上层世界的一切交互都被父亲 A 完全概括了。**

这正是后来所说的**条件独立/局部性**。由 (1) 立刻推出兄弟独立：

$$P\bigl(B_j,C_k\mid A_i\bigr)=P\bigl(B_j\mid A_i\bigr)P\bigl(C_k\mid A_i\bigr)\tag{2}$$

论文特意区分了"**弱形式**"与 Pednault 等人主张的"**强形式**"：强形式还要求对**补集** \(\bar A_i\) 也独立，这在多值变量下过强且不必要。作者的立场是：互斥穷尽与条件独立可以共存，前提是只要求 (2) 这种弱形式。

这条辨析很关键——它解释了**为什么多值变量不会破坏 BP 的合法性**。

#### 6.7.4 两个参数：把上下证据解耦

把 B 相关的数据分成两半：\(D^d(B)\)（B 以下子树）与 \(D^u(B)\)（B 以上）。贝叶斯定理给出**乘积规则**：

$$P\bigl(B_i\mid D^u(B),D^d(B)\bigr)=\alpha\,P\bigl(D^d(B)\mid B_i\bigr)\,P\bigl(B_i\mid D^u(B)\bigr)\tag{3}$$

二值情形退化为经典的"似然比 × 先验几率"：

$$O(H\mid E)=\lambda(E)\,O(H)\tag{4}$$

其中 \(\lambda(E)=P(E\mid H)/P(E\mid\bar H)\) 是似然比，\(O(H)=P(H)/P(\bar H)\) 是先验几率。

于是每个节点只需维护两个 n 维向量：

| 参数 | 定义 | 直觉 |
|---|---|---|
| \(\lambda(B_i)\) | \(P\bigl(D^d(B)\mid B_i\bigr)\) | **诊断支撑**：来自子孙的证据 |
| \(\pi(B_i)\) | \(P\bigl(B_i\mid D^u(B)\bigr)\) | **预期支撑**：来自祖先的信念 |

信念由二者相乘得到：

$$P(B_i)=\alpha\,\lambda(B_i)\,\pi(B_i)\tag{7}$$

**这就是"两参数解耦"的实质**：\(\lambda\) 只受下方影响，\(\pi\) 只受上方影响，两条信息流互不干扰——单趟收敛的全部秘密都在这里。

#### 6.7.5 三条更新式

**(a) 自下而上：合并儿子证据**

$$\lambda(B_i)=\prod_{k}\lambda_k(B_i)\tag{9}$$

儿子的独立性（式 2）保证了"证据可以连乘"。

**(b) 发给父亲的消息**

$$\tau=M\lambda\tag{8}$$

即 \(\tau_j=\sum_i P(B_i\mid A_j)\lambda(B_i)\)。\(\tau\) 的维度等于**父亲**的假设数，每个分量表示"B 以下的数据对父亲某个假设的诊断贡献"。

**(c) 自上而下：用父亲的信念推自己**

$$\pi(B_i)=\beta\sum_j P(B_i\mid A_j)\,\frac{\pi(A_j)}{\tau'(A_j)}\tag{10}$$

\(\tau'\) 是父亲**已确认收到**的、B 上一次发上去的 \(\tau\)。

**为什么必须除以 \(\tau'\)**：父亲当前的 \(\pi(A_j)\) 里已经混入了 B 自己贡献的证据；若直接拿来往下推，B 的证据会被计算两遍，形成"自己抬高自己"的正反馈——正是引言里担心的无限循环。除掉 \(\tau'\) 等于**先把 B 的影响从父亲里摘出去**，再正常传播。

令牌博弈里对应一条规则：**吸收过令牌的那条链路不再产生新令牌**。

#### 6.7.6 边界条件

| 节点类型 | 设置 |
|---|---|
| 可观测叶，状态未知（anticipatory） | \(\lambda=(1,1,\dots,1)\)（没有证据，全部中性） |
| 可观测叶，观测到第 j 个状态 | \(\lambda=(0,\dots,0,1,0,\dots,0)\)（第 j 位为 1） |
| 根节点 | 用**先验概率**代替来自父亲的 \(\pi\) 消息 |

> 全文只有根节点需要先验；其余节点的概率完全由弧矩阵、观测数据和根的先验唯一确定。这一点在工程上很重要：**先验只需给一次，且只在根上。**

#### 6.7.7 为什么单趟就收敛

- \(\lambda\) **只**受自下而上的变化影响；
- \(\pi\) **只**受自上而下的变化影响；
- 两者解耦 ⇒ 每次传播都严格推进，不会来回震荡。

证明用**双重归纳**：先对 \(\lambda\) 自下而上归纳（叶节点成立 → 由条件独立推父节点成立），再对 \(\pi\) 自上而下归纳（根成立 → 用式 10 推子节点成立）。结论：有限步后达到平衡，且平衡值就是正确的 \(P(V_i\mid D^u(V),D^d(V))\)。

**并行时间 = 网络的直径**（最长路径上的边数）。这是"分布式"二字的真正含义：不需要中心调度，信息以每秒一条边的速度扩散。

#### 6.7.8 令牌博弈：一个极好的直观

论文用"令牌游戏"图示了传播过程：

1. 数据节点被激活 → 向父亲放出**白色令牌**（= 向上传 \(\lambda\)）；
2. 父亲收到白令牌 → 按需生产：给父亲的父亲发白令牌，给儿子发**黑色令牌**（= 向下传 \(\pi\)）；
3. 已吸收令牌的那条链路**不再获得新令牌**（对应式 10 的除法）；
4. 经过"直径"轮，令牌全部被吸收，网络达到新平衡。

这个模型把"异步、无中心、局部通信"三件事一次性讲清楚了。

#### 6.7.9 代价

设 m 叉树、每节点 n 个状态：

- **存储**：约 \(n^2+mn^2+2n\) 个实数（自身的 \(n^2\) 矩阵 + 对每个儿子的 \(n^2\) 矩阵 + 两个 n 维向量）
- **每次更新**：约 \(2n^2+mn+2n\) 次乘法
- 二者都"与每个变量所触发的规则数同阶"

> 注：上述常数取自扫描件，OCR 对上下标有失真；**量级结论**是 \(O(n^2+mn^2)\)，即随状态数平方增长。

另外三条性质值得记住：

1. 局部计算量与**控制机制无关**——数据驱动、目标驱动、定时、随机触发都不影响结果；
2. 需要**完整的条件概率矩阵** \(M(B|A)\)，标注成本随 n 平方增长；
3. 树结构是硬前提，**有环就没有任何保证**。

#### 6.7.10 局限与后续演进

| 局限（1982 原文） | 后续怎么解决 |
|---|---|
| 只支持**树**、单亲 | Pearl 1988 专著推广到多亲网络，并引入 **explaining away**（诱导依赖） |
| 有环无保证 | **Loopy BP**（Turbo 码 / LDPC 解码中被"重新发现"）；实践中常收敛且效果极好 |
| 精确性无一般保证 | **Junction tree**（Lauritzen & Spiegelhalter 1988）把有环图三角化，保证精确 |
| 为何有环时仍好用？说不清 | Yedidia-Freeman-Weiss (2003)：BP 是 **Bethe 自由能的驻点**，给出了近似的变分解释 |
| 消息表达依赖"父子"语义 | **因子图 + sum-product**（Kschischang, Frey, Loeliger 2001）把 π/λ 统一成"变量节点 ↔ 因子节点"的消息 |

#### 6.7.11 与本书描述的对齐

| 本书说法 | 对应 1982 原文 |
|---|---|
| "在树上精确" | 式 (3)(7)(9)(10) 在树上恰好算出正确边缘 |
| "消息传递" | 向下 \(\pi\)、向上 \(\tau=M\lambda\) |
| "Loopy BP 不保证收敛" | 环打破了"\(\lambda\) 只受下、\(\pi\) 只受上"的解耦前提 |
| "需指定迭代次数" | 原文是"一次传播 = 直径步"，有环时没有终止判据，只能强行截断 |

**一句话总结**：BP 的本质不是"迭代算法"，而是**把全局贝叶斯计算拆成局部消息，并精心设计参数使上下证据互不污染**。1982 年的贡献是"解耦 + 单趟"，此后的贡献是"解耦失败时怎么办"。

## 7. 抽样推理

### 7.1 为什么抽样

因子分解的痛点是**因子爆炸**；抽样的思路是：不存分布，存**样本**，用频率估概率。

- 样本密度 ≈ 概率密度
- 内存只与样本数有关，与模型结构无关
- 结果是**近似**的，误差约 \(O(1/\sqrt{N})\) —— **精度翻倍，样本要翻四倍**

关于样本的正确预期（很容易误判）：

- 不同运行得到不同估计；
- 样本分布**平均而言**等于真实分布；
- 样本越多越接近，但**不保证**这一批就接近。

### 7.2 前向抽样

按**拓扑顺序**逐变量采样：

```
for V in topological_order:
    Par = parents(V)
    x_Par = 已生成的值
    x_V ~ P(V | Par = x_Par)
```

因为每次都从"父值已定"的分布采，不需要归一化、不需要枚举。这是所有抽样的基础。

### 7.3 拒绝抽样：为什么不实用

做法：前向采样，与证据冲突就丢弃。

**关键定量结论**：

> **接受率 = 证据的概率。**

后果：

- 抛 20 次全观测 → 接受率 1/2²⁰
- **证据变量越多，接受率指数下降**
- 快速拒绝带来的节省只是**线性**的，无法弥补指数代价
- 而且**只能处理"条件"**，无法处理软约束

所以作者明确说：拒绝抽样适合讲原理，不适合实用。

### 7.4 重要性抽样

核心改动：**不丢弃，改为加权**。

| 证据类型 | 权重贡献 |
|---|---|
| 硬条件 | 满足 → 1，不满足 → 0 |
| 软约束 | 权重 = 约束值 |

**样本权重 = 所有约束值之积。**

约束的形式化定义：

$$P_{\text{unnorm}}(e)=p_0\cdot C(e)$$

\(p_0\) 是忽略约束时的概率，\(C(e)\) 是约束在取值 e 处的值。注意"非规格化"——这些值求和一般不为 1。

**回答查询**：把与查询一致的样本权重求和，除以所有权重之和。

例：权重 {1.0, 1.0, 0.1, 1.0}，总和 3.1；某事实在样本 1、3 成立 → (1.0+0.1)/3.1 = **0.3548**。

**两大优势**：

1. 能处理**软约束**（拒绝抽样不行）；
2. 能把条件**转成约束**，统一框架（虽然权重可能变 0，但不破坏算法）。

**致命弱点：权重退化**。证据罕见时，几乎所有样本权重趋近 0，估计由极少数样本主导。这不是实现问题，是概率结构问题——下一节的 MH 正是为绕开它而生。

### 7.5 MCMC / Metropolis-Hastings

思路不同：不直接采样，而是构造一条**收敛到后验**的马尔科夫链。

**MH 的一般机制**：

1. 从当前状态出发，用**提议分布**生成候选；
2. 按**接受率**（新状态后验 / 当前状态后验，含提议概率比）决定是否移动；
3. 反复迭代，链上的样本近似服从目标后验。

两个必须理解的工程概念：

- **老化 (burn-in)**：丢掉链开头的样本（尚未收敛）
- **间隔 (thinning)**：每 k 步取一个样本（降低样本相关性）

### 7.6 MH 为什么强 —— 一个决定性的论证

两个变量、各有一个"窄脊"约束，单次采样命中高值概率 1/10：

- **重要性抽样**要求**同时**命中 → 1/100，平均 100 次迭代才得一个可用样本；
- **MH** 一次只改一个变量：先让 x 爬到高值区（之后几乎不再离开），再让 y 爬上去 → 约 20 次提议即可。

**放大到 100 个变量**：

| 算法 | 成功率 |
|---|---|
| 重要性抽样 | 10⁻¹⁰⁰（等于不可能） |
| MH | 逐个变量爬升，仍可工作 |

**这就是 MH 存在的唯一理由：高维耦合约束下，重要性抽样的联合命中率指数崩塌。**

### 7.7 MH 的代价（作者相当坦诚）

1. **慢**：样本相关，可能比重要性抽样多几个数量级的样本；间隔越大越独立但越慢；老化时间难定
2. **难理解/难预测**：效率高度依赖提议分布；很容易设计出"无法遍历状态空间"的提议
3. **难以判断何时停**：不知道何时进入高概率区，也不知道多少样本才够

**实用结论：重要性抽样优先，MH 作为兜底。**

### 7.8 死锁：一个必须记住的失败模式

场景：约束"**恰好一个**出演获奖"（200 演员、100 电影、300 出演）。

默认 MH 一次只改一个变量 → **完全无法工作**：

- 改"当前获奖的那次" → 变成 0 个获奖 → 违反条件 → 拒绝
- 改"没获奖的那次" → 变成 2 个获奖 → 违反条件 → 拒绝
- 于是**任何**改动获奖变量的提议都被拒，链永久卡死

**两条出路**：

1. **自定义提议**：允许一次同时改两个元素（把奖从 A 挪到 B）；
2. **放松硬条件**：用软约束替代"恰好一个"，让链有机会经过违规状态。

> **普适教训：硬条件 + 单变量提议 = 死锁风险。**
> 遇到"恰好 k 个""全部不同""和为定值"这类**全局约束**，优先考虑软约束或成组提议。

### 7.9 算法对比

| 维度 | VE | BP | 重要性抽样 | MCMC/MH |
|---|---|---|---|---|
| 精度 | 精确 | 近似（树精确） | 近似 | 近似 |
| 误差 | — | 无保证 | \(O(1/\sqrt{N})\) | 无保证 |
| 主要风险 | 因子爆炸 | 不收敛 | 权重退化 | 混合慢/卡死 |
| 适合 | 小最大团 | 大但环少 | 证据不罕见 | 高维耦合约束 |
| 附加要求 | 结构设计 | 调迭代数 | 样本数 | 提议设计+老化 |

## 8. 其他推理任务

### 8.1 联合分布

**为什么需要**：边缘分布丢掉**相关性**。两个销量可能独立、正相关（高风险）、负相关（对冲），只从边缘完全分不出来。

**实现思路**：把多个变量打包成一个"元组变量"再查询。

**代价不对称（重要）**：

- **因子分解**：要为元组新建大因子，很贵；
- **抽样**：几乎无额外代价（只是把同一次采样里的值组合起来）。

变量一多，联合分布既算不动也读不懂 → 改用**摘要统计**（先求和/取平均再查询）。

### 8.2 最可能解释 (MPE)

**定义**：使**联合概率最大**的那组取值。

$$\max_{x_1}\cdots\max_{x_n} P(x_1,\dots,x_n)$$

**最关键的区别**：

> **MPE = 联合最优 ≠ 每个变量各自边缘最优。**

于是：

- 边缘分布：能算，但每个变量独立选，**接不起来**；
- 全联合分布：算不动（指数）；
- **MPE：只求一个解，可算且整体一致** ← 最佳折中

**图像去噪就是这个论证的标准案例。**

**算法族**（都是常规算法的 max 版本）：

| 算法 | 来源 | 表达式 |
|---|---|---|
| MPE-VE | VE | 乘积之和 → **最大乘积** |
| MPE-BP | BP | 近似，需指定迭代数 |
| MH + 模拟退火 | MCMC | 抽样路线，适合大模型 |

**诊断闭环（MPE 最实用的形态）**：

1. 观察症状 → 证据
2. 求 MPE → 最可能的故障源
3. **验证**该故障，结果作为新证据
4. 未解决 → 回到第 2 步
5. 直到解决

书中的打印机案例：MPE 先判"电源关闭" → 用户检查发现电源是开的 → 加证据后 MPE 改判"网络中断" → 插回网线解决。

这个循环把"概率推理"变成**可操作的排查流程**，而不是只输出一个数字。

### 8.3 证据概率

计算 \(P(\text{evidence})\)：模型生成的可能世界满足证据的概率。

用途：

- 判断模型与现实的吻合度
- **比较不同模型**（证据概率高者更可信）
- 贝叶斯模型选择的基础

## 9. 动态推理

### 9.1 两条路线

| | 展开全部时间步 | 滚动监控（过滤） |
|---|---|---|
| 结构 | 一个展开的大 BN | 每步只留当前 + 前一时刻 |
| 推理方向 | **可前可后**（平滑、回溯） | **只能前向** |
| 内存 | 随步数增长 | 恒定 |
| 时长 | 有上限 | 可无限运行 |
| 适用 | 离线分析 | 在线监控 |

选择依据：**是否需要"用未来推断过去"**。

### 9.2 粒子滤波 = 重要性抽样 + 重采样

每个时间步三阶段：

```
粒子集(t−1)
   │ ① 传播：用迁移函数逐个推进（此时尚未考虑证据）
   ▼
先验粒子集
   │ ② 加权：按证据给每个粒子权重（违反条件→0；否则约束值之积）
   ▼
加权粒子集
   │ ③ 重采样：按权重比例有放回抽取，得到等权新粒子集
   ▼
粒子集(t)
```

**为什么必须重采样**（核心原理）：

> 不重采样的话，权重会随时间**累乘**。几步之后极少数粒子承担几乎全部权重，其余趋于 0 —— 即**权重退化**。此时粒子数再多也是浪费，**有效样本只剩几个**。重采样把"权重"转成"复制次数"，让粒子重新分布到高概率区域，恢复有效多样性。

**代价**：重采样引入随机性、降低多样性；粒子数少时会**塌缩**到少数状态。这是粒子滤波的固有张力，不是 bug。

**与 VE 的对比**：粒子滤波的代价与**时间步数 × 粒子数**成正比，与模型结构无关；VE 在 HMM 上线性但需要完整序列。

## 10. 参数学习

### 10.1 贝叶斯学习

思路：**参数本身就是随机变量**。把训练数据作为证据挂上去，跑推理得到的参数后验就是学习结果。

与 MAP/ML 的区别：

| | 贝叶斯学习 | MAP / ML |
|---|---|---|
| 产物 | 参数的**分布** | 参数的**点估计** |
| 不确定性 | 保留 | 丢弃 |
| 计算 | 贵（要积分/采样） | 便宜 |

**为什么实践中推荐 MH 做贝叶斯学习**（书里给的三条理由很实在）：

- 因子分解算法会把参数**固定成从先验抽到的那一组值**，可能错过高后验区域；
- 重要性抽样在数据多时证据概率极低 → 权重退化；
- MH 逐变量爬升，反而稳。

### 10.2 MAP / ML 与 EM

- **ML = 均匀先验下的 MAP**（严格等价）
- 实现靠 **EM（期望最大化）**，而 EM 是**元算法**：

> **外层是迭代（E 步推隐变量、M 步更新参数），内核可以是任意推理算法。**

所以会出现 "EM + VE"、"EM + BP"、"EM + 重要性抽样"、"EM + MH" 这几种组合。

### 10.3 充分统计量与共轭

关键洞察：**学后验不需要保存全部数据，只需要计数**。

$$\text{Beta}(\alpha+N_S,\ \beta+N_F)$$

观察**顺序无关**，只与成功/失败次数有关 → \(N_S, N_F\) 是**充分统计量**。

这就是共轭结构带来的效率：EM 每轮只需重新统计计数，不必重放数据。

常见配对：

| 参数分布 | 数据分布 | 充分统计量 |
|---|---|---|
| Beta | Binomial | （成功数, 失败数） |
| Beta | Flip | 每个 Flip 贡献一次成功/失败，累加 |
| Dirichlet | Select | 各选项被选中次数 |

## 11. 复杂度与算法选择

### 11.1 复杂度来源

| 算法 | 时间/空间的决定因素 | 爆炸点 |
|---|---|---|
| VE | 诱导图最大团顶点数 | 变量数 × 取值数 |
| BP | 迭代次数 × 图规模 | 环多时收敛差 |
| 重要性抽样 | 样本数 | 证据概率低 → 权重退化 |
| MCMC/MH | 混合时间 × 样本数 | 提议差 → 卡住或乱走 |
| 粒子滤波 | 粒子数 × 时间步 | 粒子少 → 多样性塌缩 |
| 学习（EM） | 迭代数 × 单次推理代价 | 每轮都跑一遍推理 |

### 11.2 选择决策树

```
需要严格保证正确？
├─ 是 → 最大团是否可控？
│        ├─ 是（树/HMM/稀疏） → VE
│        └─ 否 → 先简化模型，再 VE
└─ 否 → 证据概率高吗？
         ├─ 高 → 重要性抽样（简单、可并行、能吃软约束）
         └─ 低（罕见证据/高维耦合） → MH
                  ├─ 有"恰好 k 个"类全局约束 → 自定义提议 或 软化约束
                  └─ 需要 MAP/MPE → EM+MH / MH+模拟退火
```

### 11.3 面向可算性的建模原则

1. **按生成过程连边**，不按推理方向。
2. **四要素检查表**：变量 → 依赖性 → 函数形式 → 数值参数。
3. **参数可随机化**——这是概率编程相对 BN 的直接优势。
4. **变量取值集合要克制**：马尔科夫链迁移表是 |S|²。
5. **接口要小**：封装直接决定因子大小。
6. **大函数拆小**：把 n 参数变成多个 2 参数。
7. **能用共轭就用共轭**（Beta-Binomial、Dirichlet-Select）。
8. **生成过程必须终止**，否则模型无定义。
9. **让模型适配算法**：为 VE 减环、为 BP 控环、为 MH 去硬条件。
10. **先精确后退回抽样**：精确算法能给出可验证的答案。

### 11.4 概念性易错清单

1. 把证据当成模型的一部分。
2. 按"推理方向"画箭头（应画生成方向）。
3. 以为离散就是有限（整数是离散且无限）。
4. 对连续变量问"某点概率"（恒为 0，应问区间）。
5. 用 MN 时忘记 Z。
6. 以为 MN 的势值就是概率。
7. 以为 MPE 等于"每个变量取最可能值"。
8. 以为联合最优可以由边缘分布拼出来。
9. 以为样本越多就一定越准（忽略相关性与权重退化）。
10. 以为 MH 拒绝率高就是"证据强"（可能只是提议不合适）。

## 14. 与相邻领域的定位（个人延伸）

- **BN / MN**：固定变量集、固定结构的概率模型。MN 的负对数势即 MRF 的能量项，所以"**MRF 能量最小化**"与"**MN 后验最大化**"是同一件事的两种写法。
- **概率编程**：解除"结构固定"限制——对象数量可随机（开放宇宙）、关系可不确定、结构可随时间变化。
- **推理算法**：VE/BP 是"编译期优化"，抽样是"运行时采样"。模型越贴合算法，跑得越快——这正是第 6、7 章反复强调的"为推理而设计模型"。
