# 图像恢复（MN + MPE）的可运行实现

《概率编程实战》第 5 章建的马尔科夫网络模型（一元势 亮 0.4 / 暗 0.6，二元势
同色 0.9 / 异色 0.1），在第 12 章被当作 MPE 的标准试验台。这里把它落成纯 Python
实现，书中用 Figaro 一行 `MPEVariableElimination()` 带过的部分，这里逐个算法展开。

原理见 [概率编程实战-算法笔记](../概率编程实战-算法笔记.md) §3.6 / §8.2，
Figaro API 对照见 [概率编程实战-复现笔记](../概率编程实战-复现笔记.md) 实验 5。

## 文件

| 文件 | 内容 |
|---|---|
| `mrf_image.py` | 模型：一元势、二元势、观测噪声信道、能量 `E(X) = -log P(X|Y)` |
| `mrf_inference.py` | 四种推理：精确 VE、精确行 DP、loopy BP、MH + 模拟退火 |
| `run_demo.py` | 三个实验的对照脚本 + ASCII / PNG 可视化 |

## 运行

```bash
pip install -r requirements.txt
python run_demo.py                  # 实验 A + B + C，输出对照表并写 out/*.png
python run_demo.py --only-b         # 只跑校准后的去噪实验
python run_demo.py --n 11 --beta 0.35 --noise 0.25 --big 32
```

## 三个实验与结论

**A 用书中字面的数值求 MPE → 全暗图。** 一条异色边的代价 `log(0.9/0.1) = 2.197`，
而单个像素的证据只有 `log(0.8/0.2) = 1.386`，平滑必然压倒证据。势只定义相对大小
（§3.4 的 ceteris paribus），没有绝对尺度，所以 `0.9/0.1` 必须和似然一起调。

**B 把平滑强度调到 `beta = 0.4` 后去噪生效。** 10×10、噪声 0.2（观测错 19 像素）：

| 方案 | 错像素 | 能量 E |
|---|---|---|
| 先验 MPE（无证据） | 36 | 143.366 |
| 观测图（未去噪） | 19 | 161.630 |
| 逐像素边缘阈值 | 10 | 146.392 |
| **精确 VE MPE** | **4** | **141.391** |
| 行 DP MPE（独立校验） | 4 | 141.391 |
| loopy BP | 4 | 141.391 |
| MH + 退火 | 4 | 141.391 |

MPE 与边缘阈值解差 8 个像素、能量低 5.002 —— 逐像素最可能拼不出联合最优，
这就是 §8.2 "MPE = 联合最优 != 每个变量各自边缘最优" 的可算证据。

**C 32×32 时 VE 不可行。** 网格树宽 = 32，最大因子 `2^33 ≈ 8.6e9` 行；只能换
BP（14 轮收敛，错 180/1024）或 SA（错 181/1024），两者能量只差 0.17。

## 两个容易踩的点

- **BP 收敛 ≠ 算对。** 在 beta 偏大时 BP 会停在一个能量更高的不动点：某些设置下
  BP 输出的图"看着更像真值"，但后验比精确 MPE 低（例如 beta=0.5 的 6×6 方块，
  VE 给全暗 E=145.26，BP 给 6 个错像素 E=148.33）。判据是能量，不是像素相似度。
- **平滑势与图像结构要匹配。** 1 像素宽的细线在 Ising 先验下几乎必然被抹掉，
  所以测试图用实心块；这不是算法问题，是模型选择问题。
