# 科技创新"照亮"强国之路

"必须坚持科技是第一生产力，人才是第一资源，创新是第一动力"党的二十大报告中关于科技创新的表述引发了强烈的共鸣。科技引领着新兴产业发展，也助推了传统产业的升级，为我国的高质量发展提供了强劲的动能。但科技竞争就像短道速滑，我们在加速，人家也在加速，最后要看谁速度更快、谁的速度更能持续。为了能在科技创新的比赛中取得领先，我们需要建设重大科技创新平台，需要不断提升人才的数量和质量，需要完善的科技创新体制机制。

重大科技创新平台是科技创新可靠的支撑。重大科技创新平台集聚高端创新资源，是解决经济社会发展和国家安全的重大科技问题的物质技术基础。它们承担国家重点研发计划项目，支持顶尖科学家进行科技攻关，突破前沿基础科学问题，在重点领域实现自主可控。紫金山实验室参与主办的全球 6G 技术大会吸引了国内外国内外顶尖专家学者。为全球科技合作与协同创新"架桥铺路"，使我国能在移动通信技术领域延续 5G 领跑的优势。所以加快建设重大科技创新平台对于提高科技创新整体效能至关重要。

人才资源是科技创新最急需的资源。科技创新的竞争说到底就是人才的竞争，只有拥有足够质量和数量的人才资源才能保持速度。
Y 市经开区坚持人才引领不动摇，把人才和创新工作始终摆在重要议事日程常抓不懈。在愈演愈烈的"抢人大战"中，经开区也拿出真金白银和优惠政策吸引人才。如今经开区已成为 Y 市经济发展主阵地，科技创新的主战场，正是因为真心实意的"引才"，才让 Y 市的科技创新"名声"越来越响。
 
完善的体制机制是科技创新坚实的保障，党的十八大以来，以习近平同志为核心的党中央把创新作为引领发展的第一动力。
只有重视科技文化的宣传，才能保持全社会科技创新的活力。
 C市通过在轨道交通站点开展公益宣传活动，讲述 C 市创新故事，弘扬科学家精神，传承科技创新的气质与精神，让科技创新在全社会蔚然成风。

我们已经有了重大科学装置，人才，机制。我国已在多个领域取得重大成果，进入了创新型国家行列。如今，我国已进入新的发展阶段，我们要卯足干劲，科技自立自强没有捷径可走，没有外力可依，唯有顽强拼搏！
