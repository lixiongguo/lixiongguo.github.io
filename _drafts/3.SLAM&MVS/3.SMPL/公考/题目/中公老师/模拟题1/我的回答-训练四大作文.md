# 科技创新"照亮"强国之路

"必须坚持科技是第一生产力，人才是第一资源，创新是第一动力"党的二十大报告中关于科技创新的表述引发了强烈的共鸣。科技引领着新兴产业发展，也助推了传统产业的升级，为我国的高质量发展提供了强劲的动能。但科技竞争就像短道速滑，我们在加速，人家也在加速，最后要看谁速度更快、谁的速度更能持续。我们就要着力强化重大创新平台建设，努力开拓人才资源，做好科技创新文化的宣传。

重大科技创新平台是最坚实的“跑道”。加快建设重大科技创新平台对于提升科技创新整体效能至关重要。紫金山实验室作为 J 省重大创新平台的"领头羊"，其参与主办的全球 6G 技术大会吸引了国内外国内外顶尖专家学者。为全球科技合作与协同创新"架桥铺路"，为举办地 N 市乃至 J 省在 6G 赛道上开足"马力"点燃强引擎。使我国能在移动通信技术领域延续 5G 领跑的优势。同时，紫金山实验室将继续牵头承担国家重点研发计划项目，支撑顶尖科学家科研攻关，突破核心关键技术，实现国家科技自立自强。

人才是持续的“动能”。科技创新最急需的是人才资源。Y 市经开区坚持人才引领不动摇，把人才和创新工作始终摆在重要议事日程常抓不懈。在愈演愈烈的"抢人大战"中，经开区也拿出真金白银和优惠政策吸引人才，如今经开区已成为 Y 市经济发展主阵地，科技创新的主战场，多项科技人才指数均保持领先地位。

机制是坚实的保障，完善的科技创新体制机制将为加快实现这一战略选择提供坚强制度保障。
只有重视科技文化的宣传，才能保持全社会科技创新的活力。C 市通过在轨道交通站点开展公益宣传活动，讲述 C 市创新故事，弘扬科学家精神，传承科技创新的气质与精神，让科技创新在全社会蔚然成风。

党的十八大以来，以习近平同志为核心的党中央把创新作为引领发展的第一动力。经过多年的艰苦奋斗，攻坚克难，我国已经在一些关键核心技术实现突破，多个领域取得重大成果，进入了创新型国家行列。如今，我国已进入新的发展阶段，我们要卯足干劲，科技自立自强没有捷径可走，没有外力可依，唯有顽强拼搏！
