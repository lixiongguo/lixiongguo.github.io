# 常用对策

## 一、解题步骤

1. **审题、找点**
   对策 7 词：问题、原因、经验、教训、优势、需求 ＋ 直接对策

2. **梳理合并**
   合并问题 / 必要举措维度（明确大致有几个点）

3. **分配格数**
   计算各要点大致占格、各要点可能分值

4. **匹配现成对策**
   梳理材料现成对策、经验，匹配现有问题；估算现成信息占格，剩下自行补齐

5. **调整逻辑**
   - 判断答案逻辑顺序的必要性
   - 优化大逻辑（要点顺序）＋ 小逻辑（要点具体内容、表达）

## 二、常用对策思路积累

### a. 思想观念问题 → 加强宣传教育

- **方式**：先考虑细化必要性、特定要求
  - 线下：宣讲会、培训班、横幅标语、文化墙
  - 线上：公众号、短视频、村村通广播
- **内容**：针对材料的问题、要求、需求
- **目的**：提认识、转观念、造氛围

### b. 制度机制问题 → 健全完善规则

| 情形 | 做法 |
|---|---|
| 缺制度 | 建章立制，填补空白 |
| 有制度 | 细化规定，量化标准 |
| 制度软 | 加大违法成本，强化刚性约束 |

> 常展开内容：针对问题。

### c. 执行监督问题 → 狠抓落地见效

- **三个抓手**
  - 组织领导：成立专班，责任到人
  - 过程管控：定期督导，通报约谈
  - 考核问效：纳入绩效，奖优罚劣
- **监督方式**：明察暗访、专项整治、媒体曝光、群众举报
- **全过程逻辑**
  - 源头：提高 / 合理设置门槛
  - 中期：细化标准要求，提高巡查考核的频率与力度
  - 后期：提高违法违规成本

### d. 资源保障问题 → 统筹人财物技

#### 人

引才、育才、用才、留才

1. **引才**：破除制度壁垒；补齐基础设施、服务短板；完善就业创业机会与服务；以情怀、优势宣传；优惠政策
2. **育才**：教——专项培训、教育；帮——提供资源、平台
3. **用才**：人岗匹配——安排、引导；给予自主空间（如容错纠错机制）与各类支持（资源：人、钱、物、权）
4. **留才**：落实、更新保障和服务；情感留人

#### 财

财政拨款、专项补贴、社会资本、惠农贷款

1. **自己**：自愿筹资（分摊、乡贤捐赠）；循序发展，聚焦主要矛盾（突出问题 / 优势）
2. **社会**：有条件——招商引资、合作、赞助等；无条件——慈善
3. **政府**：直接——专项资金、特殊补贴救助等；间接——以奖代补、金融支持（低息免息贷款）、政府购买服务

#### 物

完善设施、升级设备、数字化改造

1. 盘活资源：闲置、多功能、线上线下共享
2. 修复维护
3. 采购、升级

#### 技

引入成熟技术、专家指导、技能培训

## 三、对策展开公式

> ① 材料现成内容或暗示内容（关键词要全）
> ＋ ② 自行展开（横向或纵向逻辑）
