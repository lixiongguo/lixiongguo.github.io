# 知识点九 · 真题5 · 大作文分论点

来源：《2027 考季 京考 199 讲义（三期）- 知识点九 - 大作文学习》

## 题干

> 「给定资料 5」中提到「我们要用积极的态度对旧事物的价值进行最大挖掘，让它们重新焕发生机」。请你对此进行深入思考，参考给定资料，自选角度，自拟题目，写一篇文章。（35 分）
>
> 要求：（1）观点明确，见解深刻；（2）参考给定资料，但不拘泥于给定资料；（3）思路清晰，语言流畅；（4）字数 1000～1200 字。

## 题干四要素（拆句所得）

| 提示词 | 句子成分 | 实质 |
|---|---|---|
| 积极的态度 | 状语 | 认识前提——先破「旧即落后」 |
| 旧事物的价值 | 宾语中心 | 对象内容——价值是多元的 |
| 最大挖掘 | 谓语 | 方法路径——修复、再造、进生活 |
| 重新焕发生机 | 结果补语 | 落点标准——被继续使用 |

四个词不是四个分论点。按「前提 → 基础 → 落点」合并为三段，才能压住 1000～1200 字。

## 词语含义（材料怎么用，就是什么意思）

| 词语 | 含义 | 依据 |
|---|---|---|
| 积极的态度 | 主动发现、平等看待、带着感情，不先当「破烂儿」 | 「眼缘」、「别等到下一代都不认识了」、「朝圣」般修复 |
| 旧事物的价值 | 经济 + 技艺 + 情感 + 审美四重并存；旧是时间刻度，不是价值判决 | 可售卖谋生；马车无钉；承载记忆；古朴美感 |
| 最大挖掘 | 修复 → 造场景 → 回日常 → 技艺复活，不止于变现 | 手工修复；旧物文化空间；「最好的存续方式是进入日常」 |
| 重新焕发生机 | 器物与人的关系被重建：被需要、被使用、被喜欢 | 「重新放回到现在的生活中」 |

**三个易错点**

- 态度写成「乐观心态」——它是价值判断，不是情绪；
- 挖掘写成「开发变现」——丢了技艺与情感；
- 生机写成「保护收藏」——封存恰恰是生机的反面。

**逻辑链**：态度（怎么看）→ 价值（有什么）→ 挖掘（怎么做）→ 生机（算不算成功）。

## 资料 5 要点

| 序号 | 内容 | 可用角度 |
|---|---|---|
| 1 | 「旧物的故事」特展；陈先生 2017 年建旧物基地，展示、修复、售卖 | 载体 |
| 2 | 最初为谋生，后看「眼缘」，认为真老物件「需要被保存下来，别等到下一代都不认识了」 | 态度转变 |
| 3 | 村民老张：「你们要是晚点来可能就没了，我刚想过几天把这堆东西扔掉」；乡村「生活革命」，旧家具被视为落后 | 观念误区 |
| 4 | 旧物文化空间：老物件与新中式家具组成生活场景，「老物件最好的存续方式就是进入人们的日常生活之中」 | 关键论点 |
| 5 | 王师傅修马车，通体不用一根钉子，「放眼当下没有一个木匠可以做出来」；修复靠双手，「主要是感情」 | 技艺与情感 |
| 6 | 器物有灵性，汇聚人生细碎时光、承载记忆；「旧物不一定都是被废弃淘汰的『破烂儿』」 | 价值内涵 |

## 公式

**分论点。 + 解释分论点。 + 道理论证。 + 举例论证。 + 回扣分论点。**

## 中心论点

对待旧物，当以积极的态度代替嫌弃的目光，全面认识其经济、文化、技艺与情感价值，通过修复、再造与融入生活实现最大挖掘，让老物件在新时代重新焕发生机。

## 分论点一：以积极的态度看待旧物，是焕发生机的前提

所谓积极，不是猎奇式的怀旧，而是承认老物件有被重新认识的可能，先把它从「破烂儿」的位置上取下来。观念决定存废：一旦把旧物等同于落后，它连被看一眼的机会都没有。陈先生在村里收旧物，老张领他进杂物室时那句话最刺人——「你们要是晚点来可能就没了，我刚想过几天把这堆东西扔掉」；而在陈先生眼里，那些掉色的柜子「是需要被保存下来的，别等到下一代都不认识了」。同一件器物，两种目光，两种命运。可见，态度一转，旧物才有活路。

## 分论点二：全面认识旧物的多重价值，是最大挖掘的基础

旧物之「旧」是时间的刻度，不是价值的判决：它既有可流通的经济价值，也凝结着一代人的手艺、一个地方的风俗与一家人的记忆。只看经济价值，必然低估；看全了，才谈得上挖掘。王师傅修复的那辆马车通体不用一根钉子，他断定「放眼当下没有一个木匠可以做出来」，这是技艺的价值；陈先生说「每一件旧物都汇聚了人生的细碎时光，承载了主人的记忆」，这是情感的价值。价值认定得越充分，挖掘的方向才越清楚。

## 分论点三：让旧物重回日常生活，是重新焕发生机的根本

旧物最好的存续方式不是锁进库房、摆进玻璃柜，而是被继续使用、继续被需要——被需要，才不会被遗忘。陈先生的旧物文化空间把老物件与新中式家具组成一个个生活场景，让人一眼看到「摆这些东西不是落后不是老土，而是有一种古朴的美感」；故宫把馆藏纹样做成文创，舞剧《只此青绿》让宋画走上舞台，798 的老厂房改成美术馆——旧物一旦进入当代生活，就从被保护的「遗产」变成被使用的「资源」。可见，最大挖掘的落点，是让旧物重新有用、重新被喜欢。

## 公式对照

| 环节 | 分论点一 | 分论点二 | 分论点三 |
|---|---|---|---|
| 分论点句 | 积极态度是前提 | 认清价值是基础 | 重回生活是根本 |
| 解释 | 积极≠怀旧，是取下「破烂儿」标签 | 「旧」是时间刻度，不是价值判决 | 存续靠使用，不靠封存 |
| 道理 | 观念决定存废 | 只看经济价值必然低估 | 被需要才不被遗忘 |
| 举例 | 老张要扔橱柜、陈先生留旧物 | 王师傅的马车（无钉）、器物的记忆 | 旧物文化空间、故宫文创、《只此青绿》、798 |
| 回扣 | 态度一转才有活路 | 价值看清才谈挖掘 | 有用才叫焕发生机 |

## 开头示范

> 一只掉色的旧橱柜，在村民眼里是该扔掉的「破烂儿」，在旧物修复者眼里却是「别等到下一代都不认识了」的老物件。同一件东西，判若两物，差别只在目光。让旧物重新焕发生机，需要的正是这样一种积极的态度：先承认它有价值，再想办法把价值挖出来，最后让它回到人的生活里去。

## 写法备注

- 题干是「四要素句」，**不要写成四段**，否则 1200 字装不下，且「挖掘」与「生机」本是手段与结果，硬拆会重复。
- 三个分论点句统一为「……是……的前提 / 基础 / 根本」，句式一致拿结构分。
- 材料全是「陈先生—老张—王师傅」的人物细节，**开头和正文都够用**，是真题1、4 里少见的「材料自带人例」题型，答题时应尽量吃透材料，不必外求太多。
- 材料外只补一层「进入当代生活」的例子（文创、舞剧、老厂房改造），避免通篇复述材料。
