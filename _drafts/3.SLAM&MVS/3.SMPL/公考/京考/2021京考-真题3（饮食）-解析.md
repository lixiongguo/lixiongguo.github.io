## 四、分论点

### 中心论点

> 求食塑人，食风塑魂：食物是生存的物质基础，更是一方人精神气质的载体。

### 两个分论点

| | 分论点句 | 释义（材料原词） | 段内任务 |
|---|---|---|---|
| 一 | **人们寻求食物的过程，也影响着人们自身。** | 求食＝向自然争取、向极限拓荒 | 讲**品格**：坚韧、创造、不服输 |
| 二 | **一个地域的饮食风貌，塑造着那方土地的精神气质。** | 食风＝工序、形态、仪式里的审美与记忆 | 讲**情趣与记忆**：勤劳智慧、家庭味道、审美 |

### 每段展开要点

**分论点一（塑人）**

- 解释：求食不是张嘴吃饭，是把不可能变成可能的过程。
- 道理（推理）：向盐碱地要粮 → 反复试种 → 一次次失败 → 技术与心性同时长出来（可搭三座桥）。
- 举例：格尔木 2800 米盐碱地种出海水稻；袁隆平「每天都要到田里去」，把突破称作「拓荒人精神」。
- 回扣：所以「爱国就是让粮食增产」不是口号，是在田里一天天磨出来的品格。

**分论点二（塑魂）**

- 解释：饮食风貌不只关乎口味，它是审美、伦理与记忆的容器。
- 道理（正反）：只把食物当热量，吃的是饭；把食物当仪式，吃出的是家风与乡愁。
- 举例：黄粑 20 小时工序里的耐心；象形糕点「对生活情趣的审美」；宁波年糕让宁宁记住「家庭的味道」。
- 回扣：食物传递的是精神力量——段 13 的总纲句放在此处收口。

### 段末升华（可选，衔接马达加斯加）

> 一碗米饭走到哪里，就把「靠自己养活自己」的底气带到哪里：兰德尔一家从茅草屋搬进红砖房，中国水稻在异国「生根开花」，续写的是稻作文明的新篇章。

## 五、首段要点（只给公式与填什么）

公式：**背景 → 解释题干 → 中心论点的逻辑 → 因此 → 中心论点**（150—200 字，论点落在最后一句）

| 步 | 本题填什么 |
|---|---|
| 背景 | 一句具体的吃食场景（一碗米饭／一块年糕／一屉黄粑），落到人 |
| 解释题干 | 把画线句翻成白话：求食改变人，食风塑造人 |
| 中心论点的逻辑 | 说清两个分句的关系——**一个管「人怎么被塑造」，一个管「地方怎么塑造人」**，即「过程」与「风貌」两个入口，都通向「精神」 |
| 因此 | 一句因果词 |
| 中心论点 | 求食塑人，食风塑魂 |

**注意**：本题不要写成「粮食安全」开篇——那会把文章拉到物质层，画线句的两个分句一个都接不住。

## 六、易错点

1. **凑第三分论点**（如「食物促进文明互鉴」）——画线句只有两个意思；「传递」只能作论据或结尾。
2. **通篇写粮食安全、科技兴农**——只答了材料里的物质层。
3. **两个分论点都写「食物很重要」**——必须分工：一个讲品格，一个讲审美与记忆。
4. **只举袁隆平**——第二段会空；反过来只用黄粑、年糕，第一段会空。四个分区各取所需。
5. **把段 13 总纲句当分论点**——它是「合」，写进段尾或结尾最有力，单独成段会与第二段重复。
