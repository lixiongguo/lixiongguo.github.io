## 一、审题要点

| 项 | 内容 |
|---|---|
| 题型 | 句子观点类（划线句，自拟题） |
| 题眼 | **科学、艺术、古文化**（三个并列词）＋ **源泉**（不是「助力」，是从哪里来） |
| 意思个数 | 三个，一一对应三个分论点 |
| 要害 | **三个并列词一个都不能漏**，缺项即偏题 |

**三个致命偏题方向**：把「想象」写成「创新」（两题不同——本题问想象从哪来，不是创新多重要）；把三源写成「要重视科学／要重视艺术／要重视文化」（那是三个「重视」，不是三个「源泉」）；只写古文化一段而略过科学与艺术。

## 三、分论点

### 中心论点

> 想象力是穿越未来的核心能力，而它并非凭空而生——科学给其骨架、艺术给其羽翼、古文化给其根系，三源汇流，方成不竭的创造力。

### 公式

**分论点 ＋ 解释分论点 ＋ 道理论证 ＋ 举例论证 ＋ 回扣分论点。**

### 分论点一：科学为想象力立起理性骨架，使其不流于空想

想象并非凭空玄想，而是在已有形象之上重组新形象，科学提供的正是这套重组所需的原料与规矩。知识越多元丰富，可资想象的素材越充足；敢于质疑、不断证伪，才可能突破既有认知的边界。波普尔以「证伪主义」刷新人类认识——科学精神的核心不是重复验证，而是敢于批判；爱因斯坦设想自己骑在一束光上，这一近乎游戏的想象，最终由物理学给出了答案。可见，科学的求真为想象校准了方向，使天马行空也落得下地。

### 分论点二：艺术为想象力插上审美羽翼，使其不止于功利

艺术是代表美的精神力量，贯穿于人类发展的全时空，它训练的是形式感、通感与共情，而这恰是想象最需要的语言。道理在于：想象若只求有用，便只能重复既有功能；唯有对美敏感，才能看见事物「还可以是什么样」。达·芬奇一面解剖、一面描画，科学与艺术在同一双眼中互相点燃；乔布斯大学时旁听书法课，把字体的疏密与美感带入个人电脑，让技术第一次有了「好看」这个维度。可见，艺术让想象不满足于「可用」，而追求「可感、可美」。

### 分论点三：古文化为想象力扎下深厚根系，使其不失其本

历经多少世纪而留存下来的古文化，蕴含着需要想象力才能充分挖掘的智慧与秘密，它是想象力永不枯竭的源泉。一个民族的想象有其文化传统的优势可依托，古典文学与传统艺术中的意象，往往先于技术抵达未来。屠呦呦从葛洪《肘后备急方》「青蒿一握，以水二升渍，绞取汁」中悟出低温提取之法；屈原《天问》叩问天地，两千余年后「天问一号」落于火星；敦煌飞天衣带当风，今日化作舱外行走的航天员。可见，向古文化深处取水，想象才有源头活水。

### 结尾合流（可选）

科学求真、艺术求美、古文化求根，三者不是并列的三条路，而是同一源泉的三层：根系愈深、骨架愈正、羽翼愈丰，一个人方能穿越未来，一个民族方能始终拥有不被替代的创造力。

### 公式对照

| 环节 | 分论点一 | 分论点二 | 分论点三 |
|---|---|---|---|
| 分论点句 | 科学立理性骨架 | 艺术插审美羽翼 | 古文化扎深厚根系 |
| 解释 | 想象是素材重组，科学给原料与规矩 | 艺术训练形式感与共情 | 文化意象先于技术抵达未来 |
| 道理 | 知识越多元、质疑越彻底，想象越有据 | 只求有用只能重复功能 | 文化基因决定想象的独特性 |
| 举例 | 波普尔、爱因斯坦 | 达·芬奇、乔布斯 | 屠呦呦、《天问》与天问一号、敦煌飞天 |
| 回扣 | 求真使想象落地 | 求美使想象超越功利 | 求根使想象有源不竭 |

## 四、首段要点（只给公式与填什么）

公式：**背景 → 解释题干 → 中心论点的逻辑 → 因此 → 中心论点**（150—200 字，论点落在最后一句）

| 步 | 本题填什么 |
|---|---|
| 背景 | 一句 AI 时代的具体场景（AI 能写诗、能配图），引出「人还剩什么」 |
| 解释题干 | 用材料段 2 的定义句释「想象力」，再把「源泉」翻成「从哪里来」 |
| 中心论点的逻辑 | 三个词不是三样东西，而是**三种给养**：科学给规矩、艺术给形式、古文化给基因，缺一样想象就会偏（可接缺失论证） |
| 因此 | 一句因果词 |
| 中心论点 | 三源汇流，想象不竭 |

## 五、写法备注与易错点

- 三个分论点用同一句式（「为想象力……，使其不……」）保证对仗。
- 举例以材料为底、材料外加一层：材料给「波普尔、庄周、屈原、敦煌」，材料外补「屠呦呦、乔布斯、天问一号」，做到「参考材料而不拘泥材料」。
- **易错**：把「想象力」写成「创新精神」。
- **易错**：三个分论点写成「要重视科学／要重视艺术／要重视文化」。
- 题目可自拟为《三源汇流，想象不竭》或《给想象以根、以翼、以骨》。
