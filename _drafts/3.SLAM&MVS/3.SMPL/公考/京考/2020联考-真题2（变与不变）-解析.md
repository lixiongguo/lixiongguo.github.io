## 一、题目

> 给定资料中提到村民眼中的变和小孙心中的不变，根据你对此的理解，以「变与不变」为话题，自选角度，自拟题目，写一篇文章。（40 分，800—1000 字）

## 二、题干是「一材料两指涉」

| 侧 | 谁在看 | 指什么（材料原词） |
|---|---|---|
| **村民眼中的变** | 群众视角 | 「再也不是那个靠天吃饭的穷地方」「年轻人回来了」「民心齐了，干部干劲足了、水平高了」 |
| **小孙心中的不变** | 干部视角 | 「作为一名共产党员，我的信念和情怀不会变」 |

**这不是两个抽象词的对举，而是两个主体的两种状态。** 写「万事万物都在变，也总有不变的」属空论；必须落到「谁变了、谁没变、为什么」。

## 三、材料 5 的两份清单

| | 证据 |
|---|---|
| **变**（面貌与方法） | 引水上山，改变几十年缺水状况；手工纺织、月嫂培训班；年猪推销换来 80 多万「过年钱」；用工业化理念引项目，5 个多月完成选址办证建厂培训；「村集体＋公司＋农户」纺织产业园；家门口就业，挣「薪金＋股金＋租金」；年轻人回流 |
| **不变**（信念与情怀） | 一眼结缘后「涌起一个强烈的念头」；主动请缨驻村；两个月走遍全村贫困户；顶着「一个城里女人能干啥」的风凉话干下去；「信念和情怀不会变」；梦想从脱贫扩大为「北方最大的坯布集散地」而未改其本 |

**注意材料 2 的伏笔**：岩山「花红柳绿、山清水秀」「淳朴的民风」是**本来就有的、没变的**——这也是一层「不变」，可在首段或结尾用一下，但不宜作为分论点（它不是题干所指的「不变」）。

## 四、审题三问

| 问 | 答 |
|---|---|
| 题眼是哪几个词 | **村民**（变的主体）、**小孙**（不变的主体）、变与不变 |
| 有几个意思 | 两个：该变的（方法·面貌）／不该变的（初心·信念） |
| 什么关系 | **相辅相成**：不变催生变，变又反哺不变（有回程箭头，不能只写单向） |

**题型判定**：双话题关系型（以「A 与 B」为话题）。按 5.2 双话题摆法，且用其**进阶写法**——第一段 A→B，第二段 B→A，第三段合流，段段都是互促。

## 五、分论点

### 中心论点

> 变与不变各有其位——方法与面貌必须变，初心与信念不能变；不变的初心催生山乡巨变，山乡巨变又反过来坚定不变的初心。

### 两个分论点

| | 分论点句 | 释义（材料原词） | 段内任务 |
|---|---|---|---|
| 一 | **不变的初心，催生山乡之变。** | 主动请缨、两个月走访、顶着风凉话干、跑市县乡要政策 | 讲**源头**：先有信念，才有动作 |
| 二 | **山乡之变，反哺不变之心。** | 「民心齐了、干劲足了、水平高了」→「信心更强了」；梦想从脱贫到「北方最大的坯布集散地」 | 讲**回程**：成效给信念以印证 |

### 每段展开要点

**分论点一（不变→变）**

- 解释：不是有了钱才办事，是有了那股劲才去想办法。
- 道理（推理搭桥）：信念＝把贫困村的事当自己的事 → 才会主动请缨、扎根驻村 → 才会两个月走遍全村找穷根 → 才会为十几个落地问题跑市、县、乡 → 项目才落得下来 → 面貌才开始变。
- 举例：引水上山解决几十年缺水；80 多万「过年钱」；5 个多月建成产业园。
- 回扣：所以**变化是从「那一天」开始的**——村民的原话已把因果关系说破了。

**分论点二（变→不变）**

- 解释：看不到结果的情怀容易消解，看到结果的情怀才更结实。
- 道理（正反）：只付出没回响——「一个城里女人能干啥」的质疑会把人劝退；付出有回响——民心齐了、干部水平高了，她「帮助村民脱贫致富的信心更强了」，梦想也随之扩大。
- 举例：从脱贫梦到「北方最大的坯布集散地」；「信念和情怀不会变」这句话出现在梦想变大之后，正是被变化印证过的表白。
- 回扣：所以**变把不变坐实了**，两句话在文中一前一后，位置本身就是论证。

### 关系段（第三主体段，4.4 回程箭头收口）

> 不变与变，是一个正向循环：初心给变化以方向，变化给初心以印证。守着初心却不改办法，是空有情怀；只顾求变却丢了初心，是走偏了路。岩山的可贵，正在于两头都在：既肯为十几个落地难题跑遍市县乡，也在梦想变大时说一句「信念和情怀不会变」。

### 进阶写法（想拿一等，可把「该变／不该变」做成一对残缺，4.3）

> **该变的不变，是停滞**：守着靠天吃饭的老办法、老作物、老销路，风景再好也富不起来。**不该变的变了，是走偏**：为了短期数字硬上项目、丢了为民本色，厂房盖起来了，人心却散了。岩山之变，恰恰变在该变处、守在该守处。

两句话对举、句式对称，比「二者缺一不可」有力得多。

## 六、首段要点（只给公式与填什么）

公式：**背景 → 解释题干 → 中心论点的逻辑 → 因此 → 中心论点**（150—200 字，论点落在最后一句）

| 步 | 本题填什么 |
|---|---|
| 背景 | 一个具体场景：山绿了、水通了、年轻人回来了；或初到村里听到的那句「一个城里女人能干啥」 |
| 解释题干 | 用材料原词解两侧：村民的变是面貌与人气，小孙的不变是「信念和情怀」 |
| 中心论点的逻辑 | 变不是凭空来的，是被不变的初心推着来的；不变也不是凭空的，是被看得见的变印证着的 |
| 因此 | 一句因果词 |
| 中心论点 | 初心催生巨变，巨变坚定初心 |

**注意**：不要用「世界唯一不变的就是变化」开篇——这是与材料无关的哲学套话，接不上「村民」与「小孙」两个主体。

## 七、易错点

1. **把「不变」读成「不创新」**。材料的不变是信念情怀，方法恰恰要大变；读反整篇反转。
2. **写成脱贫攻坚成果总结**。只罗列引水、培训、招商、产业园，没有回答「变与不变是什么关系」。
3. **单边论证**。只写变（成就）或只写不变（信念），各丢一半题目。
4. **只写单向箭头**（4.4 禁忌二）。只写「信念带来变化」，不写「变化反过来坚定信念」，就退化成「很重要」。
5. **把材料 2 的「风景美、民风淳」当「不变」的主证**。它是伏笔，不是题干所指；主证必须是「信念和情怀不会变」。
6. **字数误判**。原卷 1000—1200 字，讲义按京考改为 800—1000；按讲义练，实战按卷面要求。
7. **联系实际空泛**。可用：驻村第一书记群体、黄文秀、张桂梅、北京对口帮扶、乡村振兴接力。

## 八、可用的「联系实际」素材

| 层 | 素材 | 能证明什么 |
|---|---|---|
| 不变→变 | 黄文秀回百坭村、张桂梅办女高、驻村第一书记群体 | 信念先于变化 |
| 变→不变 | 脱贫村年轻人回流、村集体经济从零到有、村干部能力提升 | 成效印证并坚定初心 |
| 该变的不变（反例） | 只卖原料不办加工、守着老品种不改 | 停滞 |
| 不该变的变了（反例） | 硬上项目搞形象工程、只算数字不算民心 | 走偏 |
