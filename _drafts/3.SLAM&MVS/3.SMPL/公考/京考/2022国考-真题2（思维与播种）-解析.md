# 2022 国考（副省级）· 真题2（思维与播种）解析

## 一、中心论点：两种写法，建议 B

| | 写法 | 判定 |
|---|---|---|
| A | 今天的思维和播种，决定了我们未来收获。 | 原句照抄，合格但扁平：两个词并列作主语，读者看不出二者什么关系 |
| B | **今天的思维决定播种，进而影响未来的收获。** | 补出「思维→播种」这一跳，两个分论点之间立刻有了关系 |

**为什么 B 更贴材料**：材料紧接着说「以前瞻性思考决定今天干什么、怎样干、如何取舍」——**思维是在决定播种的内容**，不是与播种并列。B 只是把材料这句翻成了因果链。

**用 A 也可以**，但首段「中心论点的逻辑」那一步必须自己补出这层因果，否则两个分论点会写成两段各说各话。

## 二、主体结构：两分论点 ＋ 一段关系段（2＋1）

**关键判断：不是「两个分论点不够」，而是「两个分论点必须配一段关系段」。**

只写思维、播种两段，每段要撑到 400 字以上，段内「解释—道理—举例—回扣」四步容易写散；补上第三段（二者关系），三段各约 300 字，结构立刻匀称，字数也刚好落在 1000—1200。

| 段 | 分论点 | 任务 |
|---|---|---|
| 一 | 今天的思维，决定了我们未来收获 | 讲**意识**：想得远，才走得对 |
| 二 | 今天的播种，决定了我们未来收获 | 讲**行动**：肯下种、熬得住，才有积累 |
| 三 | **思维与播种相辅相成，缺一不可** | 讲**关系**：有思无行、有行无思都走不通 |

三段的字数配比：开头 150 ＋ 三段各 280—300 ＋ 结尾 100 ≈ 1100 字。

## 三、三段正文

### 分论点一：今天的思维，决定了我们未来收获

> 今天的思维，决定了我们未来收获。这里的思维，是面向未来的前瞻性思考——不是预测明天会怎样，而是决定今天把力气放在哪里。想得远的人，做事有规划、有目标，能站在未来倒推今天；只盯着眼前的人，走一步看一步，容易被突发的问题牵着走。有规划也不意味着一路顺遂：遇到难题时，清晰的方向让人不慌，能一件一件拆开解决；一帆风顺时，长远的打算又让人不掉以轻心，不会把一时的成功当成终点。顺境逆境都按部就班，积累才会发生。B 公司正是如此——它不是等市场成熟了才动手，而是提前判断技术路线、持续投入研发，最终在内燃机技术上实现突破、遥遥领先。可见，先有前瞻的思考，力气才不会用错地方，未来的收获才有来处。

**写法说明**：本段用的是 5.4 的正反论证，且**顺境与逆境两侧都写到**（难题／顺遂），这是与「只写遇到困难怎么办」的粗稿最大的差别（详见第四节）。

### 分论点二：今天的播种，决定了我们未来收获

> 今天的播种，决定了我们未来收获。播种不是撒下种子就等天收，而是把有限的资源在今天押到尚未兑现的地方：钱投在哪、人放在哪、时间花在哪，决定了十年后手里有什么。这一步的难处在于「不见效」——基础研究、生态修复、人才培养，都要经过很长一段只有投入、没有产出的沉默期。肯熬的人，让投入在时间里复利；不肯熬的人，只能摘别人种下的果子，摘完就没有了。塞罕坝三代人用六十年把荒原种成林海，第一代人只见成活、不见成林，收获落在第三代手里；今天的核心技术攻关，同样是十年前就开始下的种。可见，播种的意义不在当年的收成，而在它提前把「未来能收什么」定了下来。

**写法说明**：本段用 5.5 的推理论证搭三座桥——**播种即取舍 → 取舍带来持续投入 → 投入穿越沉默期才成积累**。第三座桥（沉默期）是全段的分量所在：没有它，「播种」就和「努力」混为一谈。

### 第三段（关系段）：思维与播种相辅相成，缺一不可

> 思维与播种，如一体两面：思维是收获的先决条件，播种是收获的必然条件。有思维而无播种，再好的判断也只是纸上蓝图——想得再远，落不了地，就成了思想上的巨人、行动上的矮子，一切终归空谈；有播种而无思维，力气使得再足也像航船没有航标，方向一旦错了，越努力离目标越远。二者更是相互塑造：有怎样的思维，才决定播下什么种子；播下什么种子，又反过来检验思维是否真的前瞻。古人讲「知为行之始，行为知之终」，说的正是这个道理。可见，面向未来不是只想不做，也不是只做不想，而是让思考为行动定向、让行动为思考作证。

**写法说明**：本段用 5.6 的缺失论证，三句话完成——① 有思维无播种 → 空谈；② 有播种无思维 → 无航标；③ 定关系（相互塑造）。**只喊「二者都重要」是表态，写出两种残缺形态才是论证。**

## 四、正反怎么写才不落空：方法一 vs 方法二

**方法一（只有「逆境」一条线）**

> 当有前瞻性的思考，就会做事有规划、有目标，能够站在未来去做出合理的计划。在发展的过程中难免会遇到各式各样的问题，有规划就会思路清晰，能够从容不迫地去面对这些挑战，有条不紊地去解决。跟着规划一件一件地去解决，一件一件地去做，那么不断积累，在不久的将来就会得到想要的成绩。

**方法二（把「顺境」也纳进来）**

> 当有前瞻性的思考，就会做事有规划、有目标，能够站在未来去做出合理的计划。在发展的过程中难免会遇到各式各样的问题，有规划就会思路清晰，能够从容不迫地去面对这些挑战，有条不紊地去解决。**而有的时候会一帆风顺，一直成功，有这样的长远规划就不会掉以轻心，遇到成功也会按部就班地发展。**不管遇到成功还是挑战，有这样的规划，都能够让未来有想要的结果。

**差别在哪**：方法一的「正反」实际只写了**逆境**一侧，顺境没处理；方法二把**顺与逆两种情形都覆盖**，正反才闭合。

> **规律**：正反不是「有／无」两个词，而是**把可能出现的两种情形都摆出来**——顺境与逆境、短期与长期、个体与整体。少一种，反例就落空。

## 五、搭桥链与类比示范

分论点二的推理链（也是本题最容易写出深度的一条）：

```
今天的播种（取舍）→ 资源持续押在一处 → 投入穿越「不见效」的沉默期 → 变成技术、人才、队伍 → 未来的收获
```

**类比示范**（说明「搭桥」长什么样）：

```
学好申论 → 笔试成绩高 → 面试更轻松 → 心态稳 → 综合成绩好 → 考上公务员
```

每一跳都是一个「因为所以」，读者不会问「凭什么」。写主体段时把链写出来，再配一个例子，就是完整的推理论证（见笔记 5.5）。

## 六、可套用的双向句式

范本：

> 现代让传统亲切鲜活，传统让现代丰富厚重。

这是「A 让 B……，B 让 A……」的**互相成就**句式，关系段可直接套：

> 思维让播种有方向，播种让思维有落地。

同类句式：「规划为治理找到坐标，治理为规划落笔成形」「科技让传统可感，传统让科技有根」。

## 七、首段要点（只给公式与填什么）

公式：**背景 → 解释题干 → 中心论点的逻辑 → 因此 → 中心论点**（150—200 字，论点落在最后一句）

| 步 | 本题填什么 |
|---|---|
| 背景 | 「正在发生的未来」的一句具体场景（无人驾驶、基因编辑已到眼前） |
| 解释题干 | 释义「思维」＝前瞻性思考；「播种」＝今天干什么、怎样干、如何取舍 |
| 中心论点的逻辑 | 二者不是并列：**思维决定播种的内容，播种把思维变成收获** |
| 因此 | 一句因果词 |
| 中心论点 | 用 B 式：思维决定播种，进而影响收获 |

## 九、易错点

1. **只写两段就收尾**——不是论点不够，是缺关系段，结构会显单薄。
2. **关系段写成空喊**——只写「二者缺一不可」，不给「有 A 没 B／有 B 没 A」两种残缺形态，等于没论证。
3. **两个分论点都写「很重要」**——必须分工：一个讲意识，一个讲行动。
4. **例子选错**——要「前瞻性规划／长周期投入」的例子，不要「坚守岗位、吃苦耐劳」类（袁隆平、张玉滚属「尽力」，不属「前瞻」）。
5. **写成「努力就有收获」**——废话论证，要有「时间差、复利、透支未来」的机理（参笔记 5.4 末尾判据）。
6. **材料三问被拆成三个分论点却又不写关系段**——那就是另一条路（一苇式），选一条走通即可，别混着写。
