## 一、审题立意

### 1.1 作文思路四步（讲义原版）

| 步 | 做什么 | 内容 |
|---|---|---|
| ① | 按题干**出题类型**定中心论点 | 句子观点类 → 这句话就是中心论点（可简写、可同义替换）；词语话题类；句子观点＋词语话题 |
| ② | 按中心论点**含几个意思**定分论点 | 一个意思／两个意思／三个意思（三个意思＝三个分论点）；单话题／双话题／三话题 |
| ③ | 去**针对性材料**找分论点关键词的含义 | 只读与该词相关的段落，不重读全篇 |
| ④ | 由分论点句决定**展开方向** | 重要性意义／原因／过程／阐述关系／对策 |

**三条补丁**（讲义未写，但京考实际需要）：

1. **①之前还要判一件事：标题给不给。**
   - 给整标题（命题）→ 立意已被锁死，只能辨关系；
   - 给半个标题（半命题，如 2021「文明的养成，重在＿＿」、2022「从『治未病』想到的＿＿」）→ **先补空**，补出的词就是中心论点；
   - 不给标题（自拟）→ 才轮到 ① 按类型定。
2. **②的「几个意思」看连接词，不看句子长短。** 既要…更要…（递进）／从…到…（转化）／以…为用（手段—目的）／分号顿号（并列）。三个意思彼此若有条件关系，就**不能写成三段并列**，要写成链。
3. **④之后还有一步：回扣。** 讲完必须同义替换收回分论点，一段才闭合；且 ④ 选哪种展开由 ② 的关系决定——并列→讲重要性，递进→讲过程与原因，双词→阐述关系。

### 1.2 比喻型题干怎么翻

以「创业者心中的山」为例：

- 「山」是**比喻**，不指实物，要先翻译成实义。
- 立意落在两点上：
  1. 像乔治·马洛里那样，对创业有**清醒认识**，敢于面对创业中的困难；
  2. 克服**急功近利**思想，为实现梦想而探索、攀登，坚信**创业没有失败者**。
- 判分口径：凡围绕上述两个方面展开论述的，均视为**认识深刻、立意明确**。

> 要点：比喻型题干 → 先把喻体翻成本体（困难、目标、坚持、心态），再判断命题人希望你谈哪几层。

## 二、阅卷方式

**整体观照，分等、分级赋分**：先定等第，再在等第内定分数，不是逐条扣分。

## 三、评分标准（40 分）

| 等第 | 分数 | 基准分 | 判定的五条要求 |
|---|---|---|---|
| 一等 | 36—40 | **38** | 符合题意；立意（写作角度、中心论点、主题思想）明确；思想深刻；论证严密；结构严谨、条理清楚、语言流畅 |
| 二等 | 26—35 | **30** | 符合题意；立意较为明确；思想较为深刻；论证较为严密；结构较为严谨、条理较为清楚、语言较为流畅 |
| 三等 | 16—25 | **20** | 不完全符合题意；立意较为模糊；内容肤浅、论证乏力；结构基本完整、条理基本清楚、语言基本通顺 |
| 四等 | 0—15 | — | 背离题意；找不到立意；结构混乱、条理不清、语言不通；拼凑、抄袭给定资料；通篇分条列项（类似细化提纲）；观点有严重错误 |

浮动规则：**基本具备本等条件 → 基准分；某一方面突出 → 适当加分；反之酌情减分。**

结论：一、二等的差别只在「程度词」——**明确 / 较为明确、深刻 / 较为深刻、严密 / 较为严密**。要拿一等，就是把「较为」两个字去掉。

## 四、文体：议论文（论点 · 论证 · 论据）

难点不在「写不写得完」，而在两件事：

1. 你**知道自己在论证什么**（中心论点、分论点是否立得住）；
2. 你**怎么论证清楚**（考官认可的那种清楚）。

## 五、结构模板（总—分—总）

### 5.1 段落与字数分配

| 段落 | 任务 | 字数 |
|---|---|---|
| 标题 | 写一个**完整的观点**，居中（标题写法在提升课讲） | — |
| 第一段 | 背景 + 解释题干 + 中心论点的逻辑 + 因此 + **中心论点** | 150—200 字 |
| 第二段 | 分论点一（主体段） | 约 250 字 |
| 第三段 | 分论点二（主体段，结构同上） | 约 250 字 |
| 第四段 | 分论点三（主体段，结构同上） | 约 250 字 |
| 结尾 | 背模板 + 回扣中心论点（**不太重要**） | 约 100 字 |

### 5.2 首段：分总结构，论点必须落在段尾

顺序固定：**背景 → 解释题干 → 中心论点的逻辑 → 因此 → 中心论点**。

- 「分」在前：铺垫、释义、讲道理；
- 「总」在后：**中心论点一定出现在首段最后一句**，不能提前、不能藏在中间。

**五步各写什么**：

| 步 | 写什么 | 字数 | 常见错误 |
|---|---|---|---|
| 背景 | 一句具体场景（某地做法、某个现象），落到可感的人或事 | 25—35 | 「随着经济社会发展」万能开头，零信息 |
| 解释题干 | 翻译比喻、给关键词**用材料原词**释义 | 35—50 | 变成了复述材料，抄一整段 |
| 中心论点的逻辑 | **说清几个意思是什么关系**（递进／手段目的／并列），为什么这样推 | 50—70 | **整步跳过，直接抛论点**——最致命，等于没解关系 |
| 因此 | 一个因果词，标出「由上文推出」 | 3—5 | 缺这层，前后像两段 |
| 中心论点 | 一句**可被反驳的判断**，≤35 字 | 25—35 | 藏在段中；段尾又补一句总结，造成错位 |

> 「分」的部分不能再出现与中心论点同义的话，否则最后一句就是重复。

**示范一（力／理／利，约 170 字）**：

> 行政执法一头连着法律的权威，一头连着百姓的冷暖。材料说执法要讲「力」「理」「利」，讲的是执法的三种品格：有力度才立威，讲道理才服人，护民利才长久。三者不是三件事，而是一次执法的三个面——没有力，理无人听；只有力不讲理，执法就滑向粗暴；力与理若不落到民利上，便成了伤民的暴力和扰民的形式。**因此，行政执法当以「力」立威、以「理」服人、以「利」为民。**

**示范二（2024 既要好政策更要巧落实，约 195 字）**：

> 从「一网通办」到「一刻钟服务圈」，公共服务的清单越来越长，群众的感受却未必同步变好。材料里那位街道负责人点出要害：既要制定好的政策，更要深入群众实际、从细微处着手，用好各种巧劲，以「助推」之手奏出优美的乐章。政策定的是方向，落到人身上却是一连串细节——通知怎么写、香皂换成什么形状、短信发在第几天；政策再周全，不肯在细微处用巧劲，也会卡在「最后一公里」。**因此，治理之效不在政策的厚度，而在落实的巧劲。**

### 5.3 主体段：五步骨架

| 步骤 | 写法要求 |
|---|---|
| ① 分论点 | **尽量抄题干或材料**，不要自己改写；字数控制在小 18 字 或 大于 21 字（避开 18—21 字区间） |
| ② 解释分论点 | 三选一或叠加：解释关键词语的含义；解释这句话的含义；解释分论点的内在逻辑 |
| ③ 道理论证 | 本节课讲**正反道理论证**（见 5.4）；后续依次为逻辑论证 → 有 A 没 B → 相辅相成 → 是什么—为什么—怎么办。其中**推理论证（搭桥）**见 5.5，**缺失论证（有 A 没 B／有 B 没 A）**见 5.6，**相辅相成与缺失论证的区分**见 5.7 |
| ④ 举例论证 | 例子**必须能证明你的分论点**；坚决不用来凑字数，一般控制在 **50 字左右** |
| ⑤ 回扣分论点 | 简单罗列当下背景 + 分论点**同义替换** |

> 主体段 = 分论点句（判分眼）→ 讲清为什么（说理）→ 拿例子坐实（论据）→ 收回到分论点（闭环）。

### 5.4 道理论证之一：正反论证（有则／无则）

**是什么**：把同一件事的两种状态摆出来对照——有它如何、没它如何。用**反差**替自己下判断，而不是直接说「A 很重要」。

**什么时候用**：分论点是一个「因」，而读者不会自动同意；或它容易被当成常识、需要被重新看见时。

**结构**：正（有 A → 怎样）→ 反（无 A → 怎样）→ 合（故 A 不可少）

**规范表达（四式）**：

| 句式 | 模板 |
|---|---|
| 对照式（最稳） | 「有 A，则……；无 A，则……」 |
| 因果式 | 「A 之所以……，正在于……；反之，若 A 缺席，则……」 |
| 反观式 | 「反观那些……的情形，恰恰是……的反面注脚」 |
| 收口式 | 「两相对照，A 的分量自明」 |

**示例（2025 材料 8 · 尝新与常新）**：

> 尝新之后能不能走远，全看有没有「持续」二字。民俗里的尝新，一年一度，仪式过了便归于日常，来年再从头；A 公司却把尝新做成一条线——每月新款、地域差异化、节庆与公益联名，一款接一款地上新，才把一时的巧思熬成长久的品牌识别。**一时尝新是点缀，持续更新才是资产。**可见，常新不是尝新的自然延长，而是持续投入的结果。

**四条禁忌**：

1. **反例要类型化、不点名**（「那些只图一时热闹的做法」）——一点名就成了第二个例子，抢走主例分量；
2. **正反不能各占一段**——那是两个主体段，不是一段里的道理论证；
3. **反例不能虚构极端**（「不这样就会失败」），要用**真实存在但做得不到位**的情形；
4. **正反之后必须有「合」**，只对照不下结论，等于把判断交给读者。

> 与 5.6 缺失论证的区别：正反是**同一样东西**的有无；缺失论证是**两样东西**互为条件。别混。

**怎么判断写的是「正反」还是「废话」**（讲义原例）：

> ❌ 如果坚持，就会成功；如果不坚持，就不会成功。

**为什么是废话**：「成功」本身就含着「坚持到底」，两句是同一命题正反各说一遍，中间没有一步新信息。这类叫**同义反复**。

> ✅ 如果能做到长期坚持，那么遇到问题就会迎难而上，不断解决难题，最终就能到达理想彼岸。反之，经常逃避问题、不敢正视困难，最终被现实打败，一生碌碌无为。

**为什么成立**：两侧都给了中间机制——正面「遇难题 → 迎难而上 → 不断解决 → 到达彼岸」，反面「逃避 → 问题堆积 → 被现实打败」，各走三步；把首尾两句删掉，中间仍能独立成立。

**三步改造法**：

1. **拆词**：把结论词拆成可观察的过程（成功 → 不绕开难题 → 一次次解决 → 位置变了）；
2. **加机制词**：因为／才／导致／最终，让每一跳都有因果；
3. **反面写具体失败路径**，不写「不成功」三个字。

**四种可用反面写法**（避免正反写成对称废话）：

| 写法 | 句式 | 适用 |
|---|---|---|
| 短板型 | 缺了它，别的条件一并失效 | 讲必要条件 |
| 时间型 | 短期有效，长期反噬 | 讲急功近利 |
| 层次型 | 个体看有效，整体看失效 | 讲局部与全局 |
| 转移型 | 看似省了成本，实则转嫁给未来或他人 | 讲透支 |

> **一句自查**：把正反的首尾去掉，中间还剩几句？剩 0 句＝废话；剩 2 句以上＝论证。

### 5.5 道理论证之二：推理论证（搭桥）

**是什么**：由题干（前提）推出结论，中间每走一步，都补上一个「为什么能连上」的判断，像搭桥一样把前后件接起来。不靠正反对照，靠**一环扣一环**。

**什么时候用**：题干给的是因果或条件关系（「X 决定 Y」「只有 X 才 Y」），而 X 与 Y 中间隔得远——不搭桥就是**跳步**，读者不服。

**结构**：前提 → 桥① → 桥② → 桥③ → 结论（每搭一桥都要回答「凭什么」）

**搭桥三式（规范表达）**：

| 句式 | 模板 |
|---|---|
| 因果式 | 「A 看似不直接产生结果，却决定了……；而……一旦改变，……随之改变；……积累到一定程度，才转化为……」 |
| 条件式 | 「A 要成立，须以 B 为前提；B 的成立，又取决于 C；故无 C 则无 A」 |
| 递进式 | 「不仅……，更进一步……，最终……」 |

**示例：从「思维」到「收获」，搭三次桥**

| 环节 | 搭桥句（规范表达） | 作用 |
|---|---|---|
| 前提 | 今天的思维和播种，决定我们未来的收获 | 题干原句，不解释 |
| 桥① 思维→选择 | 思维看不见，却决定人的目光落在哪里；目光落在趋势上，才会知道该学什么、备什么——这就是「今天干什么」 | 把「思维」落到可观察的「选择」 |
| 桥② 选择→投入 | 选择一旦作出，资源便跟着走：选了长周期的事，钱、人、时间才会持续投进去，形成「今天怎样干」 | 把「选择」落到可计量的「投入」 |
| 桥③ 投入→积累 | 投入并不立即产出，要经时间沉淀，才变成技术、专利、人才队伍这些别人拿不走的东西——这正是「如何取舍」的结果：舍掉快钱，才有积累 | 把「投入」落到可留存的「积累」 |
| 结论 | 思维改变选择，选择改变投入，投入在时间里累积成收获；今天种下什么，未来就收获什么 | 回扣前提，闭环 |

**成段示范（约 220 字）**：

> 思维看不见，却决定人的目光落在哪里：目光只在眼前一亩三分地，就只会想到今年多打几斗粮；目光落在趋势上，才知道该学什么、该备什么，这就是「今天干什么」的选择。选择一旦作出，资源便跟着走——选了长周期的事，钱、人、时间才愿意持续投进去，形成「今天怎样干」的行动。而投入从不立即产出，它要经时间沉淀，才转化为技术、专利、人才队伍这些别人拿不走的东西，这正是「如何取舍」的结果：舍得下快钱，才攒得下家底。由此可见，思维改变选择，选择改变投入，投入在时间里累积成收获；今天种下什么，未来就收获什么。

**三条禁忌**：

1. **桥不能省**：「因为要创新，所以必须改体制」——中间凭什么？读者一问就露怯。
2. **桥不能说废话**：搭的必须是**新增的一步**，不能把结论换个说法再讲一遍。
3. **桥要扛得住反驳**：每搭一桥自问「这一步有没有反例」，有就补限定（「一般情况下」「在……的条件下」），别硬推。

**与正反论证的分工**：正反管**横向对照**（有则如何、无则如何），推理管**纵向推进**（从 A 到 D 的路怎么走）。同一主体段可先推理、再正反收口，既不跳步也不重复。

### 5.6 道理论证之三：缺失论证（有 A 没 B / 有 B 没 A）

**是什么**：分别设想「只有 A 没有 B」和「只有 B 没有 A」两种残缺状态，说明二者缺一不可，再推出「需要 A 与 B 相辅相成」。**不直接说「都重要」，而是让对方看见缺一样会烂成什么样。**

**什么时候用**：题干、分论点里含**两个并列概念**——力与理、规划与治理、标准化与个性化、变与不变、硬实力与软实力、保护与开发。

**三步结构**：

| 步 | 任务 | 一句话模板 |
|---|---|---|
| ① | **有 A 无 B** → 会坏成什么样 | 「有 A 而无 B，A 便成了……」 |
| ② | **有 B 无 A** → 会坏成什么样 | 「有 B 而无 A，B 便成了……」 |
| ③ | 定关系 → 缺一不可 | 「A 是 B 的底稿，B 是 A 的落笔，缺一则行不远」 |

第③步是档次分界线：只说「缺一不可」是**表态**，点出「谁是谁的前提/手段/骨架」才是**论证**。

**规范表达句式库**：

- **对举式（最稳）**：「有 A 而无 B，A 便……；有 B 而无 A，B 便……。二者如车之两轮，缺一则行不远。」
- **假设式（更有推理感）**：「设若只有 A 而无 B，……；假使只有 B 而无 A，……。可见 A 不是 B 的对立面，而是 B 的……」
- **程度式（防绝对化）**：「A 不及则……，A 过度则……；B 亦如是。故关键不在有无，而在分寸。」
- **反诘式（收口用）**：「无 A 之 B，何以为 B？」（段尾用一次，不宜连用）

**示例一：精心规划与用心治理（材料 10 · F 镇）**

> 精心规划与用心治理，如车之两轮，缺一则行不远。有规划而无治理，图纸再精美也只是挂在墙上：设计出自研究院，落笔却要一间屋一间屋地谈，若不入户商量，「是不是面子工程」的疑虑消不掉，最终效果与图纸常常是两回事。反过来，有治理而无规划，则今天刷墙、明天拆墙，为求「快」而刻意造「旧景」，反把古镇原有的肌理破坏掉。F 镇的可贵正在于两头都做：先有覆盖整个镇域、细到窗棂的设计，再以 107 次座谈会、6936 户走访把方案落到每一户，连经营户「廊柱外移」的一条建议都能被采纳。可见，**规划是治理的底稿，治理是规划的落笔**：无底稿的落笔是乱画，无落笔的底稿是空谈。

**示例二：执法之力与执法之理（资料 5 · 力/理/利）**

> 有「力」而无「理」，罚单开得再重也是压服——当事人怕的是人，不是法，一旦执法者转身，违法行为便卷土重来；有「理」而无「力」，道理讲得再透也是空谈——该罚的不罚、该管的不敢管，法律便成了纸上的条文。可见**力是理的后盾，理是力的说明书**：无后盾的说服是求人，无说明的强制是伤人。

**四条禁忌**：

1. **两句必须对称**：同一句式、相近字数。写成「有 A 没 B 就糟了；光有 B 也不行」，排比当场垮掉。
2. **不能只表态**：只写「二者相辅相成、缺一不可」，等于没说，必须给出① ②两种残缺形态。
3. **关系必须点明**：是前提与手段、骨架与血肉、方向与动力，还是边界与空间？含糊过去就是空话。
4. **不与分论点句重复**：分论点句若已写「既要 A 又要 B」，段内就别再说一遍「既要又要」，直接进①②的残缺推演。

**与另两式的分工**：正反管**同一样东西**的两种状态（有则/无则）；缺失论证管**两样东西**的互相不可替代（有 A 无 B／有 B 无 A）；推理论证管**从起点到终点**的路怎么走。三者可叠用：推理铺路 → 缺失补位 → 正反收口。与「相辅相成」的区别见 5.7。

### 5.7 关系判断 vs 论证手法：相辅相成与缺失论证怎么分

两者最容易混，因为都涉及「两样东西」。区别只有一条：**相辅相成是关系判断，缺失论证是论证手法。**

| | 相辅相成 | 有 A 没 B／有 B 没 A |
|---|---|---|
| 本质 | **关系判断**：A 与 B 是什么关系 | **论证手法**：用残缺对照证明「都不可缺」 |
| 回答的问题 | 有了会怎样（**互促**） | 缺了行不行（**必要**） |
| 能否当分论点句 | ✅ 能（「思维与播种相辅相成」是判断） | ❌ 不能（「有思无行则空谈」是论据，不是观点） |
| 放在哪 | 分论点、中心论点、结尾合流 | 只能放段内，做说理 |
| 逻辑性质 | 正反馈（A→B→A，1+1＞2） | 必要条件穷举（排除单边可行） |

> 口诀：**「缺一不可」问必要性，用缺失论证；「互相成就」问机制，用相辅相成。**

**句式差别（一眼可辨）**：

- 缺失——两侧对称，各写残缺后果：「有 A 而无 B，A 便成了……；有 B 而无 A，B 便成了……」
- 相辅相成——**必须有回程箭头**：「A 让 B……，B 让 A……」

> 例（思维与播种）：思维让播种有方向，播种让思维有落地；播下什么种子，又反过来检验思维是否真的前瞻。
> **只写「A 有利于 B」是单向，那叫「相关」，不叫「相成」**——缺回程箭头，相辅相成就退化成「很重要」。

**三法完整分工（一物／两物／两物互促）**：

| 手法 | 对象 | 核心句式 | 回答 |
|---|---|---|---|
| 正反论证（5.4） | **一样东西**的两种状态 | 有它则……，无它则…… | 它必要吗 |
| 缺失论证（5.6） | **两样东西**各自的残缺 | 有 A 无 B 则……，有 B 无 A 则…… | 能否单边成立 |
| 相辅相成（本节） | **两样东西**的互促循环 | A 让 B……，B 让 A…… | 合起来是否更大 |

**实战排列：先缺后成**（同一段内叠用）

1. **缺失**：有思无行是空谈，有行无思是无航标 → 所以缺一不可；
2. **相辅相成**：二者一旦咬合——思维给播种定向，播种给思维作证，越思考越敢投入，越投入越看清方向，形成正向循环；
3. **收口**：可见，面向未来不是只想不做，也不是只做不想。

先缺（防守）解决「不能偏」，后成（进攻）解决「合起来强」，一段才有推进，不会停在「都重要」。

**三个常见错误**：

1. **把缺失论证当分论点句**——写「没有思维的播种是盲目的」做小标题，阅卷看不到观点；
2. **相辅相成只用单向**——只写 A 促成 B，不写 B 反哺 A，等于没写关系；
3. **两个都用却没区别**——段首说相辅相成，段中只做残缺对照，段尾又回「都重要」，三次说同一件事，反而显空。

## 六、词语话题类：只留三条判断

1. **释义只认材料原词**——「力」不是「力度」，是权力＋监督检查力度＋公信力（本源—手段—效果三层）。
2. **三话题先试写成一条链**——善治→大美→乐居；力与理→利。写不成链，才退回并列；能写而不写，就是没解出关系。
3. **论证时「截段」不「摊平」**——一条因果链只能挑相邻两三环搭桥（见 5.5），摊平成五个例子，三段必重复。

## 七、交卷前自检

- [ ] 首段最后一句是否就是**中心论点**（分总结构，不能错位）
- [ ] 词语话题类：每个话题的释义是否落在**材料原词**上，没有凭常识想当然
- [ ] 三话题题是否已先试写成**一条链**（A 实现 B、B 促成 C），而不是三段并列
- [ ] 三个分论点是否**直接来自题干或材料**，没有自我改写走形
- [ ] 每个分论点句字数是否落在「< 18」或「> 21」的区间
- [ ] 每个主体段是否都有**道理论证 + 举例论证**，没有只堆例子
- [ ] 用推理论证时，每一跳是否都**搭了桥**（无跳步、无同义反复）
- [ ] 用缺失论证时，「有 A 无 B」「有 B 无 A」两句是否**对称**，且点明了二者的关系
- [ ] 写「相辅相成」时，有没有**回程箭头**（B 反哺 A），而不是只写 A 促进 B
- [ ] 例子是否真的在证明该段分论点（而不是换个段也能用）
- [ ] 每个主体段末尾是否**回扣了分论点**（同义替换，不是原句复读）
- [ ] 首段是否 150—200 字、主体段是否约 250 字、结尾约 100 字
