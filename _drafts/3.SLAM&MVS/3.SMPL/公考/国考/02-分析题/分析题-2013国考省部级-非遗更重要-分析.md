# 分析题｜2013 国考（省部级）｜非遗比长城故宫更重要？ · 分析

> 类型：分析　｜　题源：2013 国考申论（省部级）第 2 题　｜　分值：15 分·250 字
> 题目与材料：[[分析题-2013国考省部级-非遗更重要-题目与材料]]　｜　方法论：[[综合分析]]

---

## 一、答案要点

1. 这一说法强调非遗的**精神价值与不可替代性**，并非贬低长城、故宫。
2. 长城、故宫是有形的物质遗存，价值相对稳定；非遗是无形的**活态文化**，靠口传心授，一旦传承人断代即彻底消失，抢救更紧迫。
3. 非遗承载民族记忆与精神认同，还与经济生活相连，可转化为发展资源、带动就业增收。
4. 因此要保护传承人、开展生产性保护、推动非遗融入现代生活与教育。

## 二、为什么第一步是「并非贬低」

题干用「**比……还要重要**」，是**比较句式**。若直接顺着写「非遗更重要，长城不重要」，就掉进了命题人的坑——作者自己说的是「从某种意义上」。所以表态要限定范围：**强调精神价值与不可替代性，不是否定物质遗存的价值**。

## 三、对比论证怎么写

| | 长城、故宫 | 非遗 |
|---|---|---|
| 形态 | 有形、物质遗存 | 无形、活态文化 |
| 传承 | 存于物，可修复 | 存于人，口传心授 |
| 断裂后 | 残破仍可考 | 传承人一断即彻底消失 |
| 价值 | 历史审美 | 民族记忆、精神认同＋经济资源 |

四行对照，130 字能写满，且天然回答了「为什么后者更重要」。

## 四、易错

1. 只复述作者原话，没有自己的表态与限定。
2. 对比只写「一个有形一个无形」，不写「断代后果」——后者才是紧迫性的来源。
3. 结尾不落做法，「说理」不成「分析」。
4. 把材料里「官员文化理解误区」写进答案——那是材料后半段的问题，250 字装不下，且不属于「见解」本身。
