# 知识点九 · 词语话题类 · 真题3（力 / 理 / 利）解析

> 真题来源：2024 国考（行政执法卷，35 分，1000—1200 字）

> 本题为老师解析片段整理，配合资料 5 逐段核对

## 一、定中心论点的两步

题干出题类型判定为「词语话题类」后，按两步定论点：

| 步 | 做什么 | 靠什么判断 |
|---|---|---|
| ① | 确定每个话题**在材料里到底指什么** | 找材料中与该字相关的**原词**，不凭常识释义 |
| ② | 判断几个话题**之间的逻辑关系** | 看**段落大意**：段与段的先后、段尾的结论句 |

释义错、关系错，分论点必然全错——这两步比文采重要。

## 二、核心判断：三话题很少「完全并列」

> **三话题作文，很少出现三个完全并列——并列太简单。**

判断方法：先试着把三个话题写成**一条链**；写不成链，才退回并列。

| 范本 | 关系 |
|---|---|
| 「善治 · 大美 · 乐居」 | 善治能够实现大美，大美能够促成乐居（递进链 A→B→C） |
| 「力 · 理 · 利」 | 关注「力」与「理」，**进而实现**「利」（手段→目的） |

**力与理是路径，利是归宿**。这样第三段才有独立任务（回答「凭什么说落点在利」「用什么检验力与理」），不会重复前两段。

## 三、释义：只认材料原词

| 字 | 材料中的含义 | 出处 |
|---|---|---|
| **力** | 权力、监督检查力度、公信力 | 段 2「权力和荣誉」「公信力」；段 3「加大基层执法的监督检查力度…严肃问责」；段 7「有权不能滥用」 |
| **理** | 「释法明理、法理相融」的执法理念 | 段 6 原话；展开为「认定讲证据、裁量讲道理、决定讲法律」「讲清事理、法理、情理」 |
| **利** | 人民群众的利益 | 段 6「更好地维护人民群众的利益」；旁证「提高法律遵从度」「营商环境」 |

忌：把「力」释义成「力度」「执行力」，丢掉「权力」「公信力」两条线索，后面必然写空。

## 四、一字多义时，先分层再落笔

「力」下面三个词不是三个选项，而是**三层**（问 1 的答案）：

| 层 | 对应词 | 性质 |
|---|---|---|
| 本源 | 权力 | 「力」从哪来——执法权的刚性 |
| 手段 | 监督检查力度 | 「力」怎么行使——约束权力、防滥用 |
| 效果 | 公信力 | 「力」换回什么——群众信服 |

一条线写：**加大监督检查力度（手段）→ 规范权力的使用（对象）→ 提升执法的公信力（效果）**。

单独写任何一个都会瘸腿：只写公信力，它是结果，且与「利」撞车；只写监督力度，它是过程量，讲完就没了，还漏掉「执法权本身的权威」。

## 五、分论点句的三条硬标准

以「力」为例（问 3 的答案）：

| | 写法 | 判定 |
|---|---|---|
| ❌ | 在行政执法工作中，加大执法监督检查力度，规范权力的使用，提升执法的公信力 | 对策清单，不是论点 |
| ✅ | 执法的「力」，不只在于有权，更在于有权而不滥用 | 有判断，可被反驳 |
| ✅ | 加大监督力度、规范权力运行，才能把执法的「力」转化为公信力 | 三动作＋因果词，成链 |

三条标准：

1. **能不能被反驳**——「要加大力度、规范权力、提升公信力」没人会反驳，所以它不是论点，是口号；
2. **三个动作之间有没有连接词**——无「才能/进而/因此」，就是清单；
3. **有没有给段内留话**——三个对策全写完，主体段只能靠形容词凑 250 字。

## 六、论证时「截段」，不「摊平」

材料给的是一条**因果链**（问 4 的答案）：

```
加大监督检查力度 → 规范权力使用 → 裁量讲事理法理情理（约束自由裁量权）
→ 提高法律遵从度 → 维护人民群众利益 → 提升执法公信力
```

| 材料中的句子 | 关系 |
|---|---|
| 规范管理权力 → 提升执法公信力 | 因果 |
| 加大监督检查力度 → 规范权力的使用 | 手段→目的 |
| 贯穿「释法明理、法理相融」→ 提高法律遵从度 | 手段→效果 |
| 事理、法理、情理 → 约束自由裁量权 → 维护群众利益 | 三级链条（缺中间一环即跳步） |
| 有权不能滥用 → 创新行政执法方式 | 问题→对策（反面切入） |

**结论**：这些不是五个并列论据，而是**一条链的五个断面**。主体段只能挑**相邻两三环**搭桥推过去（见笔记 5.5 推理论证），其余环节分给别的段——摊平成五个例子，三段必然互相重复。

「有权不能滥用 → 创新执法方式」这一组，本质是 5.6 缺失论证的反面切入：有权而无约束，则「力」沦为压服。

## 七、四问速查

| 问 | 答案要点 |
|---|---|
| 为什么写「权力」，不写「公信力」或「监督力度」 | 三者是一条链：权力（本源）→ 监督（手段）→ 公信力（效果），不是三选一；单写公信力与「利」撞车，单写监督力度讲完就没了 |
| 分论点三写「关注力与理，进而实现利」对不对 | 对。避免重复，且揭示手段—目的关系；但第三段只能讲「利的两种落点」（群众之利、公信之利），不能再讲力度与说理 |
| 分论点一能否直接写「加大力度、规范权力、提升公信力」 | 能写但不划算：38 字、三对策并列、无判断，主体段无话可说。改法见第五节 |
| 那几组句子用什么方式论证 | 因果推理（搭桥）。它们是一条链的相邻环节，不是并列论据 |

## 八、三个分论点定稿

### 8.1 中心论点（首段末句）

> 行政执法当以「力」立威、以「理」服人、以「利」为民：有力无理会失之于粗，有理无利会失之于空。

### 8.2 三个分论点

| | 分论点句 | 段内任务（材料落点） | 反面（收口用） |
|---|---|---|---|
| 一 | **执法之「力」，在于规范权力、严格监督，让法律有刚性。** | 权力（段 2「权力和荣誉」「一人一号」）→ 监督（段 3「加大监督检查力度」「严肃问责」）→ 公信力（段 2、7） | 以罚代管、畸轻畸重、以权压人 |
| 二 | **执法之「理」，在于释法明理、法理相融，让处罚能服人。** | 认定讲证据、裁量讲道理、决定讲法律（段 6）；讲清事理、法理、情理（段 6）；查前辅导、证据分析、政策依据（段 4、5） | 简单粗暴、以权压人（段 7） |
| 三 | **执法之「利」，在于「力」与「理」统一，让群众真正受益。** | 群众之利：切身利益（段 8）；公信之利：提高法律遵从度（段 6）、营商环境（段 7） | 逐利执法、以罚增收（段 3） |

### 8.3 为什么这样定

1. **三句同构**：「执法之 X，在于……，让……」，字数 25±1，排比成立而不重复。
2. **第三句点明关系**，不写「要关注利」——那样与前两段重复；写成「「力」与「理」统一」，落在「利」上，才把手段—目的链写出来。
3. **每句都用材料原词**：刚性（「有权不能滥用」的反面）、服人（「说得透」「答疑释惑透彻」）、受益（「维护人民群众的利益」）。
4. **第三段的禁区**：不再讲力度、不再讲说理，只讲两件事——利有哪两个落点（群众／公信）、用什么检验（群众是否受益、法律是否被遵从）。

### 8.4 段落配比（1000—1200 字）

| 段 | 内容 | 字数 |
|---|---|---|
| 开头 | 引材料→释三字（权力/道理/民利）→ 手段—目的关系 → 中心论点 | 160—200 |
| 二 | 分论点一：权力→监督→公信力，两跳搭桥 | 250—280 |
| 三 | 分论点二：证据→道理→法律，讲透才服人 | 250—280 |
| 四 | 分论点三：力与理统一于利，两个落点＋检验标准 | 250—280 |
| 结尾 | 回扣三字＋「执法为民」，不引新观点 | 100 |

（三话题并列的最常见失分：三段都在讲「重要性」，第三段无话可说。按上表分配，第三段有独立任务，不会空转。）
