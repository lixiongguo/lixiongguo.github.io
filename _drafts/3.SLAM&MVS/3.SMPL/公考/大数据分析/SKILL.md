# 公考真题题型库整合

> 这是**操作规范**，不是内容。产出物是同目录的 `01-概括题.md`、`02-对策题.md`、`03-综合分析.md`、`04-公文题.md`。
> 覆盖范围：`公考/` 下国考、京考、粤考三类资料，按四大题型分别建账。

## 一、用途

把散落在 `公考/京考/`、`公考/申论方法论/` 里的真题题干、解析与方法论，抽成**同一套字段的台账**，再据此产出可追溯的统计结论。

三条硬要求：

1. 每条结论都能在台账里数出支撑条数（≥3 条才写进结论）；
2. 没有样本的格子写「待核」，不猜；
3. 台账只增不删，来源可复查。

## 二、输入清单

| 目录 | 有什么 | 怎么用 |
|---|---|---|
| `公考/京考/*题目与材料.md` | 真题原文 | 抄设问原句，取分值、字数、卷别 |
| `公考/京考/*解析.md` | 审题、分论点、关系段 | 取题型判定与作答骨架 |
| `公考/京考/历年京考审题分析.md`、`历年京考审题速查表.md` | 历年大作文题型索引 | 补充作文样本，不混入概括题分母 |
| `公考/京考/大作文学习笔记.md` | 作文方法体系 | 校对编号引用是否失效 |
| `公考/申论方法论/归纳概括.md` | 概括题模型＋例题 1—6 | 概括题样本的主要来源 |
| `公考/申论方法论/综合分析.md` | 四类问法＋关系类型 | 分析题样本与分类依据 |
| `公考/申论方法论/京考国考广东省考特色.md` | 三地差异 | 差异表的事实来源 |

## 三、执行步骤

1. **清点**：按「地区-年份-卷别-题号」给每条真题编号，先建空台账。
2. **抽取**：每题只抄**设问那半句**（不抄材料段落），填满 §四 的 9 个字段。
3. **归类**：先归五大类（概括／分析／对策／公文／作文），再归二级类型——概括走四维（对象·范围·形式·层级），分析走四类（词句理解·观点评价·关系分析·比较评析）。
4. **汇总**：把台账与频次写进 `题型大数据汇总.md`；同一结论若样本不足，标「推测」。
5. **对齐**：与 `归纳概括.md`、`综合分析.md` 的编号互链；发现方法论缺口，回写对应文件而不是留在汇总里。
6. **复核**：检查编号引用（历史上出现过 5.x 旧编号未更新的问题）、检查「待核」是否被误写成结论。

## 四、字段（每题一行）

| 字段 | 取值 |
|---|---|
| 地区 | 国考／京考／粤考 |
| 年份·卷别 | 2024·区级／2022·副省 |
| 题号 | 第 1 题 |
| 设问原句 | 抄「概括……」「谈谈……」那半句 |
| 动词 | 概括／归纳／提炼／梳理／总结／谈谈／评价 |
| 宾语 | 做法／措施／经验／成效／问题／原因／特点／理解／关系／启示 |
| 范围 | 单则／指定几则／通篇 |
| 硬要求 | 分条／一段话／不列条目／公文／分值／字数 |
| 归类·置信 | 概括·多则·总分｜本地核实 |

## 五、产出规范

按题型拆成四个文件，分账统计；复合题（如 2026 京考首题＝概括＋政务信息）在两边各记一条并标「详见」：

| 文件 | 分母 | 备注 |
|---|---|---|
| `01-概括题.md` | 9 | 京考首题为主 |
| `02-对策题.md` | 4 | 京考 3、国考 1 |
| `03-综合分析.md` | 4＋示意 1 | 京考 3、国考 1 |
| `04-公文题.md` | 1 | 同时暴露「公文方法论缺失」 |

每个文件固定五段：**台账 → 频次 → 规律 → 待补 → 与方法论对齐**。

- 规律按「支撑条数」排序，并标出支撑数；
- 支撑＜3 条一律写「推测／假设」，不作为定论；
- 三地差异只写本地有样本的格子，缺样本的整列写「待核」。

## 六、联网补量（可选，按需触发）

只补三类缺口，不做全量爬取：

1. 国考概括题：近 5 年副省／地市／执法首题设问；
2. 粤考概括题：县级／乡镇卷首题设问；
3. 京考 2019 年前首题：用于验证「直抄材料」阶段。

检索时只记设问与硬要求，**不抄答案**；原文拿不到就留「待核」，不用二手转述填空。
