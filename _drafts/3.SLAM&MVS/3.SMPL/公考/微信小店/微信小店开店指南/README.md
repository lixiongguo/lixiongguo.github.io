# 微信小店开店完全指南（2026 版）

> **适用对象**：公司主体（企业或个体工商户）在微信生态内卖货，无专职开发运维团队，希望零代码、低成本、快速上线。
> **文档目标**：从「要不要用」到「日常运营」的完整操作手册，照着做即可开店。

## 术语表

看懂这些词，后台界面就不会迷路。

| 术语 | 含义 |
|---|---|
| **主体** | 开店背后的经营实体（企业执照或个体工商户执照） |
| **类目** | 商品的分类目录，决定你能不能上架某类商品、要交多少保证金与费率 |
| **定向准入类目** | 需要额外资质审核才能经营的类目（食品、美妆、盲盒等） |
| **保证金** | 平台冻结的履约保障金，非罚款，关店可退；金额取「类目保证金」与「浮动保证金」较高值 |
| **浮动保证金** | 随店铺成交额增长而提高的保证金部分 |
| **技术服务费** | 平台按成交额收取的佣金，即卖家最常说的「平台抽成」 |
| **结算基数** | 计算技术服务费的金额口径 = 用户实付 + 支付补贴 + 达人优惠 + 平台优惠 |
| **超级管理员** | 店铺最高权限账号持有人，需实名微信 + 本人人脸识别，通常就是老板本人 |
| **SKU** | 商品的最小销售规格单元（如「红色 / L 码」就是一个 SKU） |
| **挂车** | 在视频号直播或短视频中挂上商品链接，观众可直接下单 |
| **私域** | 你能直接触达的用户池（企微好友、公众号粉丝、社群） |
| **公域** | 平台推荐分发的流量（视频号推荐、直播间自然流量） |
| **一件代发** | 不囤货，出单后由供应商直接发货 |
| **运费险** | 退货运费由保险承担的增值服务，开通通常能换取平台流量激励 |
