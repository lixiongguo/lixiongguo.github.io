# 第 8 章　物流与售后

> **本章目标**：把发货流程和售后规则固定下来，避免踩时效和纠纷的坑。
> **本章耗时**：20 分钟配置，之后按流程执行。

---

## 本章要点

- 运费模板要在上架**之前**配好，否则商品无法正常下单
- 发货超时、物流异常是扣分和纠纷的主要来源
- 售后分「仅退款／退货退款／换货」三条分支，处理方式不同
- 保留沟通记录是最有效的纠纷防线

---

## 8.1 运费模板

在后台配置运费规则，常见四种计费方式：

| 计费方式 | 适合场景 | 注意 |
|---|---|---|
| 全国包邮 | 单价高、运费占比低 | 偏远地区仍可能亏，建议单独排除 |
| 按件数 | 小件、可合并包裹 | 多件重货容易亏运费 |
| 按重量 | 重货、体积大 | 需准确填商品重量，误差会导致亏损 |
| 地区差异化 | 有偏远地区订单 | 新疆／西藏／内蒙等地单独设置加价或限制 |

**配置要点：**

- [ ] 至少创建 1 个可用模板并绑定到商品
- [ ] 明确偏远地区策略（加价或标注不发货）
- [ ] 核对重量单位，避免把 kg 填成 g
- [ ] 改价前先算一遍：单件利润能否覆盖运费

> 💡 **提示**：新手最常见的隐性亏损是「包邮 + 偏远地区 + 重货」三件套。开卖前先按最远省份算一次运费。

---

## 8.2 发货流程

```
顾客下单 → 订单状态「待发货」
   → 打包、联系快递取件 → 后台填入物流单号
   → 订单状态「已发货」→ 顾客可在小程序内查看物流
```

**发货检查：**

- [ ] 收货信息与商品规格核对一遍（错发是主要售后来源）
- [ ] 物流单号填写正确，避免填错导致「虚假发货」判定
- [ ] 平台有发货时效要求，**超时未发货会被记录并可能扣分**
- [ ] 大促／节假日期间提前调整备货与人力，或提前在店铺公告说明

---

## 8.3 售后类型与处理方式

```
买家提交售后
 ├─ 仅退款（未发货 / 未收到货）
 │    → 后台同意 → 原路退款 → 商品若已发出需拦截
 ├─ 退货退款（已收到货，想退）
 │    → 同意 → 买家寄回 → 你确认收货 → 退款
 │    → 质量问题你承担运费；非质量问题买家承担
 └─ 换货（规格 / 质量问题）
      → 协商寄回 → 寄出新品 → 在后台备注处理结果
```

**处理原则：**

- **及时响应**：延迟响应会升级为平台介入，介入后对店铺影响更大
- **保留沟通记录**：聊天记录、物流凭证、开箱视频，是纠纷时唯一证据
- **按类目规则执行**：食品、美妆等类目有专门的售后规则，不能只按自己的习惯来
- **不私下转账**：退款走平台流程，私下转账既无法举证也可能违规

---

## 8.4 常见异常订单处理

| 异常 | 处理方式 |
|---|---|
| 缺货无法发货 | 立即联系买家说明，建议退款或换款，不要拖到超时 |
| 买家地址错误 | 发货前联系修改；已发出则协调快递改址或退回 |
| 物流长时间无更新 | 主动联系快递查件，同步告知买家，必要时补发 |
| 包裹丢失 | 向快递索赔，同时给买家退款或补发，先保体验 |
| 买家拒收 | 了解原因，按退货退款流程处理，注意运费归属 |
| 恶意退款／骗货 | 保留证据（称重、开箱视频、聊天记录），在后台申诉 |

---

## 8.5 退货地址与逆向物流

- 后台配置准确的**退货地址与联系人电话**，否则买家寄不回，纠纷必输
- 退货地址建议选你能稳定收件的地址（自有仓库或代发供应商地址）
- 一件代发模式下，退货地址通常需填供应商地址，**提前和供应商确认**
- 收到退货后及时验货并处理退款，不要压着不处理

---

## 8.6 售后自检清单

- [ ] 运费模板已配置并绑定商品
- [ ] 退货地址、联系人、电话已填写并核实
- [ ] 客服自动回复里写清了退换货政策
- [ ] 已了解所售类目的特殊售后规则
- [ ] 有一套固定的异常订单处理话术
- [ ] 知道怎么在后台提交申诉、在哪看纠纷进度
