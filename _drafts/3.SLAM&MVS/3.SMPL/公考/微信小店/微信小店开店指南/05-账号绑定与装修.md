# 第 5 章　账号绑定与店铺装修

> **本章目标**：把店铺和流量场景打通，并完成基础观感配置，让顾客点进来能下单。
> **本章耗时**：1–2 小时｜**前置条件**：店铺审核通过并完成账户验证。

---

## 本章要点

- 不绑视频号／公众号，店铺等于「藏起来的店」，只能靠聊天分享
- 绑定顺序：先开店 → 再绑账号（顺序反了找不到入口）
- 装修自由度高不了，但**海报 + 简介 + 客服自动回复 + 运费模板**四件必须做
- 客服自动回复是最省力的一项，一次配置长期生效

---

## 5.1 为什么要绑定关联账号

将小店与以下账号绑定后，店铺和商品信息才能在更多微信场景中展示和流转：

| 账号 | 绑定后能做什么 | 不绑的后果 |
|---|---|---|
| **视频号** | 直播挂车、短视频挂商品，获得公域推荐流量 | 失去最主要的公域流量入口 |
| **公众号／服务号** | 公众号文章中插入商品，老粉直接转化 | 老粉只能靠手动转发链接 |
| **企业微信** | 导购、客服在企微内分享商品，沉淀客户 | 私域运营链路断裂 |

> ⚠️ **易错**：很多人以为「在视频号开店」就是在视频号里操作，其实微信小店是独立后台。**开好店后再绑定视频号**，商品才能在视频号场景中出现。

---

## 5.2 绑定操作要点

**通用原则：**

1. 绑定操作在**小店后台 → 账号绑定／关联账号**类入口完成，需要对应账号的管理员扫码或授权
2. 授权人与被授权账号必须是同一主体或有合法授权关系
3. 一个视频号只能绑定一个微信小店；重复绑定需先解绑

**准备事项：**

- [ ] 视频号已开通且能正常发布内容（无直播/带货权限的需先申请）
- [ ] 公众号管理员微信在手边（需扫码确认）
- [ ] 企业微信已认证（如要用于导购分享）

> 💡 **提示**：绑定后先发一条测试内容挂一个测试商品，确认链路通。别等到正式直播时才发现商品挂不上去。

---

## 5.3 店铺装修清单

开店后完成基础搭建：

- [ ] **店铺首页海报**：放主推款或活动信息，尺寸按后台提示，避免文字过多
- [ ] **店铺简介**：一句话说清卖什么、为什么信你
- [ ] **客服自动回复**：覆盖发货时间、退换货政策、尺码／规格咨询
- [ ] **运费模板**：见 [第 8 章](08-物流与售后.md)
- [ ] **店铺头像与名称**：与营业执照及主营品类相符，不含极限词

装修自由度有限（模板固定），但足以支撑常规卖货。

**装修三条原则：**

| 原则 | 说明 |
|---|---|
| 信息优先 | 顾客最先想知道「卖什么、多少钱、多久发货」，把这三条放最显眼处 |
| 图片统一 | 主图尺寸、风格、色调统一，观感立刻上一个档次 |
| 少即是多 | 模板固定时，越花哨越乱；纯色底 + 单品图最稳 |

---

## 5.4 客服自动回复模板（可直接改）

**关注／进店欢迎语**

```
欢迎进店～本店主营【品类】，今天下单【X】点前付款当天发货。
有问题直接留言，我们会在营业时间内回复。
```

**发货时效**

```
默认【48】小时内发货（节假日顺延），发出后可在订单里查看物流单号。
偏远地区时效会略长，请留意物流信息。
```

**退换货政策**

```
支持 7 天无理由退换（商品不影响二次销售、包装完好）。
非质量问题退货运费由买家承担；质量问题请拍图联系我们，运费我们承担。
```

**尺码／规格咨询**

```
可以告诉我身高体重 / 使用场景吗？我帮你选最合适的规格。
```

> 💡 **提示**：自动回复不需要写得多漂亮，把「多久发货」「能不能退」讲清楚，能拦下大部分咨询。

---

## 5.5 店铺名称与头像规范

| 项 | 可以做 | 不要做 |
|---|---|---|
| 名称 | 品类词 + 品牌词（如「山野咖啡器具」） | 「最」「第一」「官方」「旗舰」「国家级」等极限词 |
| 名称 | 2–10 字，好读好记 | 蹭他人品牌、堆砌关键词 |
| 头像 | 正方形、白底或纯色、单主体清晰 | 复杂底图、大段文字、二维码、联系方式 |
| 简介 | 一句定位 + 一句信任背书 | 夸大宣传、医疗功效、绝对化承诺 |
