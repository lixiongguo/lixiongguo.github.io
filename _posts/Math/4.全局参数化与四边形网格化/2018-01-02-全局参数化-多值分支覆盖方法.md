黎曼面（Riemann Surface）可以理解为多值函数的自然定义域。例如 $\sqrt z$、$\log z$ 在复平面上是多值的，但提升到合适的覆盖空间后，就可以看成单值函数。

设 $M$ 是一个曲面，$M'$ 是它的一个**分支覆盖（branch cover）**。覆盖映射记为

$$
\pi:M'\to M.
$$

在普通点附近，$\pi$ 是局部同胚；在分支点附近，可以取局部坐标 $z'$ 和 $z$，使得

$$
z=(z')^{n_p}.
$$

当 $n_p>1$ 时，$p=\pi(p')$ 就是分支点。这个公式表达的是：在覆盖空间中绕一圈，投影到原曲面后可能只走过了某个"分支角度"的一部分。

![](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20251027130358889.png)

直观上，普通点附近的覆盖像几张完全一样的小纸片平铺在一起；分支点附近，多张 sheet 像螺旋一样缠绕到同一个点上。分支覆盖的作用，就是把原曲面上难以处理的多值性与奇异点，转写成覆盖空间中可控的 sheet 结构。



## 构造覆盖空间


原曲面上的标架场往往带有奇异点，沿着这些奇异点绕一圈之后，方向会发生非平凡的旋转，导致参数函数无法直接作为一个普通单值函数定义在原曲面上。  

QuadCover 的核心思路是：把原曲面上带奇异点的标架场提升到一个 **4-sheet covering space**。在覆盖空间中，原来绕奇异点一圈产生的多值方向会展开到不同的 sheet 上，于是 **cross field 可以被看成普通的单值向量场**。

算法主线很简单：先用 **matching** 构造覆盖空间，再把标架场提升到覆盖空间，最后通过 **Hodge/Poisson** 求解和 period 修正得到全局无缝参数化。

### 匹配（matching）

设光滑二维流形 $M$ 有局部图集 $\{U_i,\phi_i\}$：
$$
\phi_i:U_i \subset M \to \Omega_i \subset \mathbb{R}^2
$$

离散实现中，每个三角面 $T_i$ 都是一张 chart，通过重心坐标建立到 $\mathbb{R}^2$ 的仿射映射。也就是说，连续流形上的局部同胚在网格上被替换为逐片线性映射。

$M$ 上的**参数化栅格**定义为单位栅格线 $\mathbb{Z} \times \mathbb{R}$ 以及 $\mathbb{R} \times \mathbb{Z}$ 在映射 $\phi_i$ 下的原像**（拉回，pullback）**

相邻 chart 之间不能任意旋转，否则整数格线无法拼成四边形网格。允许的变化来自正方格的对称群：**$90^\circ$ 的整数倍旋转，加上整数平移**，matching 就是在边上记录这个旋转部分。

相邻区域 $U_i$ 与 $U_j$ 重合处，Jacobian 的转移关系写成

$$
D\phi_i(p) = J^{r_{ij}} D\phi_j(p), \quad J := \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}, \quad p \in U_i \cap U_j
$$

因此，离散曲面上的 matching 是一个边到 quarter-turn 编号的映射：
$$
r: \{ \text{edges } e_{ij} \mid T_i \cap T_j = e_{ij} \} \to \{0,1,2,3\}
$$

可以把 $r_{ij}$ 理解为：从 $T_i$ 走到 $T_j$ 时，局部坐标系需要额外旋转多少个四分之一圈才能对齐。$r_{ij}=0$ 表示方向一致，$r_{ij}=1$ 表示旋转 $90^\circ$，其余类推。

如图，两个 chart 之间的匹配为 $r_{ij}=3$。

![](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20251027112932703.png)

对于如下的正方体展开，$r_{01}=r_{12}=0,\ r_{20}=1$。

![](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20251027112941971.png)

#### 计算：从 cross field 到边上的 $r_e$

输入是每个三角形上的参考方向 $\vec d_i$（4-RoSy：$\vec d_i$ 与 $\pm\vec d_i,\pm\vec d_i^\perp$ 等价）。对每条**内部边** $e$（左右面记为 $T_1=e.f_1$、$T_2=e.f_2$），求

$$
r_e=\arg\min_{k\in\{0,1,2,3\}}
\angle\!\bigl(\vec d_1,\; R_{k\pi/2}\vec d_2\bigr)
\in\{0,1,2,3\}.
$$

伪代码

```cpp
void QuadCover::computeMatching() {
    matching.setZero();  // 边界边保持 0
    for (每条边 e) {
        if (e 是边界) continue;
        // 1) 面法向 → 切平面正交基 (t1,t2)
        // 2) faceDirs_[f] 点乘标架 → 2D，再单位化，得 d1_2d, d2_2d
        best = ∞; bestK = 0;
        for (k = 0; k < 4; ++k) {
            rot = Rotate2D(d2_2d, k * π/2);
            ang = acos(clamp(|dot(d1_2d, rot)|, 0, 1));
            if (ang < best) { best = ang; bestK = k; }
        }
        matching[e] = bestK;  // r: f1 → f2
    }
}
```

注意两点实现细节：

1. **夹角用 $|\vec d_1\cdot R_k\vec d_2|$**：cross field 无箭头，转 $180^\circ$ 与原方向等价，所以度量的是「线」的夹角，不是有向角。
2. **存储是无向的**：`matching[e]` 默认表示从 `e.f1` 走到 `e.f2`。反向查询必须变号，否则绕顶点累加会错。

#### 有向查询：`signedMatching`

```cpp
int QuadCover::signedMatching(int fromFace, int toFace) const {
    // 找到共享边 e
    if (e.f1==fromFace && e.f2==toFace) return  matching[e];
    if (e.f2==fromFace && e.f1==toFace) return -matching[e];
    return 0;
}
```

`computeLayerShift` 绕顶点一环按角序遍历相邻面，对每对 $(T_i,T_{i+1})$ 调用 `signedMatching`，把整数加总后再 $\bmod 4$ 映射到 $ls(v)$（见下一小节）。因此：**matching 是边数据；holonomy / 锥奇异点是顶点上一环 matching 的积分**。

算完 $r_e$ 之后，覆盖空间粘接规则就是 $(T_i,s)\sim(T_j,(s+r_{ij})\bmod 4)$——见下节。

### 由匹配诱导覆盖空间

对每个三角面 $T_i$ 复制 4 份，记为 $(T_i,s)$，其中 $s=0,1,2,3$ 是 sheet 编号。

 ![](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20251027120734402.png)

如果 $T_i$ 与 $T_j$ 共享边 $e_{ij}$，并且 matching 为 $r_{ij}$，则覆盖空间中的粘接规则为

$$
(T_i,s)\sim (T_j,(s+r_{ij})\bmod 4).
$$

这就是图中"由 matching 诱导 covering"的核心公式：跨边时不仅从一个三角形走到另一个三角形，还可能跳到另一个 sheet。

![](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250708195814043.png)

把所有边都按这个规则粘起来，就得到能展开 cross field 多值性的覆盖空间。

![](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20251027134959153.png)

#### 顶点的层偏移（layer shift）

对内部顶点 $v$，将其一环邻接三角形按几何角顺序排列为 $T_0,T_1,\ldots,T_{n-1}$（边界顶点不构成闭合回路，跳过）。沿这一圈累加**有向 matching**（注意：matching 是有向的——逆着边的存储方向走要取负）：

$$
\mathrm{holonomy}(v) = \sum_{i=0}^{n-1} r^\pm(T_i\to T_{i+1}),\qquad T_n=T_0.
$$

其中 $r^\pm(T_a\to T_b)$：若遍历方向与边的存储顺序 $(f_1,f_2)$ 一致则取 $+r_{ab}$，若相反则取 $-r_{ab}$。

此时 **先不取模**，得到整数 holonomy 总和。再取 $\bmod 4$ 并映射到 $\{-1,0,1\}$：

$$
h = \mathrm{holonomy}(v)\bmod 4,\qquad
h' = \begin{cases} h-4, & h>2 \\ h, & \text{otherwise} \end{cases},\qquad
ls(v) = \frac{h'}{4} \in \left\{-\tfrac14,\ 0,\ \tfrac14\right\}.
$$

关键点：**不能先模 4 再除 4**——那样会丢失正负方向的信息（$\bmod 4$ 后 $h\in\{0,1,2,3\}$，除 4 得不到负值）。正确的做法是先算出代数净旋转量（可以大于 3），再取模并映射回 $[-1,1]$，最后除以 4。$ls(v)=0$ 表示绕顶点一圈后回到原 sheet，是普通点；$ls(v)=\pm\tfrac14$ 表示绕一圈后发生净 $\pm90^\circ$ 旋转，顶点成为**分支点**，也对应参数化中的**锥奇异点**。

![](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20251204210126045.png)

#### 分支覆盖的核心作用：消除 Holonomy

分支覆盖的根本作用是将"多值的场 + 带奇点的拓扑"转化为"单值的场 + 分支覆盖空间"。这里有三层含义：

1. **消去 holonomy**：matching $r_{ij}$ 编码了一个 $\mathbb Z_4$-值 1-cocycle。绕顶点一圈的累计 matching 就是局部 holonomy；在覆盖空间上，这个闭环会展开到不同 sheet 中。
2. **将多值场提升为单值场**：cross field 的 4-RoSy 对称性在基空间上表现为多值，在 cover 上则对应四个 sheet 中的普通向量场。
3. **将 singularities 转化为分支点**：$ls(v)\neq 0$ 的顶点不再只是场的奇异性，而成为覆盖空间的分支结构。

关系链可以写成：

$$
\text{matching} \;\longrightarrow\; \text{covering} \;\longrightarrow\; \text{holonomy elimination} \;\longrightarrow\; \text{single-valued field}
$$

例如立方体展开中若 $r_{01}=r_{12}=0, r_{20}=1$，则基空间上闭合环路 $T_0\to T_1\to T_2\to T_0$ 会累计一个 $90^\circ$ 旋转；在 4-sheet cover 中，它被展开成跨 sheet 的路径，累计旋转由 sheet 编号记录。

## 覆盖空间中的标量函数空间

覆盖空间构造完成后，参数化问题归结为：在 $\hat M$ 上找一个标量函数，使其梯度尽量贴近已提升的 covering field。只有当一个向量场是某个标量函数的梯度时，才能把它解释成参数坐标的微分：

$$
\hat X = \nabla u \quad \text{或} \quad \hat X = \nabla v.
$$

如果场里残留旋度，沿不同路径积分会得到不同结果，参数值依赖路径，最终无法形成单值且全局一致的 UV 参数化。

frame field 先提升为 cover 上的单值向量场 $\hat K$；右半部分说明参数化就是找 $\phi$，使 $\nabla\phi$ 逼近 $\hat K$。若 $\hat K$ 不可积，则通过 Hodge 分解去掉旋度部分：

$$
\hat K = P_{\hat K} + C_{\hat K} + H_{\hat K},
\qquad
\tilde{\hat X} = P_{\hat K} + H_{\hat K}.
$$

$\tilde{\hat X}$ 是最接近原场、同时又可积的部分，存在 $\phi$ 使 $\nabla\phi=\tilde{\hat X}$。

### 对称覆盖函数与二维参数化

参数化函数是定义在覆盖空间上的标量函数，允许在 cut graph 处不连续，但跨边跳变只能是整数平移。设 $G$ 是 $M$ 的 cut graph，定义函数空间

$$
\hat S_r(\hat M)=\{\text{在 }\hat M\text{ 上分段线性、除 }G\text{ 外连续的函数}\}.
$$

$f\in\hat S_r(\hat M)$ 称为**对称覆盖函数**，若对每个 chart $U$ 和点 $p\in U$，其在四个 sheet 上的取值满足

$$
f(\tau_U^0(p))=-f(\tau_U^2(p)),\qquad
f(\tau_U^1(p))=-f(\tau_U^3(p)).
$$

**为什么是反对称？** 这个条件并非凭空强加，而是 cover 上向量场方向的自然推论。回顾 Phase 3 中对每个 sheet $s$ 的标架定义：

| sheet $s$ | $\vec X$ 方向 | $\vec Y$ 方向 |
|:---:|:---:|:---:|
| 0 | $+\vec d_i$ | $+\vec d_i^\perp$ |
| 1 | $+\vec d_i^\perp$ | $-\vec d_i$ |
| 2 | $-\vec d_i$ | $-\vec d_i^\perp$ |
| 3 | $-\vec d_i^\perp$ | $+\vec d_i$ |

可见 sheet 0 和 sheet 2 的 $\vec X$ 方向恰好**反向**（$+\vec d_i$ vs $-\vec d_i$），sheet 1 和 sheet 3 同理。而 $u'$ 函数是要逼近 $\vec X$ 方向的标量函数，即 $\nabla u' \approx \vec X$。因此若 sheet 0 上 $\nabla u' \approx +\vec d_i$，在 sheet 2 上就必须 $\nabla u' \approx -\vec d_i$——这意味着 $u'$ 在 sheet 0 和 sheet 2 上取反号才一致。这正是 $f(\tau_U^0)=-f(\tau_U^2)$ 的物理含义：**标量函数的反对称性编码了 cross field 的 180° 旋转对称性**。同理 $f(\tau_U^1)=-f(\tau_U^3)$ 对应剩余的一对。

没有这个约束，两个 sheet 上的 $u'$ 可以独立变化，投影回基空间时会得到互相矛盾的方向——参数化就失去了作为四边形网格方向引导的意义。

二维参数化由两个对称覆盖函数组成：

$$
\phi'=(u',v'),\qquad \nabla\phi'=(\nabla u',\nabla v').
$$

投影回基曲面 $M$ 时，只取 layer $0,1$ 上的值：

$$
\phi_i(p)=
\begin{bmatrix} u_i(p)\\ v_i(p) \end{bmatrix}
=
\begin{bmatrix} u'(\tau_U^0(p))\\ v'(\tau_U^1(p)) \end{bmatrix}.
$$

**为什么 $u$ 取 layer 0、$v$ 取 layer 1？** 回顾 Phase 3 的标架定义：在 sheet 0 上有 $\vec X_0 = +\vec d_i$，这正是基空间 cross field 的参考方向（即 $u$ 方向）；而在 sheet 1 上有 $\vec X_1 = +\vec d_i^\perp$，是 cross field 的正交方向（即 $v$ 方向）。cover 上逼近 $\vec X$ 的标量函数在 sheet 0 处的取值自然对应基空间 $u$ 坐标，在 sheet 1 处的取值对应基空间 $v$ 坐标。

**分支顶点的投影**：$ls(v)\neq 0$ 的顶点在 cover 上有多个 preimage（分布在多个 sheet），不能简单取某一层的值。实现中将这些 preimage 上的 UV 取**算术平均**作为基空间顶点的最终 UV。普通顶点（$ls(v)=0$）则直接取 sheet 0 上的 cover UV。最后将 $(u,v)$ 线性缩放归一化到 $[0,1]^2$。

离散实现中，每个三角形 $T$ 的每个角点 $p$ 存储二维向量 $\phi|_T(p)=(u_{T,p},v_{T,p})$。相邻 chart $U_i,U_j$ 在公共边上的转移关系为

$$
\begin{bmatrix} u_i\\ v_i \end{bmatrix}
= J^{-r_{ij}}
\begin{bmatrix} u_j\\ v_j \end{bmatrix}
-\mathbf t_{ij},
\qquad
\mathbf t_{ij}\in\mathbb Z^2.
$$

若进一步要求全局参数线连续，则只允许在 cut graph 上出现非零平移 $\mathbf t_{ij}$。满足整数平移约束的函数构成子空间 $S_r(\hat M)\subset\hat S_r(\hat M)$。


**从对称函数到二维参数化——完整的数学通道**

前述构造的核心在于：cover 上的对称标量函数自然承载了基空间 cross field 的几何信息，而两个对称函数一起构成了二维参数化。下面是其数学形式化。

**对称函数与无旋向量场的对应**。cover $\hat M$ 上的分段线性函数空间 $\hat S_r(\hat M)$ 有一个关键性质：其梯度算子 $\nabla$ 的值域恰为 $\hat M$ 上的全体**无旋（curl-free）分段常向量场**，即

$$
\nabla\bigl(\hat S_r(\hat M)\bigr) = \{\text{curl-free vector fields on } \hat M\}.
$$

这是分段线性设定下的经典结论（Polthier & Preuß, 2003）：curl-free 向量场可表为某标量函数的梯度，且该函数除 cut graph 外连续。因此，Phase 2 的 Poisson 重构等价于在 $\hat S_r(\hat M)$ 中寻找一个对称函数 $f$ 使 $\nabla f$ 尽可能逼近 cross field 的提升场 $\vec X$。

**投影回基空间——二维参数化**。一个对称覆盖函数 $f\in\hat S_r(\hat M)$ 可通过取 cover 上两个特定 layer 的值，投影为基曲面 $M$ 上的二维参数化：

$$
\phi_i(p) =
\begin{bmatrix} u_i(p) \\ v_i(p) \end{bmatrix}
:=
\begin{bmatrix} f(\tau_U^0(p)) \\ f(\tau_U^1(p)) \end{bmatrix}
\in \mathbb R^2.
$$

其中 $u$ 取 layer 0（对应 $\vec d_i$ 方向）、$v$ 取 layer 1（对应 $\vec d_i^\perp$ 方向）。选择这两个 layer 的依据已在 Phase 3 的标架定义表中说明：layer 0 的 $\vec X$ 方向与基空间 $+\vec d_i$ 对齐，layer 1 的 $\vec X$ 方向与 $+\vec d_i^\perp$ 对齐。

**chart 间的转移关系**。在相邻 chart $U_i,U_j$ 共享的三角形上，参数化值通过整数倍 $90°$ 旋转加平移连接：

$$
\begin{bmatrix} u_i \\ v_i \end{bmatrix}
= J^{-r_{ij}}
\begin{bmatrix} u_j \\ v_j \end{bmatrix}
- \mathbf t_{ij},
\qquad
\mathbf t_{ij} \in \mathbb R^2.
$$

其中 $J=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$ 是 $+90°$ 旋转矩阵，$r_{ij}\in\{0,1,2,3\}$ 为匹配整数。$J^{-r_{ij}}$ 负责对齐坐标系方向，平移项 $\mathbf t_{ij}$ 来自 cover 上函数跨边的整周期跳变。

**整周期约束与参数线连续性**。若要使等值线在跨 chart 时不发生非整数偏移而保持全局连续，平移向量 $\mathbf t_{ij}$ 必须落在整数格点 $\mathbb Z^2$ 上——此时转移函数是**格点自同构**（grid automorphism，见式 (2)）。因此最后的求解空间为

$$
S_r(\hat M) := \{\,f \in \hat S_r(\hat M) \;\mid\;
\forall\; \text{相邻 }T_i,T_j : \mathbf t_{ij} \in \mathbb Z^2 \,\}.
$$

**整数平移的规范化**。$S_r(\hat M)$ 中任意 chart 的函数值可整体平移一个整数向量而不改变梯度场或参数线的拓扑——即参数化结果在整数平移下等价。因此可假定：除 cut graph $G$ 上的边外，所有 $\mathbf t_{ij}=0$；非零平移仅发生在 cut 处。这同时意味着函数的"自由度"集中在 cut graph 上，与后文连续基/不连续基的分解一致。


### 函数空间的基

$\hat S_r(\hat M)$ 是有限维的，其维数由连续基 $\{\Phi_i\}$（cover 顶点数 $V_c$ 个）和不连续基 $\{\hat\Phi_j\}$（独立 cut path 数量 $n_p$ 个）共同决定。

**cut path 的数量与构造**。设曲面 $M$ 的欧拉示性数 $\chi = V - E + F$，有 $n_b$ 个边界分量，亏格 $g = (2-\chi-n_b)/2$。则需要构造的独立 cut path 数量为：

$$
n_p = 2g + n_b - 1.
$$

（闭曲面 $n_b=0$ 时 $n_p = 2g$。）

具体构造分两步：
1. **同调环路径**：在面邻接图上做 spanning tree，每条 **cotree 边**（不在树中的边）对应一个同调生成环——从该边的两个端点沿树路径回溯到根，形成闭合回路。共 $2g$ 条（闭曲面）或 $2g + n_b - 1$ 条（开曲面）。
2. **边界连接路径**：当存在多个边界分量时，还需构造连接不同边界分量的路径（通过 BFS 找到），数量为 $n_b-1$。

记 $S_h(\hat M)$ 为 cover 上连续的分段线性函数空间，其基为 $\{\Phi_i\}$；再取 $n_p$ 条 cut path $\{\gamma_j\subset G\}$，对每条路径定义不连续基函数 $\hat\Phi_j$：路径右侧顶点取值 $1$，左侧取值 $0$，其余为 $0$。则

$$
\{\Phi_i\}\cup\{\hat\Phi_j\}
$$

构成 $\hat S_r(\hat M)$ 的一组基。任意 $f\in\hat S_r(\hat M)$ 可写成

$$
f=\sum_i \lambda_i(f)\,\Phi_i+\sum_j \mu_j(f)\,\hat\Phi_j.
$$

对称性要求系数满足

$$
\lambda_{2i}=-\lambda_{2i+1},\qquad
\mu_{2j}=-\mu_{2j+1}.
$$

$\mu_j(f)$ 正是沿 cut path $\gamma_j$ 的 **period 系数**：$\nabla\hat\Phi_j$ 是 curl-free 的（跳跃只在路径本身，路径两侧之间），且沿 $\gamma_j$ 的积分非零。因此全局无缝参数化的条件等价于所有 period 系数落在整数格上：

$$
\mu_j(\phi)\in\mathbb Z.
$$

**纯四边形 vs 普通四边形**。若要求生成的四边形网格所有面都是纯四边形（即奇异点恰好落在格点上，而非格心），则需要 period 系数为偶数：$\mu_j(\phi)\in 2\mathbb Z$。这是因为偶 period 保证绕奇点一圈回到的是同一"类型"的格点（格点 $2\mathbb Z$ 而非格心 $2\mathbb Z+1$）。若只需普通四边形网格（允许少数三角形），则舍入到 $\mathbb Z$ 即可。

### 在基上求解

在固定 matching 后，最优参数化 $\tilde\phi$ 最小化能量

$$
E(\phi)=\int_{\hat M}\lVert \nabla\phi-\hat K\rVert ^2\,dA,
\qquad
\phi\in\hat S_r(\hat M).
$$

离散上这等价于在 cover 上解 Poisson 方程得到 $\tilde\phi$。但 $\tilde\phi$ 在 cut graph 处可能仍有 period 误差。令

$$
\Delta\mu_j=\mathrm{round}(\mu_j(\tilde\phi))-\mu_j(\tilde\phi),
$$

再构造 harmonic 函数 $\psi$，使 $\mu_j(\psi)=\Delta\mu_j$ 且 $\Delta\psi=0$，最终取

$$
\phi=\tilde\phi+\psi.
$$

这样就把"在函数空间中找解"变成"先 Poisson 积分，再用有限个 period 系数做 harmonic 修正"。



## 算法流程

### 算法输入

QuadCover 的输入有两项：

| 输入                 | 含义                                                         | 代码中的来源                                                 |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **三角网格**         | 三角化曲面 $M$，每个面 $T_i$ 为一张 chart                    | 构造函数 `QuadCover(Mesh& mesh)`；`mesh` 由 OBJ 等读入       |
| **初始 cross field** | 每个三角形上一个 4-RoSy 参考方向 $\vec d_i$（切平面内单位向量） | `setCrossField(dirs)`，`dirs` 为 `nFaces × 3`；未设置时由主曲率方向自动估计 |

主曲率方向是最常用、也最自然的 cross field 来源：它与几何特征对齐，生成的四边形网格往往更贴合形状。算法本身**不强制**方向场必须来自主曲率——只要提供满足四重旋转对称的 frame field（例如 MIQ 优化结果、用户手绘方向、曲率场等），都可以作为目标场去构造参数化。

### 主要流程

| Phase | 名称                       | 主要操作                                                     |
| ----- | -------------------------- | ------------------------------------------------------------ |
| 0     | 预处理                     | 输入 cross field → $\theta_i$；matching；matching 感知平滑   |
| 1     | Matching                   | 4-RoSy quarter-turn 对齐，得 $r_{ij}\in\{0,1,2,3\}$          |
| 2     | Layer shift & Branch cover | 面环 holonomy 得 $ls(v)$；4-sheet 粘接构造 branch cover      |
| 3     | Covering field             | 每个 $(T_i,s)$ 上旋转 $\vec d_i$ 得正交方向场 $(\vec X,\vec Y)$ |
| 4     | Hodge / Poisson            | 在 cover 上解 $L\tilde u=\mathrm{div}(\vec X),\;L\tilde v=\mathrm{div}(\vec Y)$，得 $\tilde\phi=(\tilde u,\tilde v)$ |
| 5     | 全局连续性                 | 构造 cut paths；舍入 $\mu_j$ 到 $2\mathbb Z$；加 harmonic 修正 $\psi$ |
| 6     | 投影输出                   | branch 顶点取 sheet 平均；归一化 UV 写回网格                 |

#### 算法预处理（Phase 0）：对输入 cross field 做平滑

脐点区域附近，两个主曲率趋于相等，主方向会失去稳定定义，数值上非常容易抖动。  如果直接把这些不稳定方向送进后续优化，会把大量高频噪声误认为真实几何信号。  因此 Phase 0 在**已有初始 cross field 之上**做 matching 感知平滑，目的是得到拓扑结构更合理、奇异点更可控的方向场。

**离散实现（Phase 0）** 分三步：

1. **读入方向场**：使用 `setCrossField()` 传入的 $\vec d_i$；若未设置，则对每个三角形用 Weingarten 算子 $W=I^{-1}\cdot II$ 的特征分解估计主曲率方向。将 $\vec d_i$ 转为局部角 $\theta_i\in[0,\pi/2)$。
2. **首次 matching**：按上文 quarter-turn 对齐公式计算每条内部边的 $r_{ij}$。
3. **matching 感知平滑**：迭代更新

$$
\theta_i \leftarrow \text{normalize}\Big(\tfrac12\,\theta_i + \tfrac12\big(\theta_j + \tfrac{\pi}{2}\,r_{ij}\big)\Big),
$$

其中 $T_i,T_j$ 共享边且 $r_{ij}$ 为从 $T_i$ 到 $T_j$ 的 matching。默认迭代 3 次。平滑后重建 $\vec d_i$，并**重新计算 matching**，再进入 layer shift 与 branch cover 构造。

#### Phase 2–3：Branch cover 与方向场提升

对每个三角形 $T_i$ 取参考方向 $\vec d_i$，其正交补为 $\vec d_i^\perp=\vec n_i\times \vec d_i$。在 sheet $s$ 上令

$$
\vec X_{i,s}=\cos(s\pi/2)\,\vec d_i+\sin(s\pi/2)\,\vec d_i^\perp,
\vec Y_{i,s}=-\sin(s\pi/2)\,\vec d_i+\cos(s\pi/2)\,\vec d_i^\perp.
$$

这样在 cover 上得到单值正交标架场，供 Phase 4 积分。

### 求最优化

在 cover 上已经有目标向量场 $K$，希望找到一个参数函数 $\phi$，使得 $\nabla\phi$ 尽量接近 $K$：

$$
\min_{\phi}\int_{\hat M}\lVert \nabla\phi-K\rVert ^2\,dA.
$$

如果 $K$ 本身不可积，就不能直接写成某个函数的梯度。

### Hodge分解

通过对 $K$ 做 Hodge 分解：
$$
K = P_K + C_K + H_K,
$$

其中 $C_K$ 是带来旋度、妨碍积分的部分。去掉 $C_K$ 后，$P_K+H_K$ 就是最接近原始场、同时又可积的部分。Hodge 分解在这里把"尽量贴近输入方向场"和"必须能积分成参数函数"统一到同一个最小二乘问题里。

**Hodge 分解如何落地为 Poisson 求解？** 离散情形下的关键在于：对任意向量场 $\vec X$，求解 $L u = \mathrm{div}(\vec X)$ 等价于找到 $\nabla u$ 使其在 $L^2$ 意义下最接近 $\vec X$。取变分：

$$
\min_u \lVert \nabla u - \vec X\rVert ^2 \;\Longrightarrow\; \nabla\cdot(\nabla u - \vec X)=0 \;\Longrightarrow\; \Delta u = \nabla\cdot\vec X.
$$

这就是 Poisson 方程。**Cotangent Laplacian $\Delta$ 的正则性自动扮演了"投影到 curl-free 子空间"的角色**——它的解 $u$ 天然满足 $\nabla\times(\nabla u)=0$，因此 $\nabla u$ 不含任何旋度分量 $C_K$。换句话说，$L\tilde u=\mathrm{div}(\vec X)$ 的解 $\tilde u$，其梯度 $\nabla\tilde u$ 就是 $\vec X$ 的 Hodge 分解中 $P_{\vec X}+H_{\vec X}$ 对应的那个"势场"。

**离散算子的构造**（在 cover 三角网格上）：
- **Cotangent Laplacian** $L$：$L_{ij}= -\frac12(\cot\alpha_{ij}+\cot\beta_{ij})$（边 $ij$ 的对角），$L_{ii}=-\sum_{j\neq i}L_{ij}$；
- **离散散度** $\mathrm{div}(\vec X)$：对顶点 $i$，$\mathrm{div}(\vec X)_i = \frac12\sum_{T\in N(i)} \vec X_T\cdot \nabla \phi_i^T$，其中 $\phi_i^T$ 是 $T$ 上顶点 $i$ 的分片线性 hat 函数，$\nabla\phi_i^T$ 为其梯度。

**离散 Poisson 求解（Phase 4）**：在 branch cover 三角网格上用上述算子，分别求解

$$
L\,\tilde u = \mathrm{div}(\vec X), L\,\tilde v = \mathrm{div}(\vec Y).
$$

每个连通分量固定一个 anchor 顶点（$\tilde u=\tilde v=0$）以消除常数零空间。解 $(\tilde u,\tilde v)$ 即为 Hodge 分解中去掉旋度部分后的最优可积逼近 $\tilde\phi=(\tilde u,\tilde v)$。

### 全局连续性的处理（Phase 5）

Phase 4 的 Poisson 求解得到的是"局部可积"的 $\tilde\phi$——它在每个面片内部 curl-free，满足 $\nabla\tilde u \approx \vec X$、$\nabla\tilde v \approx \vec Y$。但走到这一步还不算全局无缝：**沿非平凡拓扑环路（handle 环、边界间路径）走一圈后，$\tilde\phi$ 可能留下分数 period 误差**，即 $\mu_j(\tilde\phi)$ 不是整数。Phase 5 的任务就是修正这些 period，使之落在整数格（或偶数格）上。

Phase 5 分以下四步：

#### Step 5.1：构造 cut graph 与同调路径

在面邻接图上做 BFS spanning tree，**每条 cotree 边**（不在树中的内部边）对应一条同调生成环：从该 cotree 边的两端面各自沿树回溯到根，形成闭合回路。共 $2g$ 条（闭曲面 $n_b=0$）或 $2g+n_b-1$ 条（有边界）。若有多个边界分量，还需通过 BFS 构造连接各边界分量的路径。

#### Step 5.2：计算 period 系数 $\mu_j$

将 $\tilde\phi$ 沿每条有向路径 $\gamma_j$ 积分（离散上为沿路径的边差分之和）：

$$
\mu_j^u(\tilde\phi)=\sum_{e\in\gamma_j}\big(\tilde u(v_b)-\tilde u(v_a)\big),\qquad
\mu_j^v(\tilde\phi)=\sum_{e\in\gamma_j}\big(\tilde v(v_b)-\tilde v(v_a)\big).
$$

若 $\mu_j^u$ 或 $\mu_j^v$ 不是整数，说明绕此环走一圈后 UV 参数无法与自身无缝对接。

#### Step 5.3：harmonic 修正

令目标 period 为舍入值：

$$
\Delta\mu_j^u = \mathrm{round}_{S}\big(\mu_j^u(\tilde\phi)\big)-\mu_j^u(\tilde\phi),\qquad
S=\begin{cases}2\mathbb Z,&\text{纯四边形}\\ \mathbb Z,&\text{普通四边形}\end{cases}
$$

$round_{S}(x)$ 将 $x$ 舍入到最近的目标格点（纯四边形时 $2\cdot\mathrm{round}(x/2)$，普通四边形时 $\mathrm{round}(x)$）。

对 $u,v$ 分量分别处理。以 $u$ 为例：在 cover 的 cotangent Laplacian $L$ 上，对每条 $\gamma_j$ 求解带 period 约束的 harmonic 基函数：

$$
\begin{cases}
L\,h_j = 0 & \text{（除锚点外）} \\
\mu_k(h_j) = \delta_{kj} & \text{（period 约束）}
\end{cases}
$$

将 $L$ 扩展为块矩阵 $\begin{bmatrix}L & P^T\\ P & 0\end{bmatrix}$，其中 $P$ 是 period 约束矩阵。求得 $\{h_j\}$ 后，修正量为

$$
\psi_u = \sum_{j} \Delta\mu_j^u\, h_j,\qquad u = \tilde u + \psi_u.
$$

对 $v$ 分量同理。修正后的 $\phi=(u,v)$ 在所有同调环上的 period 都精确落在目标格点，**全局无缝**。

#### Step 5.4：输出与验证

重新计算一次 period 系数以确认修正成功。然后进入 Phase 6 投影输出：普通顶点取 sheet 0 的 cover UV，分支顶点取所有 sheet preimage 的均值，最后归一化到 $[0,1]^2$。

## 贯穿示例：一个带 $+90^\circ$ 奇异点的简单 patch

以下用一个最小化示例走通全流程。设顶点 $v_0$ 被 4 个三角形 $T_0,T_1,T_2,T_3$ 环绕（想象一个"十字形"平面 patch，中心是 $v_0$），cross field 参考方向如右安排使绕 $v_0$ 一圈净旋转 $+90^\circ$。

### ① Matching

| 边  | 方向          | $r_{ij}$ |
|:---:|:---:|:---:|
| $T_0$–$T_1$ | $T_0\to T_1$ | $0$ |
| $T_1$–$T_2$ | $T_1\to T_2$ | $0$ |
| $T_2$–$T_3$ | $T_2\to T_3$ | $0$ |
| $T_3$–$T_0$ | $T_3\to T_0$ | $1$ |

前三边方向一致，最后一跨发生了 $90^\circ$ quarter-turn。

### ② Layer Shift

绕 $v_0$ 一圈累加有向 matching：$\mathrm{holonomy}(v_0)=0+0+0+1=1$。$h=1\bmod 4=1$，$h'=1$，故 $ls(v_0)=1/4$——$v_0$ 是一个 $+90^\circ$ 锥奇异点。

### ③ 4-Sheet 覆盖空间粘接

每个三角形复制 4 份 $(T_i,0),(T_i,1),(T_i,2),(T_i,3)$。按 $r_{ij}=0$ 的边同层粘接，$r_{34}=1$ 的边跨层粘接 $(T_3,s)\sim(T_0,s+1)$。

从 $(T_0,0)$ 出发绕 $v_0$ 一圈：

$$
(T_0,0)\xrightarrow{r_{01}=0}(T_1,0)\xrightarrow{r_{12}=0}(T_2,0)\xrightarrow{r_{23}=0}(T_3,0)\xrightarrow{r_{30}=1}(T_0,1).
$$

**回到 $T_0$ 时已经在 sheet 1 而非 sheet 0！** 在覆盖空间视角下，这不是"回路不闭合"，而是这条闭环被展开到了跨 sheet 的螺旋路径——holonomy 被消除，场变成了单值的。

### ④ 覆盖场 & Poisson

设 $\vec d_0$ 指向右侧。则在 cover 上 $\vec X_{(T_0,0)}=+\vec d_0$，解 Poisson 方程得 $\tilde u$ 沿 $+\vec d_0$ 递増。在 sheet 1 上 $\vec X_{(T_0,1)}=+\vec d_0^\perp$（$+90^\circ$ 旋转），解得的 $\tilde v$ 沿 $\vec d_0^\perp$ 递増。

此时 $\tilde u$ 在 $T_0$ 上跨 $v_0$ 的 cut 处可能有分数 period。

### ⑤ Period 修正

将 $\tilde u$ 沿 cut path 积分，假设得到 $\mu(\tilde u)=0.2$（并非整数）。舍入 $0.2\to 0$，$\Delta\mu=-0.2$。构造 harmonic 基函数 $h$ 使 $\mu(h)=1$，令 $u=\tilde u-0.2\cdot h$。修正后的 $u$ 在 cut 两侧无缝对齐。对 $v$ 分量同理。

### ⑥ 投影

普通顶点：$u(p)=u'(\tau^0(p)),\ v(p)=v'(\tau^1(p))$。分支顶点 $v_0$：取所有 sheet preimage 上 UV 的平均（共 4 个值）。最后缩放归一化。

**关键收获**：matching $r_{30}=1$ 是唯一的 quarter-turn 边 → holonomy=$+1$ → $ls(v_0)=1/4$ → 4-sheet cover 将这一圈展开为螺旋 → Poisson 得到局部可积的 $\tilde\phi$ → period 舍入修正掉 cut 上的分数误差 → 全局无缝。整个过程从 matching 到无缝 UV 是一气呵成的因果链条。
