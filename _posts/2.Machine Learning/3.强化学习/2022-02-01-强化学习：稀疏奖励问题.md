## 问题定义

在标准强化学习框架中，智能体通过与环境交互获得奖励信号来学习最优策略：

$$\max_{\pi} \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t r_t\right]$$

**稀疏奖励 (Sparse Reward)** 指的是：奖励信号仅在**极少的状态**下非零（通常只有任务成功/失败时才给出 +1/-1），其余所有时间步的奖励均为 0。

### 典型场景

| 场景 | 稀疏奖励形式 |
|:-----|:-------------|
| **机器人抓取** | 抓到物体 = +1，否则 = 0 |
| **导航/迷宫** | 到达目标 = +1，否则 = 0 |
| **游戏通关** | 胜利 = +1，失败 = -1 |
| **分子生成** | 满足性质约束 = +1 |

### 核心难点

```
问题本质：探索-利用困境 (Exploration vs. Exploitation) 的极端形式

状态空间: ████████████████████████████████  (巨大)
           ↑                                   ↑
        起点                                目标 (+1)
        
奖励信号: ···································+  (几乎全是零)
                                    ↑
                              需要精确的
                              长序列动作
                              
→ 随机探索几乎不可能碰到目标 → 无法形成有效的梯度信号 → 策略无法更新
```

> **形象比喻**：在完全黑暗的迷宫中寻找出口——没有墙壁碰撞反馈，只有走出迷宫时才被告知"成功了"。随机乱走找到出口的概率趋近于零。

## Reward Shaping（奖励塑形）

**核心思想**：在不改变最优策略的前提下，人为设计**稠密的中间奖励**来引导智能体的学习过程。

### Potential-Based Reward Shaping (PBRS)

由 Ng et al. (1999) 提出的经典理论框架，保证**策略不变性**：

$$F(s, s') = \gamma \Phi(s') - \Phi(s)$$

其中 $\Phi: S \to \mathbb{R}$ 是一个**势函数** (potential function)，$\gamma$ 为折扣因子。

**修改后的奖励**：
$$r'(s, a, s') = r(s, a, s') + F(s, s')$$

**关键定理**：在 PBRS 下，原始 MDP 和塑形后 MDP 的**最优策略完全相同**（顺序保持不变），但后者通常收敛更快。

### 势函数设计示例

#### 导航任务 — 距离势函数

$$\Phi(s) = -\|p_s - p_{goal}\|_2$$

则过渡奖励为：
$$F(s, s') = -\gamma \|p_{s'} - p_{goal}\| + \|p_s - p_{goal}\|$$

**效果**：每一步都根据到目标的距离变化给予奖励，越靠近目标奖励越高。

```python
# PBRS 实现示例
def potential_based_reward(state, next_state, gamma=0.99):
    phi = lambda s: -np.linalg.norm(s.position - goal_position)
    return gamma(phi(next_state)) - phi(state)
```

#### 其他常用势函数

| 任务类型 | 势函数 $\Phi(s)$ | 直觉含义 |
|:---------|:------------------|:---------|
| 导航 | $-\|s - s_{goal}\|$ | 距离目标越近越好 |
| 抓取 | $\mathbb{1}_{\text{接近}}$ | 接近物体给正势能 |
| 平衡 | $-\|\theta\|$ | 角度越小越好（倒立摆等） |

### 局限性与陷阱

| 问题 | 描述 | 后果 |
|:-----|:-----|:-----|
| **Reward Hacking** | 智能体找到"作弊"方式获取高塑形奖励而不真正完成任务 | 学到的不是期望行为 |
| **势函数设计困难** | 复杂任务中难以手工设计好的 $\Phi$ | 可能引入误导信号 |
| **信息泄漏** | 势函数隐含了过多先验知识 | 泛化能力下降 |
| **局部最优** | 错误的塑形可能将智能体困在局部最优 | 收敛到次优策略 |

> **经验法则**：好的 reward shaping 应该是**启发式的引导**而非**确定性的路径指定**。

## HER（Hindsight Experience Replay）

**出处**：Andrychowicz et al., "Hindsight Experience Replay", NeurIPS 2017 (OpenAI). 专文笔记见 [Hindsight Experience Replay（HER）]({% post_url 2.Machine Learning/3.强化学习/2024-04-01-Hindsight-Experience-Replay %}).

### 核心洞察

> **失败的经验也是宝贵的**——虽然没达到原定目标，但至少达到了某个别的目标。

对于多目标环境中的稀疏奖励问题（如机械臂推动物体到达指定位置）：

- 原始目标：将物体推到位置 $g$
- 实际到达：位置 $g'$（与 $g$ 不同）
- **HER 思路**：把这次经验重新标记为"目标是 $g'$ 的成功经验"

### 算法流程

```
标准 DDPG/TD3 经验:
    (s_t, a_t, r_t, s_{t+1}, g)   其中 g 是原始目标
    
HER 重放策略:
    对于存储的 transition (s_t, a_t, r_t=0, s_{t+1}, g):
        1. 取实际达到的状态 s_{t+1}
        2. 计算 g' = f_achieved(s_{t+1})  ← "实际达成的新目标"
        3. 重新计算奖励: r' = r(s_{t+1}, g')
           若使用 goal-conditioned reward: r' = -||f(s_{t+1}) - g'|| 
           则此时 r' ≈ 0 (或很小的正值)！
        4. 存储: (s_t, a_t, r', s_{t+1}, g') 作为额外样本
```

### Goal Conditioning 形式化

HER 要求将 MDP 扩展为 **Goal-Conditioned MDP**：

- 状态：$(s, g)$，其中 $s$ 是环境状态，$g$ 是目标
- 动作：$a$
- 转移：$s' \sim P(\cdot | s, a)$（目标不变）
- 奖励：$r(s', g) = -\|f(s') - g\|_2$（或稀疏版本：$r = \mathbb{1}[\|f(s') - g\| < \epsilon]$）

策略网络变为：$\pi_\theta(a | s, g)$ —— 根据**当前状态和目标**选择动作。

### 目标采样策略

HER 论文对比了四种重放策略：

| 策略 | 说明 | 表现 |
|:-----|:-----|:-----|
| **final** | 用最终状态作为新目标 | 好 |
| **future** | 从未来 $k$ 步中随机选一个状态作为新目标 | ✅ **最佳** |
| **episode** | 同一 episode 中随机选 | 一般 |
| **random** | replay buffer 中随机选 | 较差 |

**Future 策略**（推荐默认使用）：
```python
def make_her_transitions(episode_transitions, k=4):
    her_batch = []
    for t, trans in enumerate(episode_transitions):
        # 以概率 k/(T-t+1) 使用 future 策略
        if random() < k / (len(episode_transitions) - t):
            # 从未来 k 步中随机取一个 achieved goal
            future_idx = randint(t, len(episode_transitions) - 1)
            new_goal = episode_transitions[future_idx].achieved_goal
            # 重算奖励
            new_reward = compute_reward(new_goal, episode_transitions[t+1].achieved_goal)
            her_batch.append(replace_goal_and_reward(trans, new_goal, new_reward))
    return her_batch
```

### 适用条件与局限

| ✅ 适合 | ❌ 不适合 |
|:--------|:----------|
| 多目标/参数化目标空间（如机器人操作） | 单一固定目标的任务 |
| 目标可从状态中提取（achieved goal 可计算） | 成功/失败二元结果无中间度量 |
| 与 off-policy 算法结合（DDPG/TD3/SAC） | 纯 on-policy（PPO/TRPO）需改造 |
| 连续动作空间 | 离散动作空间（也可用但收益较低） |

## Demonstrations（演示学习 / 模仿学习）

当奖励过于稀疏以至于纯 RL 几乎无法起步时，**直接提供专家演示数据**是一条有效的出路。

### 三大范式

#### 1. Behavioral Cloning (BC，行为克隆)

**最简单的模仿学习方法**：将演示数据视为监督学习问题。

$$\min_\theta \sum_{i=1}^{N} \mathcal{L}(\pi_\theta(s_i), a_i^{demo})$$

其中 $\{(s_i, a_i^{demo})\}$ 来自专家轨迹。

```python
# Behavioral Cloning 伪代码
class BCAgent(nn.Module):
    def __init__(self, state_dim, action_dim):
        self.policy = nn.Sequential(
            nn.Linear(state_dim, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, action_dim),
            nn.Tanh()  # 有界动作空间
        )
    
    def update(self, demo_states, demo_actions):
        pred_actions = self.policy(demo_states)
        loss = F.mse_loss(pred_actions, demo_actions)
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()
```

**致命弱点 — 复合误差 (Compounding Error)**：

$$P(e_{t+1}) > P(e_t) \quad \Rightarrow \quad \text{误差随时间步指数级累积}$$

一旦智能体偏离专家轨迹一点点，就会进入**训练分布之外的状态分布**，误差不断放大，最终彻底失控。

#### 2. Inverse Reinforcement Learning (IRL，逆向强化学习)

**思路**：不直接学策略，而是先从演示中**反推潜在的奖励函数**，再用该奖励函数训练 RL 策略。

$$\text{Demonstrations } \{(s_i, a_i)\} \xrightarrow{\text{IRL}} r^*(s, a) \xrightarrow{\text{RL}} \pi^*$$

**经典方法 — MaxEnt IRL (Ziebart et al., 2008)**：

假设专家以最大熵策略行动：

$$r^* = \arg\max_r \left[ \mathcal{L}(r) - \alpha \mathcal{R}(r) \right]$$

其中 $\mathcal{L}(r)$ 是专家对数似然，$\mathcal{R}(r)$ 是正则项。

**优势**：
- 学习到的奖励函数比手工设计的更具泛化性
- 可以解释专家行为的潜在动机

**缺点**：
- 计算开销大（需要在内层循环跑 RL）
- 奖励函数存在歧义性（多个奖励可能产生相同策略）

#### 3. Pre-training + Fine-tuning（预训练 + 微调）

目前**最实用**的工业级方案：

```
Phase 1: 行为克隆预训练
    专家演示数据 ──→ BC 训练 ──→ π_pretrained (已具备基本能力)

Phase 2: RL 微调
    π_pretrained ──→ 在环境中继续用 SAC/PPO 训练 ──→ π_fine_tuned (超越专家)
```

**代表工作**：

| 方法 | 来源 | 核心贡献 |
|:-----|:-----|:---------|
| **DAgger (Dataset Aggregation)** | Ross et al., 2011 | 迭代式收集专家数据覆盖策略访问的状态 |
| **DPPO** | OpenAI, 2017 | 演示初始化 + PPO 微调完成灵巧操作任务 |
| **SQIL** | Reddy et al., 2019 | 将模仿学习构造成 Q-learning 问题，无需超参数调优 |
| **AWAC** | Nair et al., 2020 | Advantage-Weighted Regression，统一 offline RL 和 imitation |

### DAgger 算法详解

**Dataset Aggregation** 通过主动查询专家来解决复合误差问题：

```
Algorithm DAgger:
    1. 初始化空数据集 D = {}
    2. 迭代 i = 1, 2, ..., N:
       a. 用当前数据集 D 训练策略 π_i (BC)
       b. 让 π_i 在环境中运行，收集状态轨迹 {s}
       c. 对收集到的每个状态 s，查询专家: a_expert = π^*(s)
       d. 将 (s, a_expert) 加入 D
       e. 新的策略将在更多"真实访问到的状态"上学习
```

### 演示数据的质量与数量

| 因素 | 建议 |
|:-----|:-----|
| **数量** | 通常几十~几百条高质量轨迹即可启动；越多越好但边际递减 |
| **质量** | 亚专家演示 > 少量完美演示 > 大量低质量噪声演示 |
| **多样性** | 覆盖多种成功策略比单一最优策略更好（避免过拟合特定行为） |
| **模态** | 状态-动作对最基本；有条件时可加入人类偏好排序（RLHF 思路） |

## 其他重要方法

### Intrinsic Motivation（内在动机 / 好奇心驱动）

当外部奖励稀疏时，让智能体自己给自己发奖励——基于**探索量**或**预测误差**。

#### Curiosity Module (Pathak et al., 2017)

$$r_t^{int} = \beta \cdot \|\hat{\phi}_{t+1} - \phi(s_{t+1})\|_2$$

其中：
- $\phi(s)$：状态 $s$ 的特征向量（由编码器输出）
- $\hat{\phi}_{t+1}$：用 $(s_t, a_t)$ 预测的下一状态特征
- **预测误差越大 → 越新奇 → 内在奖励越高**

```
Curiosity Module 结构:
┌──────────┐     a_t      ┌──────────────┐
│  策略 π  │ ──────────→ │ Forward Model │ → ŝ_{t+1} 或 φ̂_{t+1}
└──────────┘              └──────────────┘
                                 ↓
                          ‖prediction - actual‖
                                 ↓
                         r_int = β × prediction_error
                                 ↓
                    总奖励 = r_ext + r_int
```

#### Random Network Distillation (RND, Burda et al., 2018)

- 维持一个**固定随机网络** $f: S \to \mathbb{R}^d$ 和一个**可训练预测网络** $\hat{f}: S \to \mathbb{R}^d$
- 内在奖励 = 两个网络输出的 MSE
- 已被用于 **Montezuma's Revenge** 等极端稀疏奖励 Atari 游戏

### Curriculum Learning（课程学习）

**核心思想**：从简单任务开始，逐步增加难度。

```
课程设计示意:

Level 1 (简单):  目标就在起点旁边          → 随机探索即可命中 → 获得正向奖励
Level 2 (中等):  目标距离适中              → Level 1 学到的策略提供基础
Level 3 (困难):  目标较远且有障碍物        → 在 Level 2 基础上微调
Level 4 (专家):  完整复杂任务             → 渐进式逼近最终目标
```

**自动课程生成方法**：

| 方法 | 核心思想 |
|:-----|:---------|
| **ALP-GMM** (Florensa et al., 2017) | 用 GMM 对状态空间建模，逐步扩展支持域 |
| **Automatic Domain Randomization** (OpenAI, 2019) | 自动调整仿真器参数难度 |
| **RESET** (Jiang et al., 2021) | 根据智能体表现自动调整课程进度 |

### Hierarchical RL（层次化强化学习）

将复杂的长时域任务分解为**高层规划 + 低层执行**：

```
高层策略 (Manager / Meta-controller):
    "去厨房"
      ↓
低层策略 (Worker / Sub-policy):
    "前进 3 步 → 左转 → 前进 5 步 → 开门"
```

**代表方法**：

| 方法 | 高层输出 | 低层执行 |
|:-----|:---------|:---------|
| **Options Framework** (Sutton et al., 1999) | option (抽象动作) | intra-option policy |
| **HIRO** (Nachum et al., 2018) | 子目标 $g_t$ | 低层策略朝 $g_t$ 执行 |
| **HAC** (Levy et al., 2019) | 多层级子目标 | 逐级细化 |
| **Decision Transformer** (Chen et al., 2021) | 条件生成 desired return | 序列建模 |

**对稀疏奖励的帮助**：即使全局奖励稀疏，**子目标可以设计得更密集**，使低层策略更容易学习。

## 方法选择指南

```
决策树:

你的任务是？
│
├── 目标可达、状态维度低
│   └── 直接 RL (PPO/SAC) + 足够探索
│
├── 多目标/参数化目标任务
│   └── HER (Hindsight Experience Replay)
│       └── 推荐: HER + SAC/TD3
│
├── 有可用的专家演示数据
│   ├── 演示质量高且足够 → Pre-train with BC + Fine-tune with RL
│   ├── 演示有限但优质 → SQIL / AWAC
│   └── 可在线查询专家 → DAgger
│
├── 无演示、单目标、高度稀疏
│   ├── 环境交互成本低 → Intrinsic Motivation (Curiosity/RND)
│   ├── 可分解为子任务 → Hierarchical RL (HIRO/HAC)
│   └── 可手动设计中间奖励 → Reward Shaping (注意 PBRS)
│
└── 以上组合使用效果更佳（实践中常混合多种方法）
```

### 实战建议

1. **不要一开始就用稀疏奖励**：先用 dense reward 验证算法和环境的正确性
2. **HER 是多目标任务的银弹**：如果适用条件满足，优先尝试 HER
3. **BC pretrain 几乎总是有帮助的**：即使是随机策略产生的数据也有一定价值
4. **调试时监控探索覆盖率**：确保智能体确实在探索新的状态区域
5. **归一化和奖励缩放至关重要**：稀疏奖励环境下不恰当的缩放会毁掉学习
6. **考虑 Offline RL**：如果有大量历史交互数据（不一定是最优的），CQL/IQLE/BCQ 等方法可以直接从数据中学习
