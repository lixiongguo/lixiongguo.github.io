##### 蒙特卡洛(Monte Carlo)方法

通过大量采样，然后用概率统计方法来从采样结果中归纳出我们想得到目标函数的数值估计方法称为”蒙特卡洛“方法，比如通过随机地撒上把豆子(采样)通过计数落在圆内外的豆子数可以估算出圆的面积(概率估计)。

![image-20250227093707927](https://lgximgs.oss-cn-beijing.aliyuncs.com/images/image-20250227093707927.png)

智能体与环境进行交互后,我们会有一些轨迹的实际回报数据，如何根据这些数据来计算价值函数呢？根据大数定律采样的平均最后会趋近于期望而价值又是通过数学期望来定义的。那么比如我们计算$s$的期望，通过采样生成很多轨迹，把这些轨迹的回报都计算出来，再计算平均值作为$s$价值的估计。

将这个思路用在评估状态函数$V_\pi(s)$ ，智能体与环境的交互采样大量的轨迹对并对每个轨迹进行如下计算

遍历轨迹中每一个状态，如果在时间步$t$状态$s$被访问到了，那么

1. 状态$s$的总访问数$N(s)$增加1,$N(s) = N(s) + 1$

2. 状态$s$的总回报$S(s)$增加增加本回合该状态的真实回报$G_t$，$S(s) = S(s) +G_t$


最后状态s的价值可以通过回报的平均来估计即$V(s) = S(s)/N(s)$，根据大数定律只要采集足够多的估计就有$V(s) \to V_{\pi}(s)$

**转换为增量更新**：我们要将所有的回合数都走完,才能计算平均值进行估算，而只要通过如下的数学处理技巧，就可以在每个回合结束后估计价值函数
$$
假设现有样本x_1,x_2,...x_t,均值为\mu_t =\frac 1 t \Sigma^{t}_{j=1}x_j\\

那么，\mu_t = \frac 1 t \Sigma^{t}_{j=1}x_j = \frac 1 t(x_t + \Sigma^{t-1}_{j=1}x_j)=\frac 1 t(x_t + (t-1)\mu_{t-1})= \mu_{t-1} + \frac 1 t(x_t -\mu_{t-1})\\
，其中x_t - \mu_{t-1}是残差
\frac 1 t类似于学习率，那么就可以用上一时刻的值来更新现在的值。
$$
利用这个技巧评估状态函数可以改为如下方式，对于每个轨迹不用计算总回报$S(s)$直接进行状态函数估计$V(s) = S(s)/N(s) = V(s)+ \frac 1 {N(s)}(G_t - V(s))$,更一般地我们可以把$\frac 1 {N(s)}$替代为某个学习率$\alpha$ ,即可用$V(s) = V(s)+ \alpha (G_t - V(s))$进行更新,这是一个迭代计算过程,根据**贝尔曼方程**(Bellman Equation)可以确保其收敛性。

将上面的状态函数$V(s)$替换为动作价值函数$Q(s,a)$,即可估计出动作价值函数并通过策略提升对策略进行优化,

```python
#代码片段1 Monte Carlo算法
for episode_idx in range(num_episodes):
    episode = generate_episode(policy)#采样一条轨迹
    G = 0
    visited = set() 
    for t in reversed(range(len(episode))):
        state, action, reward = episode[t]
        G = reward + gamma * G #计算回报
        if (state, action) not in visited:
            visited.add((state, action))
            #增量更新
            Q_table[state, action] = Q_table[state, action] + (G - Q_table[state, action])/(episode_idx + 1)
            # 策略提升
            policy[state] = np.eye(num_actions)[np.argmax(Q_table[state])]
```

##### 时间差分(Time Differnce)估计

估计上面的增量式蒙特卡罗方法必须每一次都完成一个回合才能够估计值函数，而对于许多问题需要走很多步才会结束，这样一方面会造成更新缓慢，另外由于是采集整个回合后进行估计的所以估计的方差也会比较大，所以我们想能否每走一步都进行一次估计。

考虑增量蒙特卡洛公式$V(s_t) = V(s_t) + \alpha(G_t -V(s_t))$，其中$G_t$是真实的轨迹回报，而它的值可以用下一时刻的价值和奖励$r_{t+1} + \gamma V(s_{t+1})$进行估计，那么综合起来就有$V(s_t) = V(s_t) + \alpha(r_{t+1} + \gamma V(s_{t+1}) -V(s_t))$这种对状态函数的估计方法称为时间差分(Time Difference)估计,一般简称为**TD估计**。时序差分方法能够在知道结果之前就开始学习，相比蒙特卡洛方法更快速、灵活。

同样对于动作函数Q可以如下方式更新$Q(s_t,a_t) = Q(s_t,a_t)+\alpha(r_{t+1}+\gamma Q(s_{t+1},a_{t+1})-Q(s_t,a_t)) $

因为上面估计Q函数的方法每一次估计都要用到五元组$\{S_t,A_t,R_{t+1},S_{t+1},A_{t+1}\}$所以称为**SARSA**(取五个首字母)算法

$Q(s_t,a_t) = Q(s_t,a_t)+\alpha(r_{t+1}+\gamma max_{a} Q(s_{t+1},a)-Q(s_t,a_t))$这种估计Q函数的方法只用到了四元组$\{S_t,A_t,R_{t+1},S_{t+1}\}$,解耦了单次动作与轨迹间的关联，所以可以用离线采集的数据更新Q函数，称为**Q-Learning**算法

另外策略提升每次都是选取当前价值最大的动作$argmax_aQ(s,a)$，但是这样很有可能因为我们没有足够的采样经验导致我们选择的不是最优策略即”短视“的问题，因此我们需要不时地尝试新的行为去挖掘更多的信息，这就是探索(Exploration),下面采用的一种$\epsilon-探索$的随机机制来保证探索，以$\epsilon$概率从所有动作中均匀的选择一个动作，以$1-\epsilon$概率选择当前价值最大的动作。

```Python
#代码片段2 Q-learning 算法
def take_action(state)
	# ε-greedy 策略选择动作
    if random.uniform(0, 1) < epsilon:
        action = env.action_space.sample()  # 随机选择动作
    else:
        action = np.argmax(Q_table[state])  # 选择最优动作
    return action

for episode in range(num_episodes):
    state = env.reset()
    done = False
    total_reward = 0
    while not done:
        action = take_action(state)
        # 执行动作并观察结果
        next_state, reward, done,_, info = env.step(action)
        #Q-learning选择最优的动作
        best_next_action = np.argmax(Q_table[next_state])
        #SARSA 继续按照当前策略选择下一个动作，next_action = take_action(next_state)
        #TD估计更新Q-table
        td_target = reward + gamma * Q_table[next_state, best_next_action]
        td_error = td_target - Q_table[state, action]
        Q_table[state, action] += alpha * td_error
        # 更新状态和奖励
        state = next_state
        total_reward += reward
    # 衰减探索率
    epsilon = max(epsilon_min, epsilon * epsilon_decay)
```

Q-learning算法是非常激进的，它一直选择当前价值最大的动作而不管该动作是否有较大的危险性。而Sarsa算法则相对来说因为探索的更充分显得会更加保守些。
