## 1. 方法定位

这是一套 **欧拉网格 + 标记粒子（PLS 风格）** 的 **无粘自由表面液体** 动画方法，不是 SPH/PBF，也不是 Stam 的 2D Stable Fluids。

| | 本求解器 | SPH / PBF | 2D Stable Fluids |
|:---|:---|:---|:---|
| 离散 | MAC 交错网格 + 粒子液面 | 纯拉格朗日粒子 | 固定欧拉网格 |
| 方程 | 无粘不可压 + 自由面 | 粒子动量 / 密度约束 | 粘性不可压（常全域） |
| 自由面 | 粒子 + `liquid_phi` | 粒子自然形成 | 通常染料 / 高度场 |
| 不可压 | 变分压力投影 + PCG | 压力力或位置约束 | Poisson 投影 |

核心参考文献脉络：Bridson 流体动画教材中的 MAC / 半拉格朗日 / PCG；Batty 等关于 **变分压力投影**（静态固体几何、面面积权重）的工作。

## 2. 离散表示

- **速度**：MAC 交错网格  
  - $u$：$(n_i+1)\times n_j\times n_k$（$x$ 面心）  
  - $v$：$n_i\times(n_j+1)\times n_k$  
  - $w$：$n_i\times n_j\times(n_k+1)$
- **固体**：节点 SDF `nodal_solid_phi`（演示中为球壳：$\phi = -(\lVert x-c\rVert - R)$）
- **液体**：标记粒子；每步由粒子重建体心 `liquid_phi`
- **粒子半径**：约 $dx\cdot 1.01\cdot\sqrt{3}/2$，保证粒子覆盖格子对角线

默认场景（与 `main.cpp` / WASM 一致）：域宽 $1$，球壳中心 $(0.5,0.5,0.5)$、半径 $0.35$；液滴中心 $(0.55,0.55,0.4)$、半径 $0.23$。Web 演示默认网格 **32³**（桌面离线常用 60³）。

## 3. 时间步进（`FluidSim::advance`）

每个外层时间步 $\Delta t$（演示取 $0.01$）内按 **CFL** 切子步：

$$
\Delta t_{\mathrm{sub}} = \frac{dx}{\lVert u\rVert_{\max}}.
$$

每个子步顺序：

1. **粒子平流** `advect_particles`：RK2 回溯；若穿入固体则沿 SDF 投影回流体侧  
2. **速度平流** `advect`：一阶半拉格朗日，对 $u,v,w$ 分别回溯采样  
3. **外力** `add_force`：重力 $v \leftarrow v - 9.81\,\Delta t$  
4. **压力投影** `project`：  
   - `compute_phi`：由粒子写 `liquid_phi`  
   - `compute_weights`：固体面面积分数（cut-cell 权重）  
   - `solve_pressure`：变分压力 Poisson  
5. **外推** `extrapolate`：把有效速度邻域平均扩展到无效面（约 10 层），供下一步平流插值  
6. **固体约束** `constrain_velocity`：权重为 0 的面上去掉法向速度分量

```text
particles ──advect──► liquid_phi
u,v,w ──semi-Lagrangian──► + gravity ──variational project──► extrapolate ──constrain──►
```

## 4. 变分压力投影

目标：在带固体与自由面的 MAC 网格上求压力 $p$，使更新后的速度满足不可压与边界条件。

要点：

- 组装稀疏 SPD 系统，未知量规模约 $n_i n_j n_k$
- **面权重** `u_weights` 等来自固体 SDF 的 `fraction_inside`，实现静态几何的变分 / cut-cell 处理
- 自由面用 `fraction_inside` 构造 ghost 压力系数 $\theta$，避免粗糙的 Dirichlet $p=0$ 阶梯
- 线性解：**Robert Bridson MIC(0) 不完全 Cholesky + PCG**（`pcgsolver/`）

速度修正（示意）：

$$
u \leftarrow u - \frac{\Delta t}{\theta\,\Delta x}\bigl(p_i - p_{i-1}\bigr)
$$

（$v,w$ 类似；$\theta$ 在自由面附近缩放梯度。）
